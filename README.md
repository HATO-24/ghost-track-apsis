# AD-FLEET · 舰队战术

近未来轨道战场上的**信息战指挥游戏**。玩家不操船，只下达命令；看到的是传感器与下属汇报拼出来的不完整战场。

- 设计计划书 → [`docs/01_设计计划书.md`](docs/01_设计计划书.md)
- 物理与轨道模型 → [`docs/02_物理与轨道模型.md`](docs/02_物理与轨道模型.md)

## 目录

```
docs/     设计与技术文档
src/      代码（阶段一：原生 Web，无构建步骤）
```
