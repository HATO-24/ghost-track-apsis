## 0　一句话

> 玩家下的是**意图**，不是舵量。
> 舰上导航/火控把它算成一个**计划**；计划要经过延迟才生效；点火烧掉的是 Δv，烧完不能撤销。

---

## 1　三条原则

1. **不直接操船。** 没有摇杆、没有油门、没有“按住转向”。玩家选单位、选动作、给目标/约束。
2. **计划先预览，再授权。** 系统算出预测轨道、Δv、耗时、暴露风险；玩家看到代价后才下命令。
3. **命令有延迟，执行不可逆。** 命令经链路传播 + 执行准备才生效；生效前可撤销，点火后只能接受新轨道。

---

## 2　命令类型（第一版）

| 命令 | 中文军语 | 做什么 | 主要参数 | 代价 |
| --- | --- | --- | --- | --- |
| `STATION` | **保持站位** | 维持当前相对位置/轨道 | 站位点、容差 | 小 Δv、持续修正 |
| `SHADOW` | **跟踪伴飞** | 对某目标保持相对方位/距离 | 目标批号、距离、方位 | Δv、暴露风险 |
| `BURN` | **脉冲点火 / 变轨** | 在指定时刻施加 Δv | 执行时刻、Δv 矢量/大小、方向 | Δv、热、暴露 |
| `APPROACH` | **接近 / 交会** | 接近目标到指定距离/接近率 | 目标、终距、接近率、时间 | 大 Δv、碰撞风险 |
| `WITHDRAW` | **脱离 / 规避** | 远离威胁或脱离接触 | 威胁批号、脱离方向、最小距离 | Δv、可能暴露 |
| `ATTITUDE` | **姿态 / 指向** | 转向目标、装甲面、主炮指向 | 目标/姿态角、角速度 | RCS、时间 |
| `EMCON` | **辐射控制** | 雷达/通信/干扰开机或静默 | 设备、时机 | 暴露/失联 |

姿态和机动分开：**变轨改变位置，姿态改变朝向**；两者都要时间，不能瞬间完成。

> 命令码不要裸写 `HOLD`：ROE 的 `WEAPONS HOLD` 是“武器待令/仅自卫”，日志 `HOLD` 是“暂缓执行”，
> 命令码 `STATION` 才是“保持站位”。三种语义必须分开。

## 3　命令对象

```json
{
  "unit": "哈马丹",
  "action": "BURN",
  "target": null,
  "params": { "t_exec": 372.0, "dv_mps": 84.0, "dir": "prograde" },
  "issue_t": 352.0,
  "delay_s": 8.0,
  "exec_t": 380.0,
  "status": "queued",
  "plan": { "dv_mps": 84.0, "fuel_after": 1036.0, "predicted": "..." },
  "authorization": "supervisor"
}
```

- `status`：`draft → queued → transmitted → executing → done / aborted / failed`。
- `delay_s`：链路传播 + 执行准备；激光/红外/中继/穿梭机不同。
- `exec_t`：真正点火时刻；玩家可以在 `exec_t` 前撤销。
- `plan`：预览时的预测；执行后与实际比对，写进日志/报告。

## 4　玩家流程

1. **选单位**：在接触列表/地图上选本舰或友舰。
2. **选动作**：保持 / 跟踪 / 变轨 / 接近 / 脱离 / 姿态 / 辐射控制。
3. **给目标或终点**：
   - 跟踪：选批号 + 期望距离/方位；
   - 变轨：选方向（顺行/逆行/法向/径向/自定义）+ Δv 大小 + 执行时刻；
   - 接近：选目标 + 终距 + 接近率 + 最晚时刻。
4. **看预览**：预测虚线、Δv 成本、剩余 Δv、耗时、暴露风险、误差椭圆。
5. **授权**：确认后进命令队列；显示传播延迟和生效倒计时。
6. **撤销/改令**：生效前可撤销；目标机动或链路中断时，计划会过时，需要重算。
7. **执行**：点火后状态向量改变，预测轨道重画，日志写一条 `BURN`，报告里可引用。

> 关键体验：你已经下令，但还有几秒钟可以后悔——这就是本作的核心张力。

## 5　轨道数学（第一版够用）

- **L1 局部（第一关）**：站心线性化相对运动，`a = K·r + 2n×v`（CR3BP 二阶项），脉冲点火只改 `v`；预测用 `orbit_model.gd` 现有模型。
- **地球/月球两体**：开普勒传播；变轨 = 在 `exec_t` 把 `v` 加上 `Δv`；交会用 Lambert 求解，后续接。
- **不是瞬移**：点火有持续时间（化学脉冲几秒到几十秒，核热更长，电推几百秒到几小时）；第一版先按脉冲处理，持续推力后续加。
- **Δv 是预算**：每次命令扣 `unit.dv`；油船可补给；Δv 不够时计划直接标红，不允许下注。
- **误差**：预测轨道有误差椭圆；命令延迟越长、目标越机动，误差越大。

## 6　命令延迟与链路

| 链路 | 延迟 | 特点 |
| --- | --- | --- |
| 激光通信（直接） | 0.3–2 s | 主链路；高带宽；需视线 |
| 激光中继（中继舰） | 8 s | 无中继时 45 s；中继损失后回退 |
| 红外信息传输 | 2–8 s | 低带宽短报文；第三手段；低截获 |
| 无线电 | 2–8 s | 兜底；鲁棒/全向，但易被干扰/截听 |
| 可见光传输 | 秒级–分钟级 | 最后手段；极低带宽；手动操作 |

- 延迟按**仿真时间**累计；执行窗口锁 1× 时，玩家能真实感到“命令在路上”。
- 链路中断时，命令可能卡在 `transmitted`，或者到达时目标已经变了。
- 命令队列必须可见：谁、什么动作、还有几秒生效、能否撤销。

## 7　UI

- **命令面板**：选中单位后出现动作列表；不是摇杆。
- **机动规划器**：时间轴上的一个**点火节点**；方向预设（顺行/逆行/法向/径向/自定义）+ Δv 数值/滑杆；预览虚线、Δv 成本、剩余 Δv、误差椭圆。
- **执行倒计时**：`T+06.2s`、链路延迟、可撤销；点火后变历史。
- **多点计划**：后续支持一次规划多个节点（变轨 → 滑行 → 交会），第一版只做单节点。
- **禁止项**：不做手动飞行、不做实时姿态摇杆、不做“点哪飞哪”的无代价移动。

## 8　第一关的范围

第一关不教完整变轨，只教三件事：

- **HOLD / SHADOW**：让哈马丹保持对谷神-2 的跟踪；命令经望楼中继 8 s 生效。
- **MOVE（拖船/油船）**：让深井号把储罐拖离航道；用简化“站位移动”，不走完整变轨规划器。
- **Δv 感**：每次移动扣预算，玩家看到“机动是花钱”。

完整的 BURN / APPROACH 规划器放到第二关；第一关的“命令延迟”比“轨道数学”更重要。

## 9　实现顺序

1. `command_model.gd`：命令对象、队列、延迟、撤销、状态机；先不接 UI。
2. `orbit_model.gd` 扩展：`plan_burn(unit, dv, t_exec)` / `apply_burn(unit, dv)`；预测重算。
3. UI：命令面板 + 时间轴点火节点 + 预览 + 授权/撤销。
4. 第一关：STATION/SHADOW/MOVE 三个脚本化命令 + 教学提示。
5. 第二关：BURN/APPROACH 完整规划器、Lambert/持续推力。
