## 0　口径

1. **只记录事故事实**：设备/结构发生了什么、何时、影响哪些设施/泊位/储罐、恢复状态。
2. **不写叙事**：不写“谁干的”“为什么”“玩家会看到什么对话”。
3. **日期为建议值**：`2192-10`–`2193-03` 之间，全部早于 `2193-04-01`；具体日期待用户核对。
4. **设施码**采用 20 §6.2/§6.3 的 `STN-/FUL-/TNK-/PRT-/OTC-`；未列设施不强行补造。
5. **记录完整性**：部分事故的遥测/港务记录存在缺口，为后续“数据中断/黑匣子异常”提供事实基础；不写谁删除。
6. **覆盖范围**：L1–L5 的全部 20 个已知站点至少一项事故；Chronos 储罐/泊位、L1 OTC 另列设施级事故。
7. **NESOSS 不在本表**：NESOSS-01..06 的事故不记录（任务明确排除）。
