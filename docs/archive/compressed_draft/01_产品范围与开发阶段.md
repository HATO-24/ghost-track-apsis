# 01 产品范围与开发阶段

> 状态：权威。最后更新：以本轮对话为准。依赖：`00`。

## 1 产品定义

- 类型：近未来地月系信息战/舰队指挥叙事游戏。
- 视角：玩家是 OCUVF-ID13 指挥官，只通过指挥终端看态势、下命令、读通信、做政治/道德选择。
- 范围：**完整游戏**，不是只做序章 demo。
- 首发语言：中文、日文、英文；本地化接口开放。
- 平台：Windows（当前）；后续可评估其他平台，不进入本阶段承诺。

## 2 核心体验

1. 读一个被延迟、遮挡、欺骗和噪声污染的战术图。
2. 用命令、传感器、通信和证据改变局面，而不是直接操纵舰船。
3. 在 ROE、政治红线、副官信任、道德值之间做选择。
4. 从序章到多结局，形成一条完整的战役。

## 3 内容范围（剧本已给）

- 2193 年 11 月 7 日开场。
- 序章：L4-02 就任、玩家名输入、CG、简报、副官教学、L4→L1、入港并轨、谷神-2 识别、Chronos 事件、AV-4412 对峙、谈判、报告、分支。
- 后续章节：GHOST TRACK 线、程序正义线、错付正义线、守口如瓶线、多个结局。
- 完整战斗系统：剧本尚未写战斗呈现，需单独立项；不能假定“只有谈判”。
- 完整命令/通信/ROE/授权/存档。
- 空间站以符号 UI 呈现，但物理层按真实轨道/站体数据计算；近景仅在船坞/美术阶段处理。

## 4 明确不做/暂不做

- 不做玩家直接驾驶。
- 不做自由沙盒建造。
- 不做多人在线。
- 首阶段不强制完整 JPL 星历运行时加载；先 JPL 派生紧凑星历 + 局部高精度积分。
- 不在序章阶段做完整武器平衡；但战斗系统架构必须预留。

## 5 开发阶段（按用户调整）

### 阶段0：契约与技术存档

- 保留 `game_v17` 阶段2转场为技术验证存档；不再在其临时 UI 上开发。
- UI token/字体度量规范。
- 实体/时间/坐标/命令/通信/传感器/存档 schema。
- 剧情状态机 DbC（Design by Contract）。
- 本文档集与旧文档归档映射。

### 阶段1：新 UI

- Control + Theme + 9-Slice 面板。
- 自定义指针。
- 顶栏/三色圆点/动态计时器。
- 接触列表折叠/筛选/目标牌。
- 中日英输入法组件 + 候选窗美术兼容。
- 教学高亮/弹窗/标签避让。
- 全量 UI 文本校对。

### 阶段2：仿真

- TrackTable 单一写者。

- ROE/三级授权。
- 任意时刻存档。

### 阶段3：序章与后续章节衔接

- 谈判/报告系统功能化。
- 剧情分支路线功能化。

- 中后期剧情完善后的完整游玩流程衔接。

### 阶段4：内容与打磨

## 6 完整战斗系统（新增立项）

剧本尚未写战斗呈现，但产品范围要求完整可运行战斗系统。必须单独立项，至少定义：

- 武器类型/射程/弹药/冷却/命中/损伤。
- 火控解算、跟踪、照射、发射、点防御。
- ROE 四档与 TRACK/SOLUTION/FIRE 三级授权。
- 电子战/诱饵/干扰与传感器闭环。
- 损伤/损管/失压/火灾/断电。
- AI 行为与舰队编队。
- 战斗 HUD/地图/目标牌/授权提示。
- 战斗结果如何进入剧情/报告/声望。

在战斗规格完成前，不得用“脚本化开火”冒充完整战斗系统；FIRE 剧情分支可以是脚本后果，但战斗系统本身必须独立实现。

## 7 验收原则

- 每个阶段有可运行构建、可复现测试、可回退开关。
- 所有玩家可见文本有文本 key。
- 所有数值有来源/单位/时间戳。
- 所有命令/通信有事件日志。
- 存档可恢复在途命令、通信、剧情状态。
- 性能目标：UI 60fps；仿真 tick 可独立于渲染；加载不进行 19s 级同步规划。
