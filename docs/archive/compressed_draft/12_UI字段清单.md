# 12 UI 字段清单（待用户复核润色）

> 状态：草案/权威字段清单。每个字段给出：用途、数据源、呈现样式。最终文案由用户复核。
> 依赖：`05`/`06`/`07`。

## 1 顶栏

| 字段 | 数据源 | 呈现 |
| --- | --- | --- |
| 指挥官名 | 存档/玩家输入 | `指挥官/COMMANDER {name}`，CJK 9–10pt，亮色 |
| 任务时间 | Time Service | `T+DD:HH:MM:SS`，等宽 10pt，持续计时 |
| 入港时间 | Time Service/port state | `PORTED TIME HH:MM:SS`，港内替代任务时间 |
| 动态计时器 | EventBus | 堆叠列表：`变轨窗口 00:18:00`、`入轨 00:03:20`、`命中 00:00:08`；过期移除 |
| 链路 | Comms Service | `LINK L1 / LR / 8s`，颜色按状态 |
| 时标 | Time Service | `×1 / ×100 / ×1000`，可切换 |
| Δv | Entity/Units | `Δv 1,120 / 1,260 m/s`，等宽数字 |
| ROE | Combat/ROE | `WPN HOLD/TIGHT/FREE/DEFEND`，独立醒目色；序章前锁定 |
| 三色圆点 | Save Service | 绿/琥珀/红圆点，放大；悬停显示功能文本 |

## 12 字段复核要求

- 用户逐项确认字段名/文案/优先级；
- 所有字段必须能追溯到数据源；
- 不显示无来源/不可解释数值；
- 占位字段在最终 UI 中必须移除或标 `TBD`。
