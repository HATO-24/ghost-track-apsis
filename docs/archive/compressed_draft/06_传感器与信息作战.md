# 06 传感器与信息作战

> 状态：权威。替代 `11`/`38` 的临时实现约定。所有型号只是数据，逻辑按能力。

## 1 单一权威

```text
World State
 → Entity/Mount/Environment
 → Sensor Observations
 → Data Link / Fusion
 → TrackTable (single writer)
 → UI view model
```

- 战情/识别/威胁只由 TrackTable 写。
- 传感器层只产生 Observation/Evidence，不直接改 UI。
- 数据链自动融合只到 L2；L3/L4 由玩家主动识别操作完成。

## 2 接触等级

| 等级 | 含义 | 产生方式 |
| --- | --- | --- |
| L1 | 方位线/能量 | 被动传感器/单站 ELINT/光学方位 |
| L2 | 定位 | 多站/数据链/主动雷达/融合 |
| L3 | 分类 | 光学凝视、ELINT 指纹、数据库比对 |
| L4 | 确认 | IFF、应答、目视/灯光、档案 |

设计规则：

- 任何舰的被动传感器发现新目标 → 数据链比对 → 其他舰自动以同类传感器参与定位；
- 成功→L2 精确定位；失败→L1 方位；
- 数据链自动化是**舰队级机制**，不是关卡脚本；
- 型号只影响性能限制，不写死关卡。

## 3 传感器类型

### 雷达

- 球形/定向、RCS、距离、刷新、干扰；
- 主动开机=暴露；
- TWS 六态：SEARCH→DETECT→ACQUIRE→TRACK→STARE→FIRE_CONTROL；
- 失锁/重捕。

### 光学 VIS

- 口径、焦距、像素、FOV/IFOV、曝光、灵敏度；
- 视轴/云台、凝视、相对角速度、运动模糊；
- 光照/阴影/遮挡/地球反照/太阳规避；
- 可分类 L3，不产生身份；
- 兼容可见光灯语：只输出预定短语/代码。

### IR

- 热特征/背景/冷却；
- FOV/遮挡/角速度；
- 锁定→L1；不分类；
- 与 VIS 独立通道。

### IFF

- Mode 1/2/3/A/C/S/5；
- 询问/应答/无应答/故障/错误码/缴获码/加密不匹配/超距/EMCON；
- 只写身份证据，不产生位置/接触；
- 不明不自动判敌；hostile 只能由玩家/授权/融合产生。

### ELINT / COMINT

- ELINT：被动截获、链路预算、测向、指纹、LPI；
- 单站不产生接触；多站交叉只出 SIGNAL FIX 候选；
- COMINT：与 ELINT 分离；加密只给元数据/流量，不解码；
- 可见光灯语属于通信/光学交叉，需独立通道。

### 数据链

- 舰队共享观测/定位/识别证据；
- 延迟/带宽/丢包/中继；
- 中继舰（望楼）改变路径；
- 数据链被干扰时降级。

## 4 环境

- 地球/月球/站体遮挡；
- 太阳光照/阴影/地球反照；
- 背景热/杂波/干扰；
- EMCON；
- 天气/尘埃（如适用）。

## 5 信息作战

### 事件总线

统一 `Observation/Evidence/EmitterSignal/EWEffect/CommsEvent`；所有事件带 `t/source/target/confidence`。

### EW

- 噪声干扰、压制；
- 欺骗/假目标；
- 通信干扰/欺骗；
- 诱饵/箔条；
- EMCON；
- 激光致盲/LWR；
- 效果由 TrackTable/Environment 结算，不写独立脚本。

### UI

- 主 HUD 只显示摘要/告警/身份；
- 细节进传感器/光学/ELINT/EW 窗；
- 锁定/授权/未开火原因在目标牌显示；
- 所有“实际状态”必须能从 view model 追溯来源。

## 6 数据契约

```text
Observation: sensor_id, target_id, t, frame, bearing, range/range_sigma,
             level, classification, confidence, quality, occluded, source
Evidence: id, kind, target_id, t, source, confidence, text_key
Track: id, level, identity, threat, evidence[], last_update, age
```

## 7 验收

- 数据链 L1→L2 自动化可复现；
- L3/L4 必须玩家操作；
- IFF 不产生接触/不判敌；
- 光学/IR 遮挡/FOV/SNR/凝视可复现；
- 可见光灯语可读取并写入通信；
- 干扰/欺骗可在 UI 与日志追溯；
- 同一目标多传感器不产生重复航迹。
