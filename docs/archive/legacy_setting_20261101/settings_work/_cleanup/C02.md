# 第 2 章 · 地月系地理与站点

## 地月系概览

地月系的政治地理由四个区域构成。

- **地球**：UEG 的首都、主要机构、税基、兵源与发射场所在地。地球联合政府通过《轨道宪章》管辖发射场、地球同步轨道港、地月交通节点、海关与导航。
- **月球**：UEG 在近地轨道外最重要的定居点。月面永久居住领地-永昼（Solstice）是最大的地下城市与工业中心；UEG 在近地轨道外唯一登记在册的大型船坞新维多利亚（Neo-Victoria）位于月面。
- **拉格朗日点港群**：由五个港群组成——L1 Meridian、L2 Karman、L3 Alborada、L4 Anvil、L5 New Lagos。五个港群共享 OCJC 席位，但政治立场、产业与对 UEG 的态度不同。
- **远地环带飞地**：位于小行星带，是矿物开采、冶金与工业采集舰的集散地；**火星**及其卫星是当前地—火战争的主战场。

### 港群政治倾向

- **L1 Meridian**：立场摇摆。UEG 与 OCU 共管，港内同时存在两套行政与安保体系。
- **L2 Karman**：总体偏向 UEG；港群内部对 UEG 接管存在不安，担心“临时托管”长期化。
- **L3 Alborada**：OCU 稳定票仓，对 UEG 与清算者部队态度明确。
- **L4 Anvil**：OCU 最核心集群，坚定的殖民地自治支持者；ID13 的后勤依赖此地。
- **L5 New Lagos**：属于 OCU，但鹰派与鸽派斗争激烈；鹰派倾向模仿 MIDA 的袭扰策略，鸽派主张谈判争取自治。

### 月面与远地

- **月面永久居住领地-永昼 / Solstice**：月面地下多层级巨型城市，由多家企业组成的统筹理事会管理；UEG 在近地轨道外唯一登记在册的大型船坞 **新维多利亚 / Neo-Victoria** 位于月面。
- **远地环带飞地 / Distant Zonal Enclave**：小行星带工业集群，UEG 法律不承认其存在合法政治实体；唯一大型实体为 **外环合作社 / Outer Ring Cooperative**，是 ID13 最可能也最不可靠的补给来源。

## 设施层级、识别码与应答机

### 层级

港群由设施组成，设施下辖模块、泊位与储罐：

```text
L1 Meridian（港群）
├─ L1-01 Greenwich（行政/海关站）
├─ L1-03 Sextant（转运/进港调度站）
├─ L1-05 Chronos（燃料加注站 + 储罐群）
├─ L1-08 Astrolabe（商业/仲裁站）
├─ OTC-L1-01（轨道交通管制雷达卫星）
├─ TNK-L1-05-01..03（Chronos 储罐）
└─ PRT-L1-05-A/B（港口泊位）
```

港群、空间站、OTC 卫星、独立储罐均为实体；泊位与对接口是设施的子对象。空间站与港口站以 station-keeping 维持位置；OTC 卫星运行于真实轨道，可被光学与雷达观测；独立储罐随站体或独立轨道运行。

### 识别码规则

| 类型 | 前缀 | 示例 |
| --- | --- | --- |
| 港群 | `CL-` | `CL-L1-MER` |
| 空间站/港口站 | `STN-` | `STN-L1-01` |
| 加注站 | `FUL-` | `FUL-L1-05` |
| 储罐 | `TNK-` | `TNK-L1-05-03` |
| OTC 卫星 | `OTC-` | `OTC-L1-01` |
| 泊位/对接口 | `PRT-` | `PRT-L1-05-A` |
| 中继/通信节点 | `RLY-` | `RLY-L2-02` |

应答机码独立于设施码：

```text
TP-CL-L1-MER
TP-STN-L1-01
TP-FUL-L1-05
TP-TNK-L1-05-03
TP-OTC-L1-01
TP-PRT-L1-05-A
```

- 每个实体唯一；不允许复用或回收后重新分配。
- 应答机类型字段取值 station/port/fuel/tank/otc/relay。
- IFF、光学与 ELINT 只能将应答机作为 L4 证据；不能因“应答机是空间站”自动判友/敌。
- 无应答、错误码、缴获码、过期码一律保持未知，不自动判敌。
- 港口、加注站、储罐、OTC 卫星均可独立识别，不必先识别整个港群。

## 轨道交通管制与燃料设施

### OTC 卫星

每个港群或空间港至少配置一台 OTC（Orbital Traffic Control）交通管制卫星；大港多星、异轨互补。

| 港群/节点 | OTC 数量 | 轨道方案 | 职责 |
| --- | --- | --- | --- |
| L1 Meridian | 2 | 站群高轨中继 + 近站巡逻 | 进港排队、泊位分配、Chronos 储罐区监视 |
| L2 Karman | 2 | 月背中继 + 高轨观测 | 月背通信窗口、深空航道 |
| L3 Alborada | 1 | 站群同步轨道 | 农业/水运交通 |
| L4 Anvil | 2 | 船坞近轨 + 高轨 | 船坞调度、重件运输 |
| L5 New Lagos | 2 | 高密居住轨道 + 外轨 | 客运/货运分流、媒体空域 |
| NESOSS | 3 | 近地同步轨道三节点 | 近地总调度、UEG 舰队/海关支援 |
| LEO 近地轨道 | 3 | 低/中/高轨 | 近地商业、海关、救援 |
| 远地轨道 | 2 | 远地中继/深空 | 外环补给、远地航道 |
| 月同步站群 | 2 | 月同步中继 + 光学 | 月面/月同步交通 |

OTC 是独立设施实体，具备应答机、设施码与物理参数。

### 燃料储罐与加注设施

每个空间港或港群至少配置：

- 燃料储罐（`TNK-`）
- 加注站/加注接口（`FUL-`）
- 储罐区交通管制节点
- 事故隔离区/消防/泄压能力

### 轨道交通管制机制

```text
OTC 监视
→ 航迹/应答机/设施码校验
→ 航道/泊位/窗口分配
→ NPC 船只占用航道
→ 玩家/敌方申请或伪装
→ 记录/异常/取证
```

- 航道有容量、方向、时间窗与优先级。
- NPC 船只按时刻表与合同占用航道。
- 玩家或敌方单位可申请合法航道、伪造应答机或设施码、改写或删除航道记录、利用记录缺口掩盖行踪。
- 伪装存在代价：OTC 交叉校验、应答机异常、时间戳与轨迹不一致会产生 GHOST TRACK 线索。
- 航道记录进入 OTC、港务与黑匣子数据，可供调查、谈判与报告使用。
