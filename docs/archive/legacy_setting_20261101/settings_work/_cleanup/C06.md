# 第 6 章 · 舰船与识别

> 这些船是没有窗户的建筑物。
> 船有名字，人有编号。识别一条船，是读它的编制语言（舰级 / 舰种 / 舰名 / 舷号）、四位数批号、六级身份与六级威胁；探测等级 L1–L4（看得多清）与身份（政治上是谁）是两条轴，互不混淆。

## 一、舰船法则

### 1. Δv 只看燃料比，不看吨位

```
Δv = Isp · g₀ · ln( 1 / (1 − f) )      f = 燃料质量 / 总质量
```

同样 30% 燃料比、同一种推进，一千吨的船和一万吨的船，Δv 相同。

> 吨位买的是推力、装甲、传感器和载荷；燃料比买的是航程。

因此：油船是全队航程最远的船，也是全队最慢的船。

### 2. 剪影即教义

本作以线框渲染，剪影是唯一稳定的信息通道。外形由功能推导：

| 舰体特征 | 玩家读出的信息 |
| --- | --- |
| 散热片总面积 | 热负荷 → 武器功率、反应堆规模 |
| 散热片是否对称 | 是否受损、是否在应急散热 |
| 燃料舱占比 | 航程 / 是不是油船 |
| 装甲带厚度 | 抗打程度、是不是有人舰 |
| 桅杆高度 | 传感器孔径 → 探测距离 |
| 外挂罐数量 | 远征状态 / 临时改装 |

设计规则：任何一个外形特征，如果不能被玩家读成一条战术信息，就删掉。

### 3. 船厂即身份

一艘船的外形由船厂的生意模式决定：泉州有大坞和 UEG 政府订单，所以它造得整齐；车肆靠修船起家，所以它的船永远像未完成品；永昼的船本来只是会飞的压力容器，只是有人后来加上了炮。

### 4. 身份是编制

一艘船的身份由五层组成：厂商型号、舰级、舰种、舰名、舷号。各层定义与主标识见「目标识别与判读」，命名规则详见第 8 章。

### 续航公式

```
全推续航 t = f · ve / a
```

与吨位无关，只与燃料比和加速度有关：

| 舰种 | f | a | 全推续航 |
| --- | --- | --- | --- |
| 哨舰 | 0.25 | 0.15 g | 25 min |
| 炮舰 | 0.30 | 0.10 g | 45 min |
| 弹舱舰 | 0.35 | 0.08 g | 66 min |
| 中继舰 | 0.20 | 0.12 g | 25 min |
| 油船 | 0.70 | 0.01 g | 17.5 h |
| 船坞舰 | 0.30 | 0.02 g | 3.8 h |
| 拖船 | 0.30 | 0.20 g | 22 min |
| 舰载穿梭机 | 0.50 | 1.0 g | 7.5 min |

### 识别阶梯：探测便宜，识别昂贵

真实的红外物理决定：在太空里藏不住任何东西。三百度的船体对三度的背景，十万公里外就能被看见。本作的隐蔽发生在识别层：

| 层级 | 物理手段 | 代价 | 对应接触等级 |
| --- | --- | --- | --- |
| 探测（有没有） | 被动红外，大孔径 | 几乎免费 | L1 |
| 定位（在哪） | 三角测量 / 主动雷达 | 需要第二个平台，或暴露自己 | L2 |
| 识别（是谁） | 光学、光谱、信号特征 | 需要时间与接近 | L3 |
| 确认（叫什么） | 数据库比对、无线电问答 | 需要情报，或对方配合 | L4 |

> 干掉对方的哨舰，比干掉对方的炮舰有用。

## 三、推进系统

### 三种发动机

| 类型 | Isp | 推力 | 推进剂 | 用途 | 取舍 |
| --- | --- | --- | --- | --- | --- |
| 化学 | 320 s | 高 | 可贮存（肼类 / 四氧化二氮） | 战术机动、姿态、末段修正 | 能立刻点火，不用等冷却和预热 |
| 核热 | 900 s | 中 | 液氢 | 战役转移、主要航程 | 比冲够用，推力够大 |
| 电推 | 3000 s | 极低 | 氩 / 水等离子 | 长期轨道调整 | 慢，但能把航程翻三倍 |

化学推进用可贮存推进剂，比冲只有 320 s：战术机动的船不能等加注低温燃料。

### 推进剂从哪来

```
月冰 → 水 → 电解 → 液氢 + 液氧
1 kg 水 → 0.111 kg H₂ + 0.889 kg O₂
```

- 核热用液氢
- 化学用液氧 / 液氢（或可贮存肼类，由地球运来，贵十倍）
- 电推用氩，从月壤提取

冰是燃料，也是整条供应链的起点。一份关于加注站储罐的紧急托管令因此足以引发冲突。

### 沸腾：停着也在漏油

液氢沸点 20 K。再好的绝热层也挡不住漏热：

```
日蒸发率 ≈ 0.2%–0.5%（良好绝热）
```

一艘带 300 吨液氢的船，停三十天损失 18–45 吨。

> 你停得越久，油越少。

对策有三种，都要付代价：

| 对策 | 代价 |
| --- | --- |
| 主动制冷 | 持续耗电，反应堆不能停 |
| 太阳屏蔽 | 增加质量与转动惯量 |
| 尽快烧掉 | 你得决定去哪，而做出决策这行为本身需要情报支持 |

加注站是战略资产：它有油，还有无限制供电和散热，能做到零蒸发贮罐。

### 发动机布局

核热发动机需要阴影屏蔽：反应堆和乘员之间必须有距离，且屏蔽体要在一条直线上。这条约束直接决定了船为什么是长的、桅杆为什么在最上面、反应堆为什么在最下面。

| 部件 | 位置 | 原因 |
| --- | --- | --- |
| 发动机集群 | 舰艉，4–9 台 | 可万向 ±10°，兼作俯仰/偏航控制，节省 RCS 消耗 |
| 推力结构 | 贯穿全舰的脊梁 | 推力要从发动机传到最前端的载荷 |
| 反应堆 | 舰艉段 | 远离乘员，便于散热 |
| 阴影屏蔽 | 反应堆与住舱之间 | 挡住中子和伽马射线 |
| 乘员舱 | 舰体中前部 | 需要完整阴影屏蔽，避免核辐射与宇宙射线危害 |
| 桅杆 | 舰艏最前端 | 视线最好 |

### RCS：最贵的小动作

- 冷气或过氧化氢，Isp 150–200 s
- 推力小，但响应快
- 姿态调整消耗的推进剂不计入主发动机的 Δv，但一样会耗尽

一艘船在轨道上「转身」几十次，消耗的推进剂可能相当于一次像样的变轨。

## 四、能源与热管理

### 电从哪来

| 来源 | 功率密度 | 限制 |
| --- | --- | --- |
| 核热发动机带动布雷顿循环 | 数 MW | 只有主发动机工作时才有 |
| 专用反应堆 | 1–10 MW | 重，需要独立屏蔽与散热 |
| 太阳能 | 1 AU 处 1361 W/m²，效率 20–30% | 面积大，且和散热片抢地方 |
| 电池 / 飞轮 | 峰值 | 只能撑几分钟 |

### 一艘炮舰的电力预算

| 系统 | 常态 | 峰值 |
| --- | --- | --- |
| 生保 | 50 kW | 50 kW |
| 传感器 | 80 kW | 400 kW（雷达开机） |
| 通信 | 20 kW | 200 kW（激光） |
| 轨道炮 | — | 2 MW（电容充电） |
| 近防炮 | — | 300 kW |
| 热管理泵 | 100 kW | 400 kW |
| 合计 | 约 250 kW | 约 3.3 MW |

装机 3 MW，常态负载 250 kW。多出来的电是冗余，也代表着「随时能开火」的权利。

### 散热：热是唯一的硬约束

```
P = ε · σ · A · T⁴        σ = 5.67×10⁻⁸
```

| 废热 | 350 K 需要的面积 | 600 K 需要的面积 |
| --- | --- | --- |
| 1 MW | 1,176 m² | 136 m² |
| 5 MW | 5,880 m² | 680 m² |
| 20 MW | 23,500 m² | 2,720 m² |

温度翻倍，面积降到十六分之一。所有船都想把散热片烧得更热——但越热，红外特征越亮。

| 策略 | 散热片 | 红外 | 雷达 |
| --- | --- | --- | --- |
| 低温大排 | 巨大 | 暗 | 亮（面积大） |
| 高温小排 | 小 | 亮 | 暗（面积小） |

> 这是属于玩家的取舍：躲红外还是躲雷达。

### 热汇：静默的代价

关掉散热片，把热存进热汇（水、熔盐）：

```
5 MW × 300 s = 1.5 GJ
水：4.2 kJ/(kg·K) × 100 K = 420 kJ/kg
需要约 3.6 吨水
```

> 静默航行五分钟，需要三吨水的消耗。

这就是本作的「静默航行」：物理上成立，时间上有限，代价是水——而水既是燃料原料，也是人员的生命线。

### 散热片是命门

散热片是最大的雷达反射面、最大的红外特征、最容易被破片打烂的部分，也是全舰唯一没有装甲的部分。打散热片，不打穿船体也能让它失去战斗力。

## 五、防护

### 选择性装甲

```
1 m² 的 10 cm 钢 = 0.785 t
1000 m² 的外壳 = 785 t
```

785 吨超过一艘炮舰的全部干重。装甲只能选择性覆盖：

| 部位 | 装甲 | 理由 |
| --- | --- | --- |
| 乘员舱 | 2–5 cm 钢当量 | 人员安全永远是第一位 |
| 反应堆 | 5–10 cm + 屏蔽 | 打穿了就是核事故 |
| 火控 / 弹药 | 3–5 cm | 一次命中就失去战斗力 |
| 燃料舱 | 1–2 cm | 主要靠隔舱，不靠装甲 |
| 散热片 | 0 | 装甲了就不散热 |
| 桅杆 / 传感器 | 0 | 装甲了就不透波 |

### 惠普尔屏蔽

```
薄外层（1–3 mm）→ 间隙（10–30 cm）→ 内层（承载壳）
```

高速碎片打在薄外层上被撞碎、分散，内层只需承受剩下的部分。轨道上全是垃圾，每一艘船都有这层皮。它被打穿之后，用钢板补上——这就是剪影上那些「补丁」的来源。

> 补丁出自这个世界真实的需要。

### 四个弱点

- 散热片——热管理失效
- 桅杆——传感器失效
- 喷管——推力失效
- 对接环——结构失效

所有战术都围绕这四处展开。装甲再厚，打这四个地方就够了。

### 点防御

- 近防炮：拦截末段导弹
- 诱饵：欺骗导引头
- 机动：消耗导弹的 Δv

点防御的边界是拦截窗口：导弹末段飞行时间只有几秒，来不及就是来不及。

### 辐射

| 威胁 | 对策 |
| --- | --- |
| 反应堆 | 阴影屏蔽 |
| 太阳质子事件 | 风暴掩体（用水或推进剂做屏蔽） |
| 长期在轨 | 服役期限、药物、轮换 |

轨道居民在生理上不属于地球。长期低重力生活让他们无法适应地球重力。

### 大气与火

舱内为 21% 氧 / 79% 氮。纯氧在太空里等于自杀：一根电线短路就能烧掉整条船。损管队是船上最危险的工作，因为他们要在失压和起火之间选一个。

## 六、整体设计

### 模块化：船是积木

| 接口 | 规格 | 用途 |
| --- | --- | --- |
| 主对接环 | 2.4 m | 舰与舰、舰与站 |
| 辅助对接环 | 1.2 m | 补给、人员、缆线 |
| 标准货柜接口 | 2.4 m × 2.4 m | 任务模块、外挂罐、弹药 |

船可以改装：一艘货船加两个货柜接口就能当弹舱舰；一艘拖船加一个传感器模块就能当扫雷舰。这是 OCUVF 志愿舰队「拼装」风格的物理基础。

### 建造

- 轨道船坞分段建造，焊接是主要工艺
- 没有气动外形，没有起落架，没有整流罩
- 船坞的尺寸决定船的尺寸上限
- 每一根线条都是被预算逼出来的

### 居住

- 没有旋转舱（太重，太大，体积不允许）
- 全员自由落体，靠扶手、系绳、睡袋
- 锻炼两小时/天，仍然会骨质流失
- 服役期有限，需要定期回到殖民卫星的人造重力环境内避免生理疾病

### 生保：水是三合一的

```
水 = 燃料原料 + 饮用 + 辐射屏蔽
```

闭式循环回收 90% 以上，剩下的靠补给。一艘船的水储备同时是它的航程、它的生命和它的掩体。

### 舰体布局：塔楼

船在加速时「下」是舰艉，在滑行时没有「下」。舰体是竖着的塔：

```
        ┌─ 桅杆 / 传感器
        │
      ┌─┴─┐
      │舰桥│        ← 最高、最远、最冷
      ├───┤
      │住舱│
      ├───┤
      │装甲带│      ← 包住住舱与推进剂
      ├───┤
      │燃料舱│      ← 体积最大，占了剪影的一半
      ├───┤
      │反应堆│
      ├───┤
      │发动机│      ← 推力轴，也是「地板」
      └───┘
   ╱散热片╲  ╱散热片╲   ← 横出的「翅膀」，最脆弱
```

### 没有窗户

没有窗户的原因在于没什么可看：交战距离在几十到几百公里，肉眼看不见。舰桥是一个黑房间，玩家看到的画面就是传感器融合的结果。

> 玩家看到的就是船员看到的。

### 满身扶手

滑行时全员自由落体，舱外作业靠扶手和系绳。线框渲染里，这些扶手是免费的纹理——几百条短线，成本几乎为零，质感极强。

### 托盘-5 改 · 哨舰

原型为车肆重工托盘-5 轻型运输船。ID13 的改装型拆除部分货舱，安装传感器桅杆与电子设备，保留原有推进与燃料系统。

主要设备：YW-R9 搜索雷达、MS-OT2 光学设备、CH-IR2 红外阵列、ELINT 接收机、CH-R0 应急无线电。传感器配置使其成为 ID13 的 AWACS/EWR 节点。

性能：干重 300 吨，燃料比 0.25，Δv 2.54 km/s，最大加速度 0.15 g，编制 12 人。装甲与自卫火力有限，主要依靠距离、隐身与舰队掩护生存。

用途：远程搜索、目标识别、航迹融合、电子侦察。YW-R9 开机后会产生明显辐射特征，可能被敌方 ELINT 截获。

### 赤铁-6 改 · 炮舰

原型为永昼机械赤铁-6 矿运船。改装型保留厚壳与大型储罐，加装一门轨道炮与火控系统。

主要设备：LR-4 火控雷达、CH-IR2 红外阵列、CH-R0 应急无线电、轨道炮、近防炮。LR-4 提供火控级测距，但不具备远程搜索能力。

性能：干重 1200 吨，燃料比 0.30，Δv 3.15 km/s，最大加速度 0.10 g，编制 68 人。装甲较厚，火控与传感器性能有限。

用途：近距离火力支援、要点防御、对固定目标射击。对高机动目标的命中率受火控解算时间与目标机动影响。

### 龙门-3M · 弹舱舰

原型为车肆重工龙门级重货船。货舱改为四十八单元导弹发射架，保留近防炮与基础传感器。

主要设备：四十八单元导弹发射架、近防炮、CH-R0 应急无线电、基础火控。舰体自身不具备远程搜索能力，依赖哨舰或舰队融合数据。

性能：干重 900 吨，燃料比 0.35，Δv 3.80 km/s，最大加速度 0.08 g，编制 24 人。

用途：远程导弹打击、饱和攻击、对固定目标压制。导弹耗尽后作战能力显著下降。

### 月港-4 · 油船

原型为泉州重工月港-4 大型油船。ID13 保留其推进剂储运系统，用于舰队补给与储罐转移。

主要设备：推进剂储罐、加注设备、CH-R0 应急无线电。无武器系统，无远程传感器。

性能：干重 2000 吨，燃料比 0.70，Δv 10.63 km/s，最大加速度 0.01 g，编制 18 人。满载时机动能力极低。

用途：舰队航程保障、推进剂转运、储罐拖带。它是舰队最脆弱的战略资产之一。

### 安海-1 · 中继舰

原型为泉州重工安海-1 通信中继舰。ID13 的改装型保留一百二十米可展开通信/监听阵列与两米孔径激光通信主镜。

主要设备：MS-L2 激光通信、ELINT 接收阵列、CH-R0 应急无线电。中继舰不消耗 Δv 传递消息；仅在站位保持与重新部署时消耗 Δv。

性能：干重 500 吨，燃料比 0.20，Δv 1.97 km/s，最大加速度 0.12 g，编制 30 人。展开阵列后雷达反射面积与红外特征显著增加。

用途：激光中继、通信监听、链路管理。中继舰损失后，舰队链路回退到无中继状态，命令延迟上升，HUD 显示 `LINK DEGRADED`。

### 绞盘-2 · 拖船

原型为车肆重工绞盘-2 拖船。用于拖带失去动力的舰船、登舰检查、残骸回收与记录仪打捞。

主要设备：拖曳设备、对接环、登舰舱、CH-R0 应急无线电。无重型武器。

性能：干重 400 吨，燃料比 0.30，Δv 3.15 km/s，最大加速度 0.20 g，编制 9 人。

用途：救援、拖带、登舰、打捞。它决定舰队能否带走战利品或救援失去动力的友舰。

### 咏叹-1 · 舰载穿梭机

性能：20 吨，燃料比 0.50，Δv 6.12 km/s，最大加速度 1.0 g，编制 3 人。无武装。

用途：人员转移、登舰、救援、记录仪运输。它不承担通信任务；发射、对接与轨道调整以分钟到小时计，不适合传递时效性命令。

### 刺桐-2M · 船坞舰

## 八、炮舰的战术位置

轨道炮是瞬时命中，但要打提前量。目标在飞行时间内可以侧向机动：

```
侧向位移 = ½ · a · t²
```

目标以 0.1 g 侧向机动，要让位移小于 50 米（一条船的宽度），飞行时间不能超过 10 秒。弹速 6 km/s，对应射程 60 公里。

> 轨道炮只能打不会躲的东西。

| 目标类型 | 能不能打 | 原因 |
| --- | --- | --- |
| 机动中的战舰 | 不能 | 十秒足够它挪开 |
| 燃料耗尽的船 | 能 | 已失去机动能力的「固定靶」 |
| 加注中的船 | 能 | 它不敢动 |
| 空间站、质量驱动器 | 能 | 它不会动 |
| 已经失去动力的残骸 | 能 | 处决 |

炮舰是处决武器。决战靠导弹，把对方的 Δv 耗尽，再让炮舰上去收尾。这个结论直接来自牛顿力学：它的战术从物理里长出来。

### 识别流程

| 等级 | 系统输出 | 判定方式 | 玩家读到 |
| --- | --- | --- | --- |
| L1 | 方位线 | 被动红外、光学或 ELINT 捕获 | 有接触，方位与信号强度 |
| L2 | 定位 | 主动雷达、双平台三角测量、激光测距 | 位置、距离、协方差；舰种未知 |
| L3 | 分类 | 光学凝视 + 船舰数据库比对；ELINT 特征码辅助 | 舰级 / 舰种 / 船厂 / 使用方，带置信度 |
| L4 | 具体身份 | IFF 应答、注册信息、信号指纹、数据库精确匹配 | 舰名、舷号、具体单位；可能被欺骗 |

L3 只回答「这是什么类型的船」，不回答「这是哪一条船」；L4 才回答具体身份。等级随时间衰减：失去跟踪后，证据逐级过期，L4→L3→L2→L1。

### 船舰数据库

舰队计算机使用的数据库包含以下字段：

- 三维外形、尺寸、舱段比例；
- 雷达反射截面与主要反射源；
- 红外特征、散热片布局、发动机尾焰特征；
- 传感器桅杆、天线、武器与对接环布局；
- 涂装、标准改装件、国籍与舰种标识；
- 注册舷号、舰名、IFF 应答码、通信指纹；
- 船厂建造特征与已知改装记录。

数据库来源包括 UEG 联合轨道军注册处、UEG 海关、OCUVF 情报组、港群船舶登记与缴获数据。不同阵营的数据库完整度不同：UEG 拥有最完整的正规军舰数据，OCUVF 主要依赖民用登记、旧军籍与缴获资料，第33舰队拥有自己的封闭数据库。

### 计算机比对

识别过程分三步：

- 特征提取：光学图像、雷达回波、红外特征、ELINT 信号分别提取外形、尺寸、反射、热源、信号特征。
- 数据库检索：计算机将特征与数据库条目比对，返回候选舰级、舰种、船厂、使用方与置信度。
- 融合判定：舰队融合节点综合多个传感器与历史航迹，给出 L3 分类；IFF/注册信息可进一步给出 L4。

降低置信度或导致误判的情况：

- 目标采用新涂装、低红外特征或伪装应答机；
- 目标进行标准改装，数据库只有原型船体数据；
- 目标处于光学遮蔽、强背景辐射或传感器损伤状态；
- 数据库版本落后，或目标不在数据库中；
- 敌方使用假目标、诱饵或信号伪装。

系统会显示分类结果与置信度。低置信度分类不等于确认；玩家应结合航迹、行为、通信与情报判断。

## 十一、GHOST TRACK：试作群与识别

### 定义与编制

GHOST TRACK 与舰级无关：它是第33舰队内部一个没有公开编制的标准改装试验群，测试新改装包、验证假旗与航迹擦除战法，也执行舰队不愿留名字的任务。官方文件里没有这个单位；舰队的解释是「传感器伪影」「残骸」「老毛病」。

编制与装备：

- 按 UEG 轨道舰队建造标准生产的新锐正规军事舰只；
- 安装有各类新锐测试装备；
- 应答机可关闭、可伪造；IFF 可能显示友军、平民或什么都不显示；
- 每艘舰有一个鸟类标志，舰只型号直接使用鸟名，已记录实例：Kestrel、Shrike、Owl、Harrier；鸟类标志不进入常规舰名/舷号系统；
- 散热与红外特征被刻意压低。

### 识别特征

GHOST TRACK 舰只采用 UEG 轨道舰队建造标准，但不在公开数据库中，且使用新型涂装与低可探测改装。

- L2：可定位，可获得尺寸与大致舰体特征，但舰种未知。
- L3：数据库无匹配条目；外形接近 UEG 舰只，但涂装、散热与传感器布局不符合任何已知舰级。系统返回「未知舰种」或低置信度候选。涂装为新型涂料，属独立涂装。
- L4：无 IFF 应答、无注册信息、无信号指纹匹配；无法确认具体身份。
- 行为：不辐射、不应答、只在探测边缘出现、出现后不作机动。

系统不给出「这就是 GHOST TRACK」的确认；玩家通过与流程中获得的情报匹配，推理出真实身份。

### 证据链

- 对 UEG 文书系统：OCUVF-ID13 是最新编制，不在 UEG 非法舰队名册上，在传感器/文书里是一条没有登记的航迹（GHOST TRACK）。
- 对玩家：第33舰队也有自己的 GHOST TRACK——内部黑单位/试作改装群。第一关的假旗痕迹是 EXPOSE 的证据链：Chronos 港务遥测 + UEG 核查组黑匣子 + 一条「任何厂商型号都对不上」的 ELINT 特征码；三件拿两件才能走 EXPOSE。L2-04 Argus 的光学阵列能拍到不像任何已知船的航迹；L4-08 Crucible（拆船/黑市）可能流出原型零件；L2-09 Silent（月背静默站）可能是其测试点。

Chronos 加注站爆炸、UEG 核查组失联是 Act 1 的起点。官方说法是火星分离主义破坏；真相是 GHOST TRACK 自导自演，用来测试新改装、制造接管借口。Act 1 不揭晓。玩家能拿到的只有：时间对不上、船对不上、爆炸前后的航迹记录对不上。GHOST TRACK 不显示为可选阵营或可点击单位：只在证据、无线电、日志、报告里出现。

### 设计规则

- GHOST TRACK 是一支试验部队：优势在欺骗与信息。
- 以流言和破译情报为信息：玩家通过殖民地之间流传的小道消息与监听 UEG 通信解密的密文拼凑真相。
- 它可以被部分识破：玩家能证明一支幽灵部队的存在，却不能证明它的归属。
- ID13 也是 GHOST TRACK：不在 UEG 名册上的志愿舰队，对 UEG 系统而言同样是一条无法归档的航迹。这是标题的双关，与身份揭露无关。

## 十三、民用船编号与识别

### 原则

- 民用船名可以重名；登记号与应答机码必须唯一。
- 军用、民用、设施三套编号不混用：军用舰名/舷号、民用登记号、设施码/应答机码各自独立。
- 空间站/储罐/OTC 用 `STN-/FUL-/TNK-/PRT-/OTC-/RLY-` 设施码；民船用登记体前缀。设施码详见第 2 章。
- 应答机码可被关闭、故障、俘获或伪造；无应答不等于敌意。
- 可见光灯语是最后手段：只在无线电/激光/红外失效时使用；只能发预定义短语与短码，不能传复杂内容。

### 编号域区分

| 域 | 格式 | 例 | 谁分配 | 说明 |
| --- | --- | --- | --- | --- |
| UEG 军用舰 | `UEGS` + 舰名 + 三位舷号 | `UEGS Waterloo` · 217 | UEGAF/海军登记处 | 正式舰名 |
| 第33 OSID 舰 | 类型前缀 + 四位登记号 | `AV-4412`、`CA-4471` | 第33舰队登记处 | 与文书号无关 |
| OCUVF 舰 | 舰名 + 三位舷号（或原厂名） | 哈马丹 114、APSIS 001 | OCUVF 登记/港群捐赠 | — |
| 民用船 | `[REG]-[TYPE]-[MODEL]-[SERIAL]-[CHK]` | `FRC-OW-CER2-0417-C` | 港群/合作社登记处 | 见下 |
| 固定设施 | `STN-/FUL-/TNK-/PRT-/OTC-/RLY-` + 区位 | `STN-L1-01`、`TNK-L1-05-03` | FacilityRegistry | 详见第 2 章 |
| 设施应答机 | `TP-` + 设施码 | `TP-STN-L1-01` | FacilityRegistry | 详见第 2 章 |

> `TP-` 设施码与船舶登记号分属两套体系；民用船登记号不写成 UEGS/OSID 格式。

### 民用船登记号

```
[REG]-[TYPE]-[MODEL]-[SERIAL]-[CHK]
```

| 字段 | 位宽 | 含义 | 例 |
| --- | --- | --- | --- |
| REG | 3 字母 | 登记体/登记港 | `FRC`（外环合作社）、`MER`（Meridian）、`ANV`（Anvil）、`KAR`（Karman）、`ALB`（Alborada）、`NLG`（New Lagos） |
| TYPE | 2 字母 | 船舶用途类型 | `OW` 作业船、`OV` 矿运船、`CV` 货船、`TK` 油船/补给船、`TG` 拖船、`SV` 测量/科考、`PV` 客船 |
| MODEL | 3–5 字母/数字 | 型号短码 | `CER2` = Ceres-2 / 谷神-2 型 |
| SERIAL | 4 位数字 | 登记序号 | `0417` |
| CHK | 1 字母 | 校验字符 | `C` |

- 示例：`FRC-OW-CER2-0417-C` = 外环合作社登记、作业船、谷神-2 型、序号 0417、校验 C。
- 登记号不复用；船体报废/失踪后号码封存，不重新分配。
- 船名是显示名，可与型号同名（如「谷神-2」）；正式文书以登记号为准。
- 校验采用简单字母校验（A–Z 对应序号/和）。

### 远地环带作业船

| 项 | 值 |
| --- | --- |
| 登记体 | 外环合作社 / Outer Ring Cooperative（`FRC`） |
| 常用类型 | `OW` 通用作业船；`OV` 矿运船；`TG` 拖船；`SV` 测量船 |
| 登记地 | 远地环带飞地（具体登记港 `FRC-01`） |
| 编号示例 | `FRC-OW-CER2-0417-C`；`FRC-OV-HEMA-0212-B`；`FRC-TG-CLMP-0034-A` |
| 特征 | 无军用 IFF；民用应答机；可关闭/故障；常挂应急灯语；船体小、可维修 |
| 军事冲突 | 不因民用登记自动判中立/敌意；身份仍由 L3/L4 与 ROE 决定 |

### 应答机码

- 民用应答机使用四位八进制码（0000–7777），由登记体/港群分配；与设施码、舰名、舷号无关。
- 常码由登记体分配；跨区飞行须向 UEG 海关/港务报备。
- 军用/政府船可用加密模式。
- 码段：`0001–0999` 港务/引航；`1000–4999` 民用作业/货运；`5000–6999` 商业客运/服务；`7000–7399` 试验/临时；`7500/7600/7700` 保留应急。

应急码：

| 码 | 含义 | 使用 |
| --- | --- | --- |
| `7500` | 非法干预/劫持 | 仅在实际发生非法干预时；游戏内可作为事件码 |
| `7600` | 无线电失效 | 谷神-2 的应急码；只能灯语/其他方式通信 |
| `7700` | 一般紧急 | 生命/结构/推进紧急；不等于敌对 |

谷神-2 使用 `7600`（无线电失效）；`7700` 留给一般紧急。

应答机状态：

| 状态 | 含义 | 识别后果 |
| --- | --- | --- |
| `normal` | 正常应答 | 可作 L4 证据 |
| `off` | 关闭 | 无有效应答 |
| `faulty` | 故障 | 无有效应答；谷神-2 |
| `captured` / `spoofed` | 被俘获/伪造 | 可返回伪造应答；身份未知/置信度降级 |
| `no_reply` | 不应答 | 未知；不自动判敌 |
| `wrong_code` / `expired` / `crypto_fail` | 错误/过期/加密失败 | 无有效应答 |

无应答 ≠ 敌意；L4 只提供身份证据，不自动产生 Hostile。

### 可见光灯语

- 可见光通道只能发送预定义短语/短码，不能传自由文本。
- 格式：`L#-####`，其中 `L#` 是短语码，`####` 是船舶登记序号或批号；每组重复 3 次。
- 示例：`L3-0417` = 「无线电失效，我是登记号 0417」。
- 灯语只在无线电/激光/红外均不可用时使用；速度以秒–分钟计，手动操作。

短语码：

| 码 | 含义 | 备注 |
| --- | --- | --- |
| `L1` | 收到/确认 | 最短应答 |
| `L2` | 请求通信/请求频道 | 需要对方建立链路 |
| `L3` | 无线电失效 | 谷神-2 主用 |
| `L4` | 请求救援/拖带 | 可与 L3 串联 |
| `L5` | 人员紧急撤离 | 最高优先级之一 |
| `L6` | 本船失控/失去动力 | 需要拖船 |

谷神-2 的灯语序列：`L3-0417` → `L4-0417` → 重复，表示「无线电失效，请求救援/拖带」。灯语不替代 IFF；身份仍由接触等级/ROE 判定。
