# 第 8 章 · 命名与术语

## 身份层

一艘船的身份由六层组成：

| 层 | 是什么 | 谁定 | 例 |
| --- | --- | --- | --- |
| 厂商型号 | 产品名 | 船厂 | 刺桐-2、龙门-3M、赤铁-6 改 |
| 舰级 / class | 编制/条令代号 | 舰队条令 | 托盘级、远地点级；第33舰队内部舰级 |
| 舰种 / type | 舰体规模与战术角色 | 舰队条令 | 战列舰 BB、重巡洋舰 CA、轻巡洋舰 CL、驱逐舰 DD、护卫舰 FF、通报舰 AV |
| 任务职能 / role | 当前任务的职能 | 特遣群/司令部 | 哨戒、护航、封锁、追击、追索、征用、送达 |
| 舰名 | 专名 | 登记处/命名委员会 | 远地点、哈马丹、背风岸 |
| 舷号 | 登记号 | 舰队登记处 | 001、114；第33舰队 3301、4471、4412 |

身份中没有「文书编号」这一层。

## 标准名与本地化

一艘船只有一个标准名，使用英文；其他语言均为本地化。

| English（标准） | 中文（本地化） | 日本語（本地化） |
| --- | --- | --- |
| APSIS | 远地点号 | アポジー |
| HARMATTAN | 哈马丹号 | ハルマッタン |
| LEE SHORE | 背风岸号 | リーショア |
| FERRY | 渡口号 | フェリー |
| DEEPWELL | 深井号 | 深井（しんせい） |
| WATCHTOWER | 望楼号 | ウォッチタワー |
| SUNSUMMONER | 传唤者 | 伝喚者（でんかんしゃ） |
| ANNIHILATOR | 湮没者 | 湮滅者（えんめつしゃ） |
| NO QUARTER | 无赦 | 無赦（むしゃ） |

日语本地化用汉语词，不用口语短语；念法用音读。「無赦（むしゃ）」是舰名，「容赦なし」是一句话。

船壳涂装使用英文标准名；本地化名用于各语言界面。UEG 与 OCU 的工作语言为英语；港群通行语还混有西班牙语、日语、中文与尼日利亚英语。

型号同理：刺桐-2 的国际型号为 ZAITON-2（刺桐是泉州古称，Zaiton 是其中世纪名称）；龙门-3M 为 GANTRY-3M；赤铁-6 为 HEMATITE-6。

## 厂商型号

型号名来自各厂的命名语法：

| 厂 | 语法 | 例 |
| --- | --- | --- |
| 泉州重工 | 港口与航路 | 刺桐、月港、安海、后渚 |
| 车肆重工 | 工具与物流 | 龙门、绞盘、锚链、托盘 |
| 永昼机械 | 矿物 | 赤铁、玄武、冰晶、云母 |
| 奥尔西尼 | 音乐术语 | 咏叹、夜曲、托卡塔 |
| 远环合作社 | 小行星 | 谷神、灶神、智神 |

型号后缀：

| 后缀 | 意思 |
| --- | --- |
| `-1` | 原型 |
| `-2` | 量产 |
| `-3` | 大改 |
| `M` | 军规 |
| `改` | 战地改装 |

「龙门-3M」：车肆的龙门级重货船，第三代，军规型。「赤铁-6 改」：永昼的赤铁级矿运船，第六代，战地改装，船坞自行加装火炮。

## 港群与站点命名

港群按拉格朗日点编号，名称来自不同语言与建站历史：

| 编号 | 港群 | 英文 | 实例 |
| --- | --- | --- | --- |
| L1 | 子午 | Meridian | Greenwich、Sextant、Chronos、Astrolabe |
| L2 | 卡门 | Karman | Janus、Argus、Horizon、Silent |
| L3 | 黎明 | Alborada | Aurora、Ceres、Dew、Demeter |
| L4 | 铁砧 | Anvil | Hammer、Vulcan、Crucible、Ingot |
| L5 | 新拉各斯 | New Lagos | Eko、Zuma、Savannah、Victoria |

站点编号格式为 `L<数字>-<两位站号>`，例如 `L1-05 Chronos`。跳号表示未命名小站或预留位，不另补。各站点职责与归属详见第 2 章。

## UEG 命名

UEG 联合轨道军舰船以地球城市、地区或历史地名命名，舰名前加 `UEGS`（United Earth Government Ship），舷号三位数。实例：`UEGS Greenwich`（舷号 017）、`UEGS Meridian`（舷号 042）、`UEGS Aurora`（舷号 088）。

UEG 海关与轨道管制船只使用 `UEGC` 前缀，舷号四位数，以职责或地名命名。

UEG 舰级按任务与吨位划定（护卫舰、驱逐舰、巡洋舰、战列舰），不套用港群型号；舰名取自地球城市、联邦州、历史战役与星座；舷号由舰队登记处统一编号，可带类型前缀；涂装为 UEG 白/灰，舰种代码与国籍标识完整。

## 第33舰队命名

第33舰队的舰级名称取自法律与强制行为，舰名取自行为后果，舷号为四位数。舰名是通告：

> 不取希望，只取后果。名字要告诉对方：接下来会发生什么。

| 舰级 | 舰种 | 代码 | 任务职能 | 实例 |
| --- | --- | --- | --- | --- |
| 清算级 | 战列舰 | BB | 清算 / 主力 | 清算级战列舰 终局，舷号 3301 |
| 执刑级 | 重巡洋舰 | CA | 执刑 / 旗舰 | 执刑级重巡洋舰 湮没者，舷号 4471 |
| 禁制级 | 轻巡洋舰 / 封锁巡洋舰 | CL | 禁制 | 禁制级轻巡洋舰 无赦，舷号 3312 |
| 追索级 | 驱逐舰 | DD | 追索 / 登舰 | 追索级驱逐舰 追索者，舷号 3327 |
| 征用级 | 护卫舰 / 回收舰 | FF | 征用 | 征用级护卫舰 征用者，舷号 3340 |
| 传唤级 | 通报舰（aviso） | AV | 传唤 / 送达 | 传唤级通报舰 传唤者，舷号 4412 |

单舰名分三个语域：

| 语域 | 例 |
| --- | --- |
| 施事者 | 裁夺者、究诘者、追索者、湮没者、抹除者、定谳者、荡除者、肃清者 |
| 不可动摇 | 不移、无赦、恒常、既定 |
| 权威 | 终局、铁律、定谳、既判 |

单舰全称示例：执刑级重巡洋舰，湮没者，舷号 4471。

## GHOST TRACK 命名

GHOST TRACK 舰只以鸟类命名，型号直接使用鸟名，每艘舰以鸟类为标志。实例：

- Kestrel（红隼）
- Shrike（伯劳）
- Owl（鸮）
- Harrier（鹞）
- Falcon（隼）

GHOST TRACK 舰只不进入常规识别链，舷号与舰级不对外公开。

## OCUVF / ID13 命名

船坞舰与补给舰以轨道要素命名：远地点号 APSIS（舷号 001）、近地点号 PERIGEE、交点号 NODE、停泊点号 PARKING、拱线号 APSIDES。战斗改装舰保留原民用船名，例如哈马丹、渡口、深井、望楼。

分遣群编号格式为 `OCUVF-ID<数字>`，实例 `OCUVF-ID13`。

大多数时候舰级就是型号：托盘级、赤铁级、龙门级。大幅改装时，舰队另给代号：

| 情况 | 舰级 | 例 |
| --- | --- | --- |
| 原样采购 | 型号即舰级 | 龙门级弹舱舰、托盘级哨舰 |
| 大幅改装 | 舰队另给代号 | 刺桐-2M → 远地点级 |

OCUVF 没有中央命名局。舰名来自港群捐赠者、旧名册、船员投票。ID13 沿用旧志愿舰队名册：

| 舰种 | 舰名系列 | 英文标准名 | 中文名 |
| --- | --- | --- | --- |
| 船坞舰、补给舰 | 轨道要素 | APSIS、PERIGEE、NODE、PARKING、APSIDES | 远地点、近地点、交点、停泊点、拱线 |
| 哨舰 | 天气 | HARMATTAN、LEE SHORE、DOLDRUMS、HOARFROST | 哈马丹、背风岸、无风带、白霜 |
| 炮舰 | 地形与关隘 | ANVIL、FERRY、CLIFF、SHOAL | 铁砧、渡口、断崖、浅滩 |
| 弹舱舰 | 火山 | VESUVIUS、KRAKATOA、ST HELENS | 维苏威、喀拉喀托、圣海伦 |
| 油船 | 水源 | DEEPWELL、SPRINGHEAD、UNDERFLOW | 深井、泉眼、暗河 |
| 中继舰 | 高塔与烽火 | WATCHTOWER、BEACON、LIGHTHOUSE | 望楼、烽燧、灯塔 |
| 拖船 | 工具 | BOLLARD、ANCHOR、TOWHOOK | 缆桩、铁锚、拖钩 |
| 舰载穿梭机 | 文书 | MISSIVE、SEALING WAX、BULLA | 信笺、火漆、封泥 |

## 舷号规则

OCUVF / ID13 舷号为三位数，按角色分段：

| 段 | 舰种 |
| --- | --- |
| 001–099 | 船坞舰、补给舰 |
| 100–199 | 哨舰 |
| 200–299 | 炮舰 |
| 300–399 | 弹舱舰 |
| 400–499 | 油船 |
| 500–599 | 中继舰 |
| 600–699 | 拖船 |
| 700–799 | 舰载穿梭机（旗舰载，不占舰队编制） |

- 远地点号：远地点级船坞舰首舰，泉州重工 刺桐-2M，舷号 001。
- 哈马丹号：托盘-5 改哨舰，车肆重工，舷号 114。

第33舰队舷号为四位登记号，类型代码是身份的一部分：

- 四位登记号按服役/接管顺序发放，不按舰种分段；
- 类型代码写在登记号前，如 `AV-4412`、`CA-4471`；只看数字会撞号，须连类型代码一起读；
- 同一艘船可能在涂装下保留旧登记号；识别时以当前登记号为准；
- 例：`AV-4412` 传唤者 / 通报舰；`CA-4471` 湮没者 / 重巡洋舰。

UEG 联合轨道军舰船舷号三位数，可带类型前缀，由舰队登记处统一编号；Act 1 出场舰船只使用「后渚-3」这类产品型号。

## 人名

地月系居民的人名来自多个语言与文化背景：

- 伊芙琳·索恩（Evelyn Thorne），UEG 中央安全委员会主席
- 阿德里安·沃尔科夫（Adrian Volkov），第33舰队司令
- 科尔（Cole），第33舰队接管官
- 阿米娜·哈桑（Amina Hassan），哈马丹号舰长
- 托马斯·里德（Thomas Reed），渡口号舰长

人名不按单一文化体系生成；同一艘船上出现不同语源的名字是常态。

### 通信与传感器

| 缩写 | 中文 | English | 延迟 | 备注 |
| --- | --- | --- | --- | --- |
| `LD` | 激光直连 | laser direct | 0.3–2 s | 主链路；需视线 |
