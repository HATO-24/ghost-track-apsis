# 部件型号命名重设计与拓展任务书

对象：`docs/settings/GHOST_TRACK_世界设定全书.md`。用户意见：部件型号命名太简单，不像是真实设备型号名，需要重新设计；同时对型号进行拓展，补上完整规格卡。

文风红线照旧（无「不是……而是……」；无元信息；推定标「（推定）」；不发明与既有设定冲突的专名——本任务书允许按方案发明**型号编号**，因为这是用户要求的重新设计）。

## 一、新命名体系（全表执行）

格式：`厂商前缀-三位类别码-变型字母`，另配汉字通称「厂商名 类别 型号」。
类别码：0xx 材料与结构（装甲/壳）；1xx 反应堆与动力；2xx 发动机；3xx 红外；4xx 雷达；5xx 光学与测距；6xx 火控；7xx 通信与电子战；8xx 散热；9xx 武器（910 近防 / 920 导弹 / 930 轨道炮 / 940 大型导弹）。

## 二、全局替换范围

1. 第 4 章部件目录：所有型号单元格换新码，并加「通称」列（如「北岭 190 型反应堆」）。
2. 第 6 章规格卡「设备」清单中的型号（YW-490A、MS-520A、CH-320B、CH-700B、LR-4→MS-540A 等）同步替换。
3. 第 7 章各条目「型号」行同步替换，并在条目里保留新旧对照一句？不——不留旧名，直接新名；第 7 章条目内其他文字中出现的旧型号也替换。
4. 第 9 章军语表中若引用型号（如 YW-R9 雷达暴露示例）同步替换。
5. 全书搜索旧型号字符串（NR-9、SC-4、QH-12、VA-3、FR-2、NR-N1、SC-N3、QH-N2、OA-C1、MS-IR9、NO-IR7、YW-IR5、CH-IR2、YW-R9、KD-R6、MS-R4、SC-R2、MS-OT2、LR-4、YW-F7、KD-F5、MS-F3、CH-F1、MS-L2、YW-L1、CH-R0、YW-E3、MS-E1、CH-E0、NT-3、WT-5、CH-2、HT-8、BY-2、HV-6、FR-1、TZ-K30、QH-K20、FR-K40、TZ-C30、LS-C20、CH-C15、CF-H4、TZ-H2、LS-H1）确保零残留（除任务书对照表本身不写入文档）。

## 三、型号拓展

每个类别至少补 1–2 个新型号（制造商与类别段一致，变型字母与序列号不与现有冲突），例如：反应堆加 VA-131A、NRA-191B；雷达加 YW-491A；近防加 TZ-910B；导弹加 CF-941A、LS-921B；散热加 NT-831A；装甲加 HT-081B。新增型号参数按既有同类梯度合理推定，全部标「（推定）」。

## 四、完整规格卡

第 4 章部件目录每个型号从现在的单行表改为「#### 型号 · 通称」小节卡：

```
#### NRA-190A · 北岭 190 型反应堆

| 项 | 值 |
| --- | --- |
| 厂商 | 北岭原子（Northridge Atomics） |
| 类别 | 反应堆 |
| 规格 | 2 |
| 输出 | 8 MW |
| 强项 | 满推不衰减，寿命长 |
| 弱项 | 重，维修要回泉州 |
| 价格档 | 高 |
| 适配 | 中大型舰（推定） |
```

保留原有每型号的全部事实（输出/距离/射速/Δv 等），不压缩；新增字段（适配等）标「（推定）」。三套典型配置、标准化 vs 优化等节中的型号引用同步换新码。
