## 二、删除清单（任何章节通用）

1. 所有「状态/依据/来源/变更记录/待拍板/待定/待裁决/待用户核对/相关文档/重写范围/第二阶段迭代补丁」区块，以及编号条目（W-xx、T-xx、S-xx、I-xx、R-xx、T1-xx、CF-xx、A1–A6 等）和「提案/暂定/TBD/待核对」标注。事实保留，标注删除。
2. 所有「数据接口/JSON/schema/API 清单/headless 测试/实现接口/教学/UI 审计/写作检查表/作者侧」内容。
3. 文档自述与自我标注：「本文只描述……」「本章只列……不讨论……」「这条分层不是为了……」「以上/以下」等。
4. 汇编头部与尾部的「细调记录」「附录 A/B/C」（冲突台账、S04 快照、完整性清单）不属于任何章，不复制。

## 三、文风规则（必守）

1. 删掉所有「不是……而是……」句式（含「并非……而是……」），改写为直接陈述。
2. 删掉元信息、自我标注、脚手架（见删除清单 3）。
3. 删掉「第一条……第二条……第三条……」式机械列举：改为小节标题或自然段；纯清单可保留 `-` 列表，但去掉「第 X 条」引导与每条的重复性解释。
4. 删掉过度解释：结论已明示的不再复述；删除同义反复段落与「换句话说」式补充。
5. **事实零丢失**：名称、数字、日期、参数、机制表述、表格数据全部保留。只删上述四类，不缩写事实。
6. 语气：克制、制式、信息密度高。不用感叹句，不抒情，不写「没有人意识到」这类悬念腔（如已存在可改写为直陈或删去）。
7. 不发明新设定，不补新数字，不改专名（UEG、OCUVF、ID13、Reclaimers、GHOST TRACK、港群名、舰级名等原样保留）。
8. 同一事实在多来源重复时，保留最完整的一版并合并细节，其余删除；属其他章分工的事实删除，最多留一句「（详见第 X 章）」——章节标题见分工表。

## 四、跨章归属（去重裁决，必须遵守）

- 港群与站点的完整定义、站点表、设施码、事故表 → **C02** 独家；其他章只允许简称加指引。
- 舰级、舷号、命名规则、命名池 → **C08** 独家；C06 保留舰种表（含参数）与识别流程，不重复命名规则详表。
- 传感器与武器的参数、原理 → **C07** 独家；C06/C09 不重复。
- 术语表 → 由 **C08** 收为章末「术语索引」，只收未被正文覆盖的词条，与正文重复的词条删除。
- 人物 → **C05** 独家；其他章出现人物只留姓名与一句职能。
- 时间线 → **C01** 独家；48 的事故表日期并入 C02 的事故表，不另建时间线。
