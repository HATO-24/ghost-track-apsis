# 49 · 民用船编号与识别（提案）

> 状态：**用户复核通过（2026-10-21）；仅 N7 校验算法延后**。只新增本文，不覆盖 legacy 编号/识别规则。
> 目的：区分军用、民用、设施编号；给出民用船登记号、远地环带作业船编号、应答机码与可见光灯语；给出 **Ceres-2（谷神-2）** 的完整编号建议。

## 0　原则

1. **编号是身份，名字不是。** 民用船名可以重名；登记号/应答机码必须唯一。
2. **军用、民用、设施三套编号不混用。** 军用舰名/舷号、民用登记号、设施码/应答机码各自独立。
3. **设施码不等于船舶登记号。** 空间站/储罐/OTC 用 `STN-/FUL-/TNK-/PRT-/OTC-/RLY-`；民船用登记体前缀。
4. **应答机码不是身份密码。** 可关闭、故障、被俘获/伪造；无应答不等于敌意（42 §14.3）。
5. **可见光灯语是最后手段。** 只在无线电/激光/红外失效时使用；只能发预定义短语与短码，不能传复杂内容。
6. **不覆盖 legacy**：20 §6.2 的设施码、42 §14 的应答机状态、43 B 的谷神-2 现有实体不改；本文只补民用编号层。

## 1　编号域区分

| 域 | 格式 | 例 | 谁分配 | 说明 |
| --- | --- | --- | --- | --- |
| UEG 军用舰 | `UEGS` + 舰名 + 三位舷号 | `UEGS Waterloo` · 217 | UEGAF/海军登记处 | 03 §8.2；正式舰名 |
| 第33 OSID 舰 | 类型前缀 + 四位登记号 | `AV-4412`、`CA-4471` | 第33舰队登记处 | 04 §12.6；不是文书号 |
| OCUVF 舰 | 舰名 + 三位舷号（或原厂名） | 哈马丹 114、APSIS 001 | OCUVF 登记/港群捐赠 | 04 §12.7 |
| 民用船 | `[REG]-[TYPE]-[MODEL]-[SERIAL]-[CHK]` | `FRC-OW-CER2-0417-C` | 港群/合作社登记处 | 本文 §2 |
| 固定设施 | `STN-/FUL-/TNK-/PRT-/OTC-/RLY-` + 区位 | `STN-L1-01`、`TNK-L1-05-03` | FacilityRegistry | 20 §6.2 |
| 设施应答机 | `TP-` + 设施码 | `TP-STN-L1-01` | FacilityRegistry | 20 §6.2；不是船舶码 |

> 不要把 `TP-` 设施码当作船舶登记号；也不要把民用船登记号写成 UEGS/OSID 格式。

## 2　民用船登记号

### 2.1 格式

```text
[REG]-[TYPE]-[MODEL]-[SERIAL]-[CHK]
```

| 字段 | 位宽 | 含义 | 例 |
| --- | --- | --- | --- |
| REG | 3 字母 | 登记体/登记港 | `FRC`（外环合作社）、`MER`（Meridian）、`ANV`（Anvil）、`KAR`（Karman）、`ALB`（Alborada）、`NLG`（New Lagos） |
| TYPE | 2 字母 | 船舶用途类型 | `OW` 作业船、`OV` 矿运船、`CV` 货船、`TK` 油船/补给船、`TG` 拖船、`SV` 测量/科考、`PV` 客船 |
| MODEL | 3–5 字母/数字 | 型号短码 | `CER2` = Ceres-2 / 谷神-2 型 |
| SERIAL | 4 位数字 | 登记序号 | `0417` |
| CHK | 1 字母 | 校验字符（提案） | `C` |

- 示例：`FRC-OW-CER2-0417-C` = 外环合作社登记、作业船、谷神-2 型、序号 0417、校验 C。
- 登记号**不复用**；船体报废/失踪后号码封存，不重新分配。
- 船名是显示名，可与型号同名（如“谷神-2”）；正式文书以登记号为准。
- 校验算法：简单字母校验（A–Z 对应序号/和）已接受为方向；具体算法 N7 延后，后续与登记/应答/交通系统整合实现完整闭环。

### 2.2 远地环带作业船

| 项 | 提案 |
| --- | --- |
| 登记体 | 外环合作社 / Outer Ring Cooperative（`FRC`） |
| 常用类型 | `OW` 通用作业船；`OV` 矿运船；`TG` 拖船；`SV` 测量船 |
| 登记地 | 远地环带飞地（具体登记港 `FRC-01`，提案） |
| 编号示例 | `FRC-OW-CER2-0417-C`；`FRC-OV-HEMA-0212-B`；`FRC-TG-CLMP-0034-A` |
| 特征 | 无军用 IFF；民用应答机；可关闭/故障；常挂应急灯语；船体小、可维修 |
| 军事冲突 | 不因民用登记自动判中立/敌意；身份仍由 L3/L4 与 ROE 决定 |

## 3　应答机码

### 3.1 分配

- 民用应答机使用 **四位八进制码**（0000–7777），由登记体/港群分配；与设施码、舰名、舷号无关。
- 常码由登记体分配；跨区飞行须向 UEG 海关/港务报备（提案）。
- 军用/政府船可用加密模式；本文不展开军用应答机加密。
- 码段建议（提案）：`0001–0999` 港务/引航；`1000–4999` 民用作业/货运；`5000–6999` 商业客运/服务；`7000–7399` 试验/临时；`7500/7600/7700` 保留应急。

### 3.2 应急码（提案；游戏化抽象）

| 码 | 含义 | 使用 |
| --- | --- | --- |
| `7500` | 非法干预/劫持 | 仅在实际发生非法干预时；游戏内可作为事件码 |
| `7600` | 无线电失效 | **谷神-2 的提案应急码**；只能灯语/其他方式通信 |
| `7700` | 一般紧急 | 生命/结构/推进紧急；不等于敌对 |

> 现有 demo 文本/43 曾用 `7700` 作演示码；本文建议谷神-2 用 `7600`（无线电失效），`7700` 留给一般紧急。**以用户最终核对为准**。

### 3.3 状态

沿用 42 §14.3：

| 状态 | 含义 | 识别后果 |
| --- | --- | --- |
| `normal` | 正常应答 | 可作 L4 证据 |
| `off` | 关闭 | 无有效应答 |
| `faulty` | 故障 | 无有效应答；谷神-2 |
| `captured` / `spoofed` | 被俘获/伪造 | 可返回伪造应答；身份未知/置信度降级 |
| `no_reply` | 不应答 | 未知；不自动判敌 |
| `wrong_code` / `expired` / `crypto_fail` | 错误/过期/加密失败 | 无有效应答 |

> 无应答 ≠ 敌意；L4 只给身份证据，不自动产生 Hostile（42 §15.3；19 §2.5）。

## 4　可见光灯语

### 4.1 格式

- 可见光通道只能发送**预定义短语/短码**，不能传自由文本。
- 提案格式：`L#-####`，其中 `L#` 是短语码，`####` 是船舶登记序号或批号；每组重复 3 次。
- 示例：`L3-0417` = “无线电失效，我是登记号 0417”。
- 灯语只在无线电/激光/红外均不可用时使用；速度以秒–分钟计，手动操作。

### 4.2 短语码（提案）

| 码 | 含义 | 备注 |
| --- | --- | --- |
| `L1` | 收到/确认 | 最短应答 |
| `L2` | 请求通信/请求频道 | 需要对方建立链路 |
| `L3` | 无线电失效 | 谷神-2 主用 |
| `L4` | 请求救援/拖带 | 可与 L3 串联 |
| `L5` | 人员紧急撤离 | 最高优先级之一 |
| `L6` | 本船失控/失去动力 | 需要拖船 |

- 谷神-2 的提案灯语序列：`L3-0417` → `L4-0417` → 重复；表示“无线电失效，请求救援/拖带”。
- 灯语不替代 IFF；不能因为灯语显示 L4 就判友/敌；身份仍由接触等级/ROE 判定。
