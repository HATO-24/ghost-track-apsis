### 3.2　舰名：一个标准名，多个本地化

```
name_en（标准） → name_local { zh, ja, ja_kana, ... }
```

| English | 中文 | 日本語 | 読み |
| --- | --- | --- | --- |
| APSIS | 远地点号 | アポジー | — |
| HARMATTAN | 哈马丹号 | ハルマッタン | — |

## 10　自检五问

接手前先答这五个，答不上就回去读：

1. 永昼在三种语言里分别叫什么？为什么不是音译？
2. 清算署为什么可预测？它的死穴是什么？
3. 炮舰为什么不是战列舰？给出那个数字。
4. 为什么舰名标准名是英文，而不是中文？
5. 「册民」还能用吗？「下界」呢？

<details>
<summary>答案</summary>

1. 永昼 / Solstice / 常世。三种语言各自命名：太阳不落 / 太阳停住 / 回不去的国度。
2. 它按程序（通告→宽限→执行→回执），程序瑕疵会让裁定失效，所以不能改期；死穴是它不能违法。
3. 目标 0.1 g 侧向机动，飞行十秒位移五十米；6 km/s 弹速对应 60 km。它只能打不会躲的东西。
4. 公约舰队是四国联军，工作语言是英语；船壳刷英文，UI 本地化。
5. 都不能。「册民」已删，法律语境用「在册抵押人员」；「下界」已改「原乡 / 地上」。

</details>
