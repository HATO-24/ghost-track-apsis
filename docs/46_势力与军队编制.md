## 1　UEG 高层与军种链条

### 1.1　决策链

```text
地球联合政府（UEG）
├─ 联邦总统
├─ 联邦议会（预算、授权、宣战/紧急状态相关程序）
├─ 中央安全委员会（鹰派；第七号令与第33舰队的政治靠山）
├─ 轨道事务委员会（鸽派/自治派；复核第七号令）
└─ 联合轨道军（UEG Joint Orbital Force，军种总称；03 §4.1）
   ├─ UEGAF（UEG Aerospace Force，空天军；提案全称）
   │  └─ UEGAF-ORBFLT（UEG Aerospace Force Orbital Fleet，轨道舰队）
   │     ├─ 轨道巡逻与守备部队
   │     ├─ NESOSS 近地同步轨道站群守备与交通管制
   │     └─ 轨道管制/海关支援单位
   ├─ UEOF（UEG Expeditionary Orbital Force，远征轨道部队；提案全称，待核）
   │  ├─ 第7舰队（UEOF 地球圈方向）
   │  └─ 第三远征舰队（UEOF 火星方向）
   └─ 第33轨道特别独立舰队（UEG 33rd OSID）
      └─ 名义隶属 UEG 轨道司令部，实际向中央安全委员会与舰队司令部负责
```

- **UEGAF** 是空天军军种；**UEGAF-ORBFLT** 是其在近地/地月方向的轨道舰队。03 使用“联合轨道军”作为总称；本文不把“联合轨道军”改名为 UEGAF，只在编制上区分“军种”与“舰队”。
- **UEOF** 的全称在 42/44 中只出现缩写；本文提案为 *UEG Expeditionary Orbital Force*，**待用户核对**。42 明确副官出身“UEOF 地球圈方面第7舰队”（`42:L66`），44 明确前任出身“UEOF 第三远征舰队（火星方向）”（`44:L59`）。
- **第33 OSID** 不在 UEOF 战斗序列内；它由中央安全委员会推动设立，拥有独立征用、军法与接管程序（03 §4.2；44:L19–L20）。

## 3　OCU / OCJC / OCUVF / ID13 编制

### 3.1　OCJC

| 机构 | 职能 | 备注 |
| --- | --- | --- |
| 轨道殖民地联合议会（OCJC） | 五个港群 + 月面自治代表；票决；没有合法常备军 | 03 §4.3 |
| 安全与防务委员会 | 审议 OCUVF 授权、ROE、紧急状态 | 提案；名称待核 |
| 港群席位 | L1 Meridian、L2 Karman、L3 Alborada、L4 Anvil、L5 New Lagos | 20 §1 |
| 观察员 | 月面自治代表、远地环带观察员 | 提案 |
| 监察/审计 | 调查 OCUVF 报告与违纪 | 08 §4.4 |

- OCJC 不是主权政府；不能征税、不能强制各港群出兵；对 OCUVF 的授权是逐案、可撤回的。
- OCJC 的“军令”本质是**决议 + 授权**；OCUVF 各分遣群可自行决定执行程度（03 §4.3、§6.4）。

### 3.2　OCUVF

| 层级 | 提案 |
| --- | --- |
| 最高 | OCUVF 本部（志愿舰队司令部；OCJC 授权下） |
| 分遣群 | ID1–ID13（至少 13 个）；ID13 为最新编制，独立行动权最高 |
| 舰群 | 各分遣群下辖舰只；无统一舰级，按采购/改装/征用登记 |
| 后勤 | 各港群赞助 + OCJC 缴款 + 商业收入；无统一军费 |
| 兵源 | UEG 退伍人员、港群志愿者、反清算者/反 UEG 人士；混编、立场流动 |

**ID13 编制提案：**

```text
OCUVF-ID13 指挥官（玩家）
├─ 副指挥官/副官（前 UEOF 第7舰队；见 47）
├─ 作战与航行组（航线、变轨、命令队列）
├─ 传感器与情报组（哈马丹 AWACS、ELINT、目标识别）
├─ 通信与中继组（望楼号、链路管理）
├─ 工程与损管组（APSIS 船坞、维修、拖带）
├─ 后勤与补给组（深井号、港群采购）
├─ 医疗组（APSIS 医院）
├─ 记录/报告组（内部事后报告、证据归档）
└─ 舰只：APSIS（1000）、哈马丹（1001）、渡口（1002）、望楼（1003）、深井（1004）
```

- ID13 的“独立行动权”来自 OCU 特别安全会议票决；同时被授予轨道通行特权、UEG 海关特赦权（尚在商榷）与特别火力授权（44:L59）；具体权限边界见 07/08。
- ID13 对外伪装为普通 OCUCF 性质；OCUCF 的正式全称/编制**TBD**（44:L63）。
- ID13 不在 UEG 非法舰队名册上；对 UEG 系统是一条 GHOST TRACK（03 §4.3、04 §10）。

### 3.3　OCU 与港群

- OCU 是自治港群的政治联合，不是国家，也不是军队（03 §4.3）。
- 港务委员会负责港口、航道、引航、补给与本地安保；不是 OCUVF 的上级。
- 各港群对 OCUVF 的支援按合同/政治关系处理，不构成统一后勤。
