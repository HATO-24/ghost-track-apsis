状态：**设计补充与 DeepSeek 实施卡草案，未实机验收**。设计方向取自 [Astra 评审](../Astra_产品玩法与复古终端评审.md) §4，接续 [60 UI 规范](../../../60_Astra_UI与文案设计规范_交Sol.md)、[61 实施队列](https://github.com/HATO-24/ghost-track-apsis/blob/4e75897ed32f8245f35c5ec584f0ec912ec919c6/docs/61_UI%E6%96%87%E6%A1%88%E5%8F%B0%E8%B4%A6%E4%B8%8E%E5%AE%9E%E6%96%BD%E9%98%9F%E5%88%97.md) 的 UI-01～04，不建立第二套视觉总规范。参考《异形：夺命舰》的是**设备用途、年代、内容和操作的一致性**；APSIS 采用“在役轨道舰队的工业战术工作站”身份，不直接照搬影片资产、布局或屏幕故障。

## 2. 先交同一战术样页的两个版本

用一份固定数据与固定布局制作 `清晰版` 和 `屏幕效果版`，覆盖常规巡航、目标选中、战斗告警、失联／过期情报、友军请求受阻；后两项在尚无真实 B2 运行接口时必须醒目标“设计样页／数据示意”。清晰版关掉全部屏幕效果仍应一眼找到目标、对象、风险、动作、命令阶段和受阻原因。效果版只改变材质，不改变数据有效性或阅读顺序。

两版都以 1920×1080、1600×900 和约定 UI 缩放检查实际字体、混排、长舰名、告警密度、选中态、鼠标命中与键盘焦点。60 的 14–16px 主信息、12–14px 次要信息只是首轮有效可见尺寸建议，不能代替实测。若清晰版不成立，先调整图形层级；若效果版降低识别速度，回调效果。正式通过需真实入口截图和人工阅读记录，不能用 shader 存在或 headless 成功替代。

## 3. 给 DeepSeek 的实施卡草案

### VIS-01｜正式 HUD 屏幕材质最小切片（接 UI-02／UI-03）

**前置：** Astra／Sol 审清晰版与效果版样页；确认正式入口与影响层；记录新的实现基线和共享 HUD 文件归属。`orbital_sim` 的真实入口是必测路径；沿用旧 `main.gd` 效果前，逐项检查 shader 的渲染尺寸、层级与输入命中。

**实现范围：** 在正式 `v1_hud.tscn` 路径提供可关闭的轻量屏幕效果；主战术矢量、光学视频和正文可分别选择效果强度，正文及紧急警报优先清晰。旧 shader 可以复用经验证的部分，但不把 1080 固定扫描频率、全屏 RGB 色散、随机闪烁作为默认；若要短余辉／亮部扩散，须明确独立实现与性能代价。设置中提供减弱／关闭动态或屏幕效果的可达选项。预览数据仍标预览，材质不能改变情报权限或命令状态。

**验收：** 同一数据的开／关对照图；正式 `orbital_sim` 入口截图；上述三组分辨率／缩放、人眼阅读、焦点／命中、文字基线和状态样张；检查屏幕效果关闭仍有完整语义，开启不遮蔽关键告警、不造成虚假可选航迹；记录性能测量与平台。提交 SHA、设置状态、截图来源和未覆盖边界写进报告。此卡是**草案**，未发布或实施。

### UI-01／UI-03 补项｜状态与动效对应表

Sol 在既有 [文案清单](https://github.com/HATO-24/ghost-track-apsis/blob/4e75897ed32f8245f35c5ec584f0ec912ec919c6/docs/ui/20261027/copy_inventory.md) 与 [术语表](https://github.com/HATO-24/ghost-track-apsis/blob/4e75897ed32f8245f35c5ec584f0ec912ec919c6/docs/ui/20261027/glossary.md) 旁增一列“触发事件／允许的视觉或声音反馈／减少动态时的替代”。`已发送、已送达、已接受、执行中、已完成、已拒绝、失败`不能用同一成功闪烁；`未知、尚未收到、过期、不可用`不能用屏幕噪声糊过去。DeepSeek 仅按真实运行状态接映射，常态更新不重复弹窗、不给静态预览伪装战况。

### UI-04 补项｜联合战役的空间占用

编制与战报可为独立整页；交战中的火控、传感与协同详情在稳定侧区或按需展开，中央态势始终可读。友军受阻状态要显示请求阶段、最后已知报告时间与真实拒绝或失联原因；尚无 B2 接口的样页继续标为设计，不提前实现假回执。

## 4. 审校责任

Astra 核对设备身份、视觉取舍和“影片参考→APSIS 规则”的边界；Sol 维护 60/61、样页及文案／动效映射；DeepSeek 实现获批准的卡并提交真实入口证据。屏幕材质不修改传感器、通信、权限或 AI 的业务契约。
