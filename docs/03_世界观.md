## 1　我们向 Highfleet 借什么

### 1.1　它真正的三根柱子

| 柱子 | Highfleet 怎么做 | 为什么有效 |
| --- | --- | --- |
| **探测即战略** | 雷达开机就暴露，关机就瞎；ELINT 决定你走哪条路 | 把"看见"变成一种**要付费的行为** |
| **舰队是一笔会破产的资产** | 燃料、弹药、维修、奖金；打一场仗常常是亏的 | 让"避免交战"成为主要玩法 |
| **制度用声音建立** | 无线电里的头衔、通报、命令；你服从一个从未见过的机构 | 用文书和口音建世界，比用 CG 便宜，也比用 CG 可信 |

### 1.2　一处必须先说清的误读

Highfleet 的"真实"**不是技术真实**，是**制度真实**：补给会耗尽、命令会迟到、债务会到期、上级会失联。

> 所以我们不抄它的物理，也不抄它的美术。**我们抄它的账本。**

如果照搬它的表层，会得到"太空里的二战"——飞艇换成飞船，别的什么都不变。那是错的，因为我们的物理是真的。物理真了，设定就必须付得起物理的账。

### 1.3　太空歌剧的尺度从哪里来

不是从星系来。地月空间有四十万公里、六公里每秒的重力井、以周计的航程。只要**时间和代价是真的**，宿命感就成立。

> 歌剧感来自"个人被卷进比自己大的东西"，而"比自己大的东西"在近未来只有一个合理答案：**制度**。

## 2　世界的物理前提：沙漠就是 Δv 地图

### 2.1　一笔算得出来的账

按 02 的推进数据，一艘 1000 吨干重、带 300 吨燃料的核热舰，Δv 约 **2.3 km/s**。而地月空间的价目表是：

| 机动 | Δv（约） |
| --- | --- |
| 地球表面 → 低轨 | 9.4 km/s |
| 低轨 → 地月转移 | 3.1 km/s |
| 地月转移 → 环月 | 0.9 km/s |
| 环月 → 月面 | 1.8 km/s |
| 月面 → 环月 | 1.9 km/s |
| 环月 → 返回地球 | 0.8 km/s |
| 低轨 → 地球同步轨道 | 3.9 km/s |

**结论一：一艘战舰加满油，只够做一次大机动，然后必须找地方加注。** 它不能"去月球打一仗再回来"。

**结论二：没有一艘战舰曾经降落过。** 它们没有起落架，没有气动外形，从出生到拆解都在轨道上。这直接决定美术：**纯功能外形，没有任何为了好看而存在的曲面。**

**结论三：地球的舰队每一次出动都是一次国家级开支。** 爬重力井太贵，所以地球打仗靠"到位"而不是"机动"——先占住，再谈。

### 2.2　于是地图长这样

| Highfleet | 我们 | 说明 |
| --- | --- | --- |
| 沙漠 | Δv 预算 | 你穿过的不是空间，是燃料 |
| 城市 | 加注站 + 船坞 + 法庭 | 三位一体：加油的地方，也是打官司的地方 |
| 公里数 | Δv 数 | 同样两百公里，顺行和逆行差一个数量级 |
| 燃料 | 月冰制推进剂 | 唯一的战略物资 |
| 雷达 / ELINT | 主动雷达 / 被动红外 / 通信截听 | 见 05 |
| 商队 | 定期货运航班 | 按 Hohmann 窗口发车，错过一班等三周 |
| 废墟 | 废弃轨道设施 | 上一轮泡沫留下的站、坞、坟 |

> **所有的政治，都是加油站的产权纠纷。**

## 3　历史：四个时刻

### 2049　涌潮

可复用重载成熟，月极冰探明并商业化。轨道经济起飞：太阳能电站、零重力材料、数据中心的散热外包、在轨加注。地球资本把 cislunar 当成新殖民地开发，合同期限七十年，利息按轨道周期结算。

### 2061　大违约

轨道资产的现金流断了。地球各国拒付担保，承建的联营体连环破产，清算程序启动。

问题在于：资产在轨道上，债权在地球上，**没有一部法律同时管得了两者**。于是有了那条后来被写进所有教科书、也被所有人诅咒的条款：

> 抵押物在轨，计息周期随抵押物。**每轨道周期计息 0.05%。**

一年五千七百圈，年化十七倍。这笔债从签字那天起就不可能还清。所有人都知道，但没有人敢说。**债务的意义从来不是被偿还，而是被继承。**

清算程序里最不体面的一项：破产联营体的在轨雇员，其劳动合同被作为资产一并处置。生在站上、长在站上、从未去过地球的人，在法律上是**抵押物的一部分**。

### 2071　标高公约

打不动了，也还不起。各方签《标高公约》，把 cislunar 划成管辖区，把清算程序"临时"托管给一个常设机构，等债务问题解决后撤销。

「标高」是测量学术语：人为选定的基准面。公约以此为名，意思是——**我们把天定成了平的。**

那个"临时"机构，就是后来的清算署。临时了十七年，没有一个人再提撤销。

### 2087　冰裁定

永昼的 A-3 井探明一处远超预估的冰层。清算署随即发布《第七号裁定》：月面南极采冰区为编号 7-031 的抵押物，依公约第九条附则予以接管。永昼租界拒绝。天市没有月冰就活不过下一个窗口。签约国需要一次"债务有进展"的胜利。外权地切断金属供应。

**战争在四十八小时内开始，没有一枪是"宣战"之后开的。**

## 4　当代格局：五个权力体

| 权力体 | 物质基础 | 合法性神话 | 军事风格 | 致命弱点 |
| --- | --- | --- | --- | --- |
| **签约国**（地球） | 人口、资本、发射场、法律 | 「我们建了这一切」 | 远征舰队，重甲，程序化，怕伤亡 | 爬井贵；国内政治一碰就碎 |
| **永昼租界**（月南） | 冰、质量驱动器、地热 | 「我们签了合同」 | 固定防御、抛射体、少量舰 | 不能跑。它是固定目标 |
| **天市**（环站群） | 船坞、制造、数据、黑市 | 「我们不隶属于任何人」 | 改装船、电子战、蜂群 | 没有纵深。站不能弃 |
| **外权地**（小行星带） | 金属、挥发物、距离 | 「我们是被留下的那些人」 | 远程、粗野、自制 | 太远。赶到时战争已结束 |
| **清算署**（同步轨道） | 债权、托管账户、没收的船坞 | 「我们只是在执行判决」 | 标准化、程序化、数量 | **不能违反自己的程序** |

### 4.1　签约国

不是一个国家，是一组债权人国家的合称。它们的舰队很好，好到不舍得用；军官很守规矩，守到不会赢。

### 4.2　永昼租界

公司城。合同就是宪法，矿工就是市民，董事会就是法院。它不要求独立，只要求**履约**——这是它最要命的地方：它的诉求在法律上比对手更干净。

城市叫「永昼」，因为它建在南极环缘的永久光照带上：太阳绕着地平线转，从不落下。英文叫 **Solstice**（太阳停住），日文叫 **常世**（回不去的国度）。冰在脚下——永久阴影里，永远不化的坑底。

> **永昼的人，靠永夜的冰活着。**

### 4.3　天市

拉格朗日点上的城市联邦，名字取自中国古代星官「天市垣」——天上的市场。四个行政区，按点编号：

| 区 | 点 | 主要功能 | 首邑 |
| --- | --- | --- | --- |
| 环一 | L1 | 门户、海关、加注 | 斛 |
| 环二 | L2 | 船坞、重工业 | 车肆 |
| 环三 | L4 | 人口、行政、金融 | 市楼 |
| 环四 | L5 | 精密制造、数据 | 帛度 |

它是这个体系里唯一真心相信"谁都不该拥有天空"的一方，也是唯一靠黑市养活自己的一方。

### 4.4　外权地

小行星带。它在这场战争里的角色是：卖金属给两边，然后看着两边把金属打成废铁再卖一次。它的舰队不在战场上，它的**账单**在。

### 4.5　清算署

见 §8。它不是第五个权力体，它是前四个的共同前提。

## 5　战争为什么打起来

不是仇恨，是一份**格式正确的通知**。因果链只有八步：

| # | 环节 | 内容 |
| --- | --- | --- |
| 1 | 债 | 每圈 0.05%，年化十七倍。从签字起就还不清 |
| 2 | 职 | 清算署的法定职责不是讨债，是**变现抵押物**。十七年来一次一个站，慢慢做 |
| 3 | 触发 | 2087 年，永昼 A-3 井探明大冰层——这是最后一笔没有设定抵押的战略资产 |
| 4 | 裁定 | 第七号裁定：采冰区为抵押物 7-031，予以接管。法律依据是公约自己的第九条附则 |
| 5 | 签约国为何不阻止 | ① 它们的债也在清算署账上，阻止等于自证违约；② 地球轨道经济要冰，清算署承诺按配额分配；③ 它们怕清算署——今天能没收月亮，明天就能没收它们；④ 国内需要一次"债务有进展"的胜利 |
| 6 | 永昼为何不交 | ① 冰是它的全部经济；② 租约早于债务，**在法律上它是对的** |
| 7 | 天市为何卷入 | 月冰断供，环站推进剂储备撑不过一个窗口（约三周）。它没有选择 |
| 8 | 公约舰队为何在场 | 第九条附则规定"为确保裁定之执行与推进剂之自由流通"，联合参谋部得派员监督交接 |

**所以玩家接到的任务，本质上是"让这件事不发生枪战"。** 因为一旦开火，债市崩盘，公约先死。

## 6　公约舰队是什么

这是最容易搞混的一点，单列一节。

### 6.1　它不属于签约国

| | 是什么 | 听谁的 |
| --- | --- | --- |
| **签约国海军** | 各国自己的海军 | 本国政府 |
| **公约舰队** | 公约组织的常设联合舰队 | 联合参谋部 |
| **各国分遣队** | 各国"捐"给公约的舰与兵 | **理论上**听参谋部，实际可被本国召回 |

```
缔约国会议（签约国 / 永昼租界 / 天市 / 外权地观察员）
        │  一致通过制 —— 所以经常没有决议
        ▼
联合参谋部
        ▼
公约舰队司令部
        ├─ 第一分舰队（签约国捐舰，重甲，远征型）
        ├─ 第二分舰队（天市捐舰，改装，电子战强）
        └─ AD 特遣群（临时编成，玩家所在）
```

### 6.2　这个结构制造什么

1. **命令是妥协的产物**。一份作战命令经过四方签字，必然含糊。
2. **盟友随时会走**。分遣队被本国召回不需要理由，只需要一份电报。
3. **责任是模糊的**。打错了，没人认；打对了，四家都来认。

> 你是一支多国联合部队的指挥官。你的专业性没有问题，
> **有问题的是你头上的那条链。**

## 7　玩家站在哪里

### 7.1　头衔：监督官

你不是舰队长，不是提督。你是**监督官**——公约舰队派去监督交接的人。

这个头衔是整部作品最残忍的设计：**你有权认证，无权开战。** 你的交战规则写着"不得首先开火"，你的任务书写着"确保交接在无暴力情况下完成"，而你的政府同时在给对面发完全相反的电报。

### 7.2　旗舰：远地点号（APSIS）

公约舰队**远地点级船坞舰**首舰，舷号 **001**。泉州重工造，厂商型号刺桐-2M。它不是战舰，是**能移动的港口**：两个维修坞、一座机加工车间、一个法庭舱、一间医院、够全队烧三周的燃料。它跑得慢，转得笨，一旦失去，战役结束。

舰名不是船员起的，是**公约舰队舰名委员会**按条例给的：船坞舰与补给舰以轨道要素命名——远地点、近地点、交点、停泊点、拱线。同级的二号舰叫「近地点号」。

> 远地点是轨道上离中心最远的那个点。这条船要在那里待很久。

### 7.3　第九条

公约第九条附则给了监督官一项**临机处置权**：在通信中断、上级失联、或出现"迫切且不可逆之损害"时，监督官可自行决定行动，**事后接受审裁**。

于是你下的每一条命令都是**暂缓执行的判决**。

### 7.4　你的船员

远地点号的编制里，有相当一部分人的劳动合同登记在清算署的托管账户上——法律上，他们是抵押物的一部分。

> **你指挥的是一船在法律上属于敌人的东西。**

这句话不用写进任何任务简报，它本身就是整部作品的引擎。

### 7.5　戏剧问题

> 你是执行判决的人，还是判决的对象？

## 8　敌人：清算署

### 8.1　它不是帝国，是机构

没有皇帝，没有旗帜，没有"为了某某"的口号。它有一个理事会、一套程序、一个托管账户，和一支**被没收来的舰队**。

它不恨你，甚至不认为在和你作战。在它的档案里，你是"妨碍执行的船舶"，一个分类，不是一个敌人。

### 8.2　接管人 科尔

前线负责人是一个人，不是 AI。这很重要：**能谈判的敌人才可怕**，因为你没有借口。

科尔从不提高音量，从不说威胁的话，每一份通报都引用条款，每一次开火之后都会补发一份**回执**。她真心相信自己在阻止一场更大的灾难——而且她可能是对的。

### 8.3　执行舰队

舰级是**教条**，单舰名是**后果**。名字不表达希望，只表达它要对你做什么。

| 舰级 | 角色 | 说明 |
| --- | --- | --- |
| **清算级** | 主力舰 | 以机构命名，最常见 |
| **执刑级** | 重炮 / 旗舰 | 出现即意味着终局 |
| **禁制级** | 封锁 | 断航、驻留 |
| **追索级** | 追击、登舰 | |
| **征用级** | 缴获、回收 | |
| **传唤级** | 联络、送达 | 最客气的一级 |

单舰名从三个语域取：施事者（湮没者、定谳者、裁夺者）、不可动摇（无赦、不移）、权威（终局、铁律）。

其余全是没收来的改装船，保留原厂型号名加一个「改」字：龙门改、赤铁改、谷神改。

一艘船的全称是「执刑级，湮没者，舷号 4471」。船员没有名字，只有编号。而法条带下面，还盖着它被没收前的名字——**湮没者原来是白霜。**

> 你可能在某一天认出一条船——那是你十七年前服役过的站造出来的。

### 8.4　它的程序，也是它的死穴

```
通告 → 宽限期 → 执行 → 回执
```

四个阶段全部明文广播，时刻表固定，从不偷袭。这不是骑士精神，是**合规**：程序瑕疵会让整个裁定在法庭上失效。

于是产生一个非常特别的对局：**你永远知道它什么时候来，永远不会知道它以什么方式来。** 你可以利用宽限期撤走、加固、设伏；它也知道你会这么做，但它不能改期。

> **敌人可预测，但不可阻挡；盟友可阻挡，但不可预测。**

## 9　两套战争语法

| | 清算署 | 公约 |
| --- | --- | --- |
| 时间 | 可预测（有期限） | 不可预测（要开会） |
| 兵力 | 不可阻挡（有账户） | 可阻挡（要拨款） |
| 手段 | 标准、充足、浪费得起 | 拼装、短缺、每一发都要记账 |
| 语言 | 完整句、条款、被动语态 | 标准通话格式、程序词、绝不闲聊 |
| 弱点 | 不能违法 | 不能统一 |

**公约的说话方式必须是军队的说话方式**：报单位、报方位、报距离、用程序词、不解释、不抒情。纪律不是人设，是设定——一支多国联合部队如果通话不标准，早就自己撞上了。

那恐怖在哪里？**在程序完好无损，而命令的内容已经疯了。**

## 10　世界如何在游戏里出现

### 10.1　三种载体

| 载体 | 位置 | 作用 |
| --- | --- | --- |
| **无线电** | 战斗中、截听、干扰 | 建立"有人在那儿"，制造口音与立场 |
| **文书** | 任务之间、简报、回执 | 建立制度，"格式即压迫" |
| **传闻** | 站内闲聊、船员议论 | 建立纵深，允许错误信息 |

**不用旁白，不用过场动画解释历史。** 玩家拼出来的世界，比被告知的世界可信十倍——这和本作的信息战核心是同一个道理。

### 10.2　口音

| 阵营 | 说话方式 | 例句 |
| --- | --- | --- |
| 公约·参谋部 | 标准通话格式，公文腔，先说结论 | 「远地点，参谋部。命令。授权监督交接。完毕。」 |
| 公约·分遣队 | 同一格式，缩写不同，偶尔用错程序词 | 「远地点，这里是背风岸。接触。红外。方位零四七。完毕。」 |
| 清算署 | 完整句、条款号、被动语态、从不用缩写 | 「贵舰已被列入妨碍执行清单。本通知不构成威胁。」 |
| 永昼租界 | 数字、合同、没有形容词 | 「A-3 尚余四十一吨。贵方有六小时。」 |
| 天市 | 商船腔：短、实用、带价码 | 「远地点，市楼。油价涨了。还要吗？」 |
| 外权地 | 长停顿、不带头衔、不报单位 | 「……你们打完了吗。我们的货还在路上。」 |

### 10.3　两段样本

标准通话：

```
「远地点，远地点，这里是背风岸。报文。完毕。」
「背风岸，远地点。请发。完毕。」
「接触。红外。方位零四七。距离八千。无识别。完毕。」
「收到。保持静默。完毕。」
```

同样的格式，同样的纪律，内容是疯的：

```
「远地点，联合参谋部。命令。
  授权你部监督交接。交接对象为友军单位。
  不得首先开火。重复，不得首先开火。完毕。」
```

### 10.4　幽影航迹

自冰裁定以来，传感器记录到一类无法归档的接触：不辐射、不应答、只在探测边缘出现、出现后不作机动。官方解释是传感器伪影、残骸、"老毛病"。

三种民间说法：

1. 清算署有一支不存在的舰队（它自己不承认）
2. 外权地的船，涂了冷漆，在等
3. 涌潮时代留下的自动化设施，还在执行早已失效的合同

**三种说法都可能是错的，也都不需要被推翻。** 这是战役暗线，也是标题的第二个意思：**你自己也是一条幽影航迹**——一支不在任何名册上的分遣队。

> 规则：永远不给全貌，只给证据。

## 11　命名系统

### 11.1　拼音不是名字

一个地方在另一种语言里的名字，不是把中文音译过去，而是**说那种话的人自己给它起的名字**。

> 所以永昼在英文里不叫 Yongzhou。它叫 **Solstice**。

中文叫「永昼」，因为太阳不落；英文叫 **Solstice**，因为太阳停住（solstice 的本义就是"太阳站着不动"）；日文叫「常世」，因为那是回不去的地方。

**三个名字，三种理由。** 这就是这个世界的样子。

### 11.2　名字的数量 = 住在那里的社群数量

小站只有两个名字，大城有三个。没人为一个没人住的地方起名。

| 月面冰场 | 永夜坑 | the Long Night | 常夜 | 坑里 | A-3 井 |

### 11.3　英文要正式，中文可以意境

「天市」「市座」是意境名字，因为它们来自星官和商帮。英文不能这么起——**一个英语世界的商人联邦，正式名字必须像一个机构。**

| 层 | 中文 | English | 日本語 |
| --- | --- | --- | --- |
| 法律实体 | 天市同盟 | the Port League | 市座連合 |
| 正式称呼 | 天市 | the Chartered Ports | 市座 |
| 口语 | 市里 | the Fair | 市 |

> 英语里，**联盟是法人，港市是地方**：条约由 the Port League 签署，资产挂在它名下，被起诉的也是它；但你嘴里说的那片地方叫 the Chartered Ports。
> 中文和日文没有这个区分，因为「天市」「市座」本身就是地方词——所以中日的法律名只能在后面加一个组织词（同盟 / 連合）。

### 11.4　每一个名字都有自己的理由

| 名字 | 语言 | 为什么这么叫 |
| --- | --- | --- |
| 永昼 | 中文 | 太阳绕着地平线转，从不落下 |
| Solstice | 英文 | solstice 本义是"太阳停住"——在这个纬度，太阳确实不升不落 |
| 常世 | 日文 | 常世の国，海那边永远不腐朽的国度 |
| 天市 | 中文 | 天市垣，中国古代星官，意为天上的市场 |
| the Port League | 英文 | 法律实体。签条约、持资产、被起诉的都是它 |
| the Chartered Ports | 英文 | 正式称呼。那片地方本身，由一批特许港市组成 |
| 市座 | 日文 | 座，中世纪商人的特许经营权 |
| 市楼 | 中文 | 天市垣星官，市场之楼 |
| Guildhall | 英文 | 行会大厅，市政所在 |
| 会所 | 日文 | 同业聚会议事之处 |
| 斛 | 中文 | 量谷的器具 |
| Bushel | 英文 | 蒲式耳，量谷的单位 |
| 蔵前 | 日文 | 仓库前。东京真有此地名 |

### 11.5　不止三种语言

这里只列三种，因为这三个社群在这几个地方人口最多。**每种语言都有自己的一套名字。**

| 语言 | 管永昼叫什么 | 意思 |
| --- | --- | --- |
| 西班牙语 | Mediodía | 正午 |
| 俄语 | Полдень | 正午 |
| 韩语 | 한낮 | 正午 |
| 阿拉伯语 | الظهيرة | 正午 |

有趣的是它们都想到了「正午」——因为那儿看起来就是正午。而日语想到的是「常世」，因为对他们来说，那不是一个时间，是一个回不去的地方。

> **有的语言独立想到同一个词，有的语言想到完全不同的东西。地名就是这么长出来的。**

### 11.6　地球不是「下界」

「下界」是贬义——它把地球说成一个更低的地方。但轨道人不是俯视地球，是**够不着**它。

中文叫原乡，英文叫 the Old Country，日文叫 現世——**三个词都指向"那个你离开的地方"，没有一个指向"下面"。**

> 地球还有第四个名字：「应许」。只有少数还相信能回去的人这么叫，而且他们大多没回去过。
>
> 你回不去的地方，才有名字。

### 11.7　称呼即立场

同一个地方，叫什么名字，暴露他是谁：

| 谁 | 管月球那座城叫什么 | 为什么 |
| --- | --- | --- |
| 公约参谋部 | Solstice | 合同名，公文里就是这么写的 |
| 月面矿工 | 永昼 | 他们住在那儿 |
| 日裔工程师 | 常世 | 他们祖辈给这个坑起的名字 |
| 清算署 | A 区 | 它不承认这地方有名字 |
| 刚到任的军校生 | 永昼（念得很小心） | 他在学哪套词是对的 |

**在对话里换一个名字，就是换一个立场。**

### 11.8　住在那里的人

| 说法 | 谁在用 | 语气 |
| --- | --- | --- |
| **轨道居民** | 新闻、文件、正式场合 | 中性，像"市民""居民" |
| **轨道人** | 日常口语、自称 | 随意，有时带一点自豪 |
| **在册抵押人员** | 清算署公文、法庭、劳动合同 | 法律分类，冷 |
| 地球人 | 轨道人对签约国本土人的称呼 | 略带疏远 |

日常一律用「轨道居民」或「轨道人」。「在册抵押人员」只出现在文书里——它不是一种身份，是一个条款编号。

> 你没法把一个人叫成"抵押物"。但你可以在合同附件第三页找到他。

## 12　语气规则

写任何文本（舰名、简报、无线电、UI 文案）时遵守：

1. **军队说话像军队**。报单位、报方位、报距离、用程序词、不解释、不抒情。网络上没有闲话。
2. **敌人说话比我们礼貌**。这是全作最重要的语气反差。
3. **数字要具体**。不写"大量燃料"，写"四十一吨"。
4. **不解释技术**。没人会向同事解释自己每天用的东西怎么工作。
5. **悲伤不外露**。死人之后，下一句台词是关于燃料的。
6. **不用「银河」「星舰」「宇宙战舰」这类词**。说「轨道」「环上」「站」「坑里」。
