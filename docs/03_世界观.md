## 1　我们向 Highfleet 借什么

### 1.1　它真正的三根柱子

| 柱子 | Highfleet 怎么做 | 为什么有效 |
| --- | --- | --- |
| **探测即战略** | 雷达开机就暴露，关机就瞎；ELINT 决定你走哪条路 | 把「看见」变成一种**要付费的行为** |
| **舰队是一笔会破产的资产** | 燃料、弹药、维修、奖金；打一场仗常常是亏的 | 让「避免交战」成为主要玩法 |
| **制度用声音建立** | 无线电里的头衔、通报、命令；你服从一个从未见过的机构 | 用文书和口音建世界，比用 CG 便宜，也比用 CG 可信 |

### 1.2　一处必须先说清的误读

Highfleet 的「真实」**不是技术真实**，是**制度真实**：补给会耗尽、命令会迟到、授权会过期、上级会失联。

> 所以我们不抄它的物理，也不抄它的美术。**我们抄它的账本。**

如果照搬它的表层，会得到「太空里的二战」——飞艇换成飞船，别的什么都不变。那是错的，因为我们的物理是真的。物理真了，设定就必须付得起物理的账。

### 1.3　太空歌剧的尺度从哪里来

不是从星系来。地月空间有四十万公里、六公里每秒的重力井、以周计的航程。只要**时间和代价是真的**，宿命感就成立。

> 歌剧感来自「个人被卷进比自己大的东西」，而「比自己大的东西」在近未来只有一个合理答案：**制度**。

## 2　世界的物理前提：沙漠就是 Δv 地图

### 2.1　一笔算得出来的账

按 02 的推进数据，一艘 1000 吨干重、带 300 吨燃料的核热舰，Δv 约 **2.3 km/s**。而地月空间的价目表是：

| 机动 | Δv（约） |
| --- | --- |
| 地球表面 → 低轨 | 9.4 km/s |
| 低轨 → 地月转移 | 3.1 km/s |
| 地月转移 → 环月 | 0.9 km/s |
| 环月 → 月面 | 1.8 km/s |
| 月面 → 环月 | 1.9 km/s |
| 环月 → 返回地球 | 0.8 km/s |
| 低轨 → 地球同步轨道 | 3.9 km/s |

**结论一：一艘战舰加满油，只够做一次大机动，然后必须找地方加注。** 它不能「去月球打一仗再回来」。

**结论二：没有一艘战舰曾经降落过。** 它们没有起落架，没有气动外形，从出生到拆解都在轨道上。这直接决定美术：**纯功能外形，没有任何为了好看而存在的曲面。**

**结论三：地球的舰队每一次出动都是一次国家级开支。** 爬重力井太贵，所以地球打仗靠「到位」而不是「机动」——先占住，再谈。

### 2.2　于是地图长这样

| Highfleet | 我们 | 说明 |
| --- | --- | --- |
| 沙漠 | Δv 预算 | 你穿过的不是空间，是燃料 |
| 城市 | 加注站 + 船坞 + 港务/海关 | 三位一体：加油的地方，也是登记、报关和争管辖权的地方 |
| 公里数 | Δv 数 | 同样两百公里，顺行和逆行差一个数量级 |
| 燃料 | 月冰制推进剂 | 唯一的战略物资 |
| 雷达 / ELINT | 主动雷达 / 被动红外 / 通信截听 | 见 05 |
| 商队 | 定期货运航班 | 按 Hohmann 窗口发车，错过一班等三周 |
| 废墟 | 废弃轨道设施 | 上一轮泡沫留下的站、坞、坟 |

> **所有的政治，都是加注站与航道的管辖权纠纷。**

## 3　历史：四个时刻

### 2049　涌潮

地球气候与能源危机叠加，可复用重载成熟，月极冰探明并商业化。轨道经济起飞：太阳能电站、零重力材料、数据中心散热外包、在轨加注。地球资本把地月空间当成新边疆开发，第一代「轨道移民」在服务期满后没有回地球，而是留在了站上。

### 2061　大停摆

地月基础设施连锁失效：能源、补给、通信、轨道交通一环扣一环。旧国际体系在救援与责任分摊上彻底失灵，随后解体。**没有中央政权有能力维持地月秩序**，港群、矿业站和船坞只能自保。

大停摆之后，「港群」作为一种政治事实出现：同一轨道点附近的站、坞、农场和居民区，为了水、电、粮食和航道联合起来。它们没有军队，只有港务、工会和彼此之间的协议。

### 2071　UEG 成立

旧的全球治理框架被「**地球联合政府（UEG）**」取代。UEG 以《轨道宪章》接管关键基础设施：发射场、地球同步轨道港、地月交通节点、海关与导航。它承诺港群自治，但联合议会里的席位按地球人口与出资分配，港群永远不够。

UEG 是联邦制政府：联邦总统、联邦议会、中央安全委员会、轨道事务委员会、联合轨道军。首都与主要机构在地球。它合法，但它的合法性主要建立在地球上。

### 2087　火星叛乱与第七号令

火星殖民地叛乱爆发，UEG 联合轨道军主力被拖在火星。地月系只剩架子：少量巡逻舰、海关艇、训练舰和一支正在扩权的独立舰队。

中央安全委员会借「紧急状态」推动中央集权，把关键基础设施的「临时托管」写进轨道宪章的解释里。**第七号轨道紧急托管令（Order 7）** 由 **Greenwich** 发布，并在 L1 Meridian-05 **Chronos** 的储罐区张贴：任何「失能、受威胁或被敌方渗透」的加注站、储罐、船坞与航道，可由 UEG 指定部队接管，直至紧急状态结束。

同一天，Chronos 加注站发生爆炸，UEG 核查组失联。第33舰队以「火星分离主义破坏」为由援引第七号令，接管储罐与进港航道。

**现在**：第七号令发布后的第九天。Chronos 的储罐还在漏，港群在等；OCUVF-ID13 刚到 Meridian，是唯一还能动的武装。

## 4　当代格局：五个权力体与一条战线

| 权力体 | 物质基础 | 合法性表述 | 军事风格 | 致命弱点 |
| --- | --- | --- | --- | --- |
| **地球联合政府（UEG）** | 人口、资本、发射场、宪章、地球工业 | 「我们是合法政府」 | 正规军，重甲，程序化，主力在火星 | 爬井贵；国内政治分裂；地月兵力真空 |
| **第33轨道特别独立舰队 / Reclaimers** | 紧急军费、接管资产、标准化改装、黑单位 | 「我们只是在执行紧急托管」 | 标准化、程序化、数量、接管条令 | 不能违反自己的宪章与授权；依赖鹰派 |
| **轨道殖民地联合（OCJC / OCU）** | 五港群、船坞、制造、人口、航道 | 「我们不隶属于任何人」 | 改装船、志愿舰队、电子战、蜂群 | 没有常备军；议而不决；站不能弃 |
| **永昼特许领** | 冰、水、地热、质量驱动器 | 「我们按特许状经营」 | 固定防御、抛射体、少量舰 | 不能跑。它是固定目标 |
| **外环声索地** | 金属、挥发物、距离 | 「我们是被留在外面的人」 | 远程、粗野、自制 | 太远。赶到时局面已定 |

> 火星叛乱不是第六个权力体，是**把 UEG 拖住的那条战线**。它让地月系出现真空，也让难民与坏消息一起涌进港群。

### 4.1　地球联合政府（UEG）

不是单一民族国家，是联邦制政府。地球是它的首都、兵源、税基和发射场。

- **联邦总统 + 联邦议会**：分裂。总统需要紧急状态维持权威，议会不愿为地月系加税。
- **中央安全委员会（鹰派）**：第33舰队的靠山。主张把「临时托管」变成常态，把港群纳入中央指挥。
- **轨道事务委员会（鸽派 / 自治派）**：要求复核第七号令，主张与 OCJC 谈判。玩家潜在盟友。
- **联合轨道军**：正规军。主力深陷火星，地月系只剩巡逻、海关与训练单位；少数新型军舰是港群眼里的「真正的军舰」。
- **UEG 海关 / 轨道管制**：Greenwich、Janus、Horizon 等节点。管文件、航道与进出港许可，也管谁先拿到补给。

UEG 的问题不是「坏」，是**它必须同时做合法政府和战争政府**：越强调紧急状态，港群越不信它；越让步，鹰派越说它在纵容分裂。

### 4.2　第33轨道特别独立舰队 / 清算者（Reclaimers）

- 正式中文：**地球联合政府（UEG）第33轨道特别独立舰队**。
- 正式英文：**Earth Union Government (UEG) 33rd Orbital Special Independent Fleet**。
- 俗名：**清算者部队 / Reclaimers**。港群里的人也叫它「接管队」「三十三」「戴臂章的海关」。
- 名义上隶属 UEG 轨道司令部，实际上只对中央安全委员会和舰队司令部负责。它有自己的征用体系、标准化条令、接管程序与军法系统。
- 任务：执行第七号令，接管「失能 / 受威胁 / 被渗透」的关键基础设施，回收「无主 / 违法」资产，维持它定义的秩序。
- 它不是帝国，也不是法院。它是一支**合法政府内部的独立武装**：先出示授权，再执行接管；程序完整，态度礼貌，必要时开火。
- **GHOST TRACK**：舰队内部的标准改装试验群 / 黑单位。见 §7.5。

### 4.3　轨道殖民地联合（OCJC / OCU / OCUVF / ID13）

- **OCJC**：轨道殖民地联合议会（Orbit Colony Joint Congress）。五个港群 + 月面自治代表 + 外环观察员；松散、票决、没有常备军。它能在声明上达成一致，很难在行动上达成一致。
- **OCU**：轨道殖民地联合（Orbit Colony Union）。政治名称，指联合本身。不是国家，是自治港群的政治联合。
- **OCUVF**：轨道殖民地联合志愿舰队（Orbit Colony Union Volunteer Fleet）。混编、半地下、靠港群供养；船是买的、借的、改的，人是轮换的。
- **OCUVF-ID13**：第13独立分遣群（13th Independent Detachment）。玩家单位。母港 **L4-02 Hammer**，旗舰 **APSIS（远地点号）**。
- **玩家**：ID13 新任指挥官。前任在 **L5-01 Eko** 被刺杀，官方说法是「殖民地刺杀」；船员不信官方说法，也不完全信任新来的指挥官。

> ID13 不在 UEG 的舰队名册上。对 UEG 的传感器和文书系统来说，它是一条 **GHOST TRACK**——这也是标题的第二层意思。

### 4.4　五个港群

港群不是五个国家，是五个轨道点上的城市—工业联合体。它们共享 OCJC 席位，但彼此利益不同。站名以用户给定版本为准；详细站点表见 [`20_港群与站点.md`](20_港群与站点.md)。

| 点 | 港群 | 中文 | 定位 | 政治倾向 | 关键站（例） |
| --- | --- | --- | --- | --- | --- |
| L1 | **Meridian** | 子午 | 贸易、海关、加注、转运；最国际化 | 摇摆；Act 1 现场 | Greenwich、Sextant、Chronos、Astrolabe |
| L2 | **Karman** | 卡门 | 中继、观测、月背通信；技术官僚 | 偏 UEG，但怕被接管 | Janus、Argus、Horizon、Silent |
| L3 | **Alborada** | 黎明 | 农业、食品、水；合作社 | OCU 稳定票仓 | Aurora、Ceres、Dew、Demeter |
| L4 | **Anvil** | 铁砧 | 船坞、重工业、拆船；工会 | OCU 工业核心 | Hammer、Vulcan、Crucible、Ingot |
| L5 | **New Lagos** | 新拉各斯 | 居住、轻工业、人口；派系杂 | OCU，但内部撕裂 | Eko、Zuma、Savannah、Victoria |

- **L1 Meridian** 是门面：海关、转运码头、加注站、贸易代表处。UEG 与 OCU 在这里共管又互相扯皮，所有进出港文件的第一道闸都在 Greenwich。
- **L4 Anvil** 是后方：ID13 的母港 Hammer、装甲与舰体材料、拆船与黑市渠道。没有 Anvil，志愿舰队连修理都做不到。
- **L5 New Lagos** 是人：最老的居住区、最密的社区、最强的舆论。前任指挥官的死在 Eko，让 ID13 与港群之间多了一层私人账。

### 4.5　永昼特许领

月面南极环缘的公司城。太阳绕着地平线转，从不落下，所以中文叫「永昼」；英文叫 **Solstice**（太阳停住）；日文叫 **常世**（回不去的国度）。冰在脚下——永久阴影里，永远不化的坑底。

它不要求独立，只要求**特许状被尊重**。特许状就是它的宪法，董事会就是它的政府，矿工就是它的居民。它是地月系最重要的水、氢和氧来源，也是这场冲突里最不想站队、又最不可能中立的一方。

> **永昼的人，靠永夜的冰活着。**

### 4.6　外环声索地

小行星带。官方文件叫「外环声索地」，港群里的人叫「带外」。它卖金属给两边，然后看着两边把金属打成废铁再卖一次。它的舰队不在主战场，它的**货单**在。

外环合作社是 ID13 最可能的补给来源，也是最不可靠的盟友：它讲交情，但更讲运费。

### 4.7　火星叛乱

火星殖民地的叛乱把 UEG 联合轨道军主力拖住。地月系看到的不是战报，是后果：征用、延误、难民船、坏消息和突然变严的海关。

L5-07 Savannah 是主要难民接收站。难民带来劳动力、情报和舆论压力，也带来 UEG 的检查与「临时安置」——港群最怕的词之一。

## 5　冲突为什么发生

不是仇恨，是一份**格式正确的紧急命令**。因果链只有八步：

| # | 环节 | 内容 |
| --- | --- | --- |
| 1 | 战线 | 2087 火星叛乱，UEG 主力被拖在火星，地月系兵力真空 |
| 2 | 授权 | 中央安全委员会推动「紧急托管」解释，准备把港群纳入中央指挥 |
| 3 | 法令 | 第七号轨道紧急托管令（Order 7）发布：关键基础设施可由 UEG 指定部队接管 |
| 4 | 触发 | Chronos 加注站爆炸，UEG 核查组失联，储罐与进港航道成为「受威胁资产」 |
| 5 | 接管 | 第33舰队援引第七号令进驻，要求港务移交储罐、航道与调度权 |
| 6 | 分裂 | OCJC 内部无法就「抵抗 / 谈判 / 默认」达成一致；港群各自打算 |
| 7 | 真空 | UEG 不想升级，鸽派要求复核，鹰派要既成事实；当地没有 UEG 正规军 |
| 8 | 在场 | OCUVF-ID13 刚到 Meridian。它有船、有人、有命令链，但**没有法理依据** |

**所以玩家接到的任务，本质上是「让这件事不要变成枪战」。** 一旦开火，UEG 鹰派拿到戒严借口，OCJC 被迫站队，港群的自治就结束了。

> 第七号令不是谎言。它是一份**真实存在的紧急权力**，被用来做一件所有人都知道不对、但没有人能证明非法的事。

## 6　玩家站在哪里

### 6.1　头衔：ID13 指挥官

你不是 UEG 军官，也不是港群元老。你是 **OCUVF-ID13 的新任指挥官**——一个志愿舰队的分遣群指挥官。

这个位置最残忍的地方：**你有船，没有法理；你有命令链，没有统一的上司。**

- OCJC 给你授权，但授权范围每次都要吵；
- 港群给你补给，但每个港都要交换条件；
- UEG 把你当「未登记武装」，Reclaimers 把你当「妨碍执行」；
- 你的船员来自不同港群，口音、习惯、忠诚都不一样。

### 6.2　旗舰：远地点号（APSIS）

OCUVF 的**远地点级船坞舰**首舰，舷号 **001**。泉州重工造，厂商型号刺桐-2M。它不是战舰，是**能移动的港口**：两个维修坞、一座机加工车间、一个会议室 / 听证舱、一间医院、够全队烧三周的燃料。它跑得慢，转得笨，一旦失去，战役结束。

舰名不是船员起的。志愿舰队沿用旧名册，船坞舰与补给舰以轨道要素命名——远地点、近地点、交点、停泊点、拱线。同级的二号舰叫「近地点号」。

> 远地点是轨道上离中心最远的那个点。这条船要在那里待很久。

### 6.3　你的舰队

ID13 不是一支标准舰队，是一堆**还能动的船**：

- 哨舰哈马丹号：廉价、传感器好、装甲薄；
- 炮舰渡口号：耐打、传感器差、有轨道炮；
- 中继舰望楼号：全队的链路命脉；
- 油船深井号：全队的航程；
- 还有一批没有出现在编制表上的船、借来的船、改到一半的船。

船员不信 UEG，也不完全信 OCJC。他们信的是：**船要能回来，工资要能发，死人要有记录。**

### 6.4　授权与交战规则

OCJC 给 ID13 的授权是逐案的、含糊的、经常迟到的。联合议会的原话通常是：

> 「在不首先开火的前提下，采取一切必要措施保护港群资产与居民。」

这句话可以解释成「卡位」，也可以解释成「投降」。玩家要在两者之间自己找空间。

- **默认 ROE**：不得首先开火。
- **UEG 的命令**：要求 ID13「配合维持秩序」，但不承认 ID13 的执法权。
- **Reclaimers 的要求**：要求 ID13「不要妨碍执行」，语气礼貌，措辞像通知。
- **报告**：ID13 向 OCJC / OCUVF 提交**内部事后报告**；UEG 不会收到它，也不会承认它。

### 6.5　戏剧问题

> 你是保卫自治的武装，还是另一支没有合法性的私兵？
>
> 你是在保护港群，还是在替港群打一场他们不敢承认的战争？

## 7　敌人：第33舰队 / Reclaimers

### 7.1　它不是帝国，是体制内暴力

没有皇帝，没有旗帜，没有「为了某某」的口号。它有一个舰队司令部、一套接管条令、一个紧急授权，和一支**被它接管的舰队**。

它不恨你，甚至不认为在和你作战。在它的档案里，你是「未登记武装船舶」，一个分类，不是一个敌人。

> 这也是它最可怕的地方：**它真的相信自己在恢复秩序。**

### 7.2　接管官 科尔

前线负责人是一个人，不是 AI。这很重要：**能谈判的敌人才可怕**，因为你没有借口。

科尔从不提高音量，从不说威胁的话，每一份通知都引用轨道宪章与第七号令的条款，每一次行动之后都会补一份**记录归档**。她真心相信临时托管能避免更大的灾难——而且她可能是对的。

称呼：**接管官科尔**。不是文书送达员，也不是法警。

### 7.3　接管舰队

舰级是**条令**，舰名是**后果**。名字不表达希望，只表达它要对你做什么。

| 舰级 | 舰种 | 代码 | 任务职能 | 说明 |
| --- | --- | --- | --- | --- |
| **清算级** | 战列舰 | BB | 清算 / 主力 | 以条令命名，最常见 |
| **执刑级** | 重巡洋舰 | CA | 执刑 / 旗舰 | 出现即意味着终局 |
| **禁制级** | 轻巡洋舰 / 封锁巡洋舰 | CL | 禁制 | 断航、驻留 |
| **追索级** | 驱逐舰 | DD | 追索 / 登舰 | 追击、跳帮 |
| **征用级** | 护卫舰 / 回收舰 | FF | 征用 | 缴获、回收 |
| **传唤级** | 通报舰（aviso） | AV | 传唤 / 送达 | 最轻，也最客气的一级 |

单舰名从三个语域取：施事者（湮没者、裁夺者、究诘者）、不可动摇（无赦、不移）、权威（终局、铁律）。

其余全是没收来的改装船，保留原厂型号名加一个「改」字：龙门改、赤铁改、谷神改、月港改。

一艘船的全称是：**执刑级重巡洋舰，湮没者，舷号 4471**。船员没有名字，只有编号。而法条带下面，还盖着它被接管前的名字——**湮没者原来是白霜。**

> 你可能在某一天认出一条船——那是你服役过的站造出来的。

### 7.4　它的程序，也是它的死穴

```
接管通知 → 核验窗口 → 执行 → 归档
```

四个阶段全部明文广播，时刻表固定，从不偷袭。这不是骑士精神，是**合规**：程序瑕疵会让整个第七号令行动在 UEG 的政治审查里失去依据。

于是产生一个非常特别的对局：**你永远知道它什么时候来，永远不会知道它以什么方式来。** 你可以利用核验窗口撤走、加固、设伏；它也知道你会这么做，但它不能改期。

> **敌人可预测，但不可阻挡；盟友可阻挡，但不可预测。**

### 7.5　GHOST TRACK

第33舰队内部有一个不在战斗序列里的 **标准改装试验群**，代号 **GHOST TRACK**。

- 它测试新的标准改装包：低红外涂装、假应答机、诱饵、航迹擦除、信号伪装。
- 它执行不挂名的任务：假旗、制造接管借口、抹掉自己出现过的证据。
- 它没有公开的舰名与舷号；船壳上的编号可能来自拆解船、退役船或根本不存在的登记。
- 它的船看起来「像一条船，但任何厂商型号都对不上」——因为它是标准改装件、原厂船体和试验设备的拼装。
- 法条带下面通常没有旧名：旧名被磨掉，或者从来没刷过。

自第七号令以来，Meridian 的传感器记录到一些无法归档的接触：不辐射、不应答、只在探测边缘出现、出现后不作机动。官方解释是传感器伪影、残骸、「老毛病」。

三种民间说法：

1. 第33舰队有一支不存在的舰队（它自己不承认）
2. 外环的船，涂了冷漆，在等
3. 涌潮时代留下的自动化设施，还在执行早已失效的程序

**三种说法都可能是错的，也都不需要被推翻。** 这是战役暗线，也是标题的第一个意思。

> ID13 自己也是一条 GHOST TRACK：不在 UEG 名册上，只能靠港群和传闻证明自己存在。

## 8　两套战争语法

| | 第33舰队 / Reclaimers | OCU / ID13 |
| --- | --- | --- |
| 时间 | 可预测（有接管时刻表） | 不可预测（要开会、要等授权） |
| 兵力 | 不可阻挡（有紧急军费与标准化舰队） | 可阻挡（要筹船、要港群同意） |
| 手段 | 标准、充足、浪费得起 | 拼装、短缺、每一发都要记账 |
| 语言 | 完整句、条款、被动语态 | 标准通话格式、程序词、绝不闲聊 |
| 弱点 | 不能违反自己的宪章与授权 | 不能统一 |

**OCU 的说话方式必须是军队的说话方式**：报单位、报方位、报距离、用程序词、不解释、不抒情。纪律不是人设，是设定——一支混编志愿舰队如果通话不标准，早就自己撞上了。

那恐怖在哪里？**在程序完好无损，而命令的内容已经疯了。**

## 9　世界如何在游戏里出现

### 9.1　三种载体

| 载体 | 位置 | 作用 |
| --- | --- | --- |
| **无线电** | 战斗中、截听、干扰 | 建立「有人在那儿」，制造口音与立场 |
| **文书** | 任务之间、简报、通知 | 建立制度，「格式即压迫」 |
| **传闻** | 站内闲聊、船员议论 | 建立纵深，允许错误信息 |

**不用旁白，不用过场动画解释历史。** 玩家拼出来的世界，比被告知的世界可信十倍——这和本作的信息战核心是同一个道理。

### 9.2　口音

| 阵营 | 说话方式 | 例句 |
| --- | --- | --- |
| UEG 联合轨道军 | 标准通话格式，公文腔，先说结论 | 「远地点，联合轨道军。通知。请保持航道畅通。完毕。」 |
| UEG 海关 / 港务 | 表格腔、编号、期限 | 「L1-05，海关。请提交第三联。逾期按滞留处理。」 |
| 第33舰队 / Reclaimers | 完整句、条款号、被动语态、从不用缩写 | 「贵舰已被列入妨碍执行清单。本通知不构成威胁。」 |
| OCU / 港群 | 商船腔或工会腔：短、实用、带价码或条件 | 「远地点，Meridian 港务。油价涨了。还要吗？」 |
| ID13 / 志愿舰队 | 标准格式，但缩写混用、口音杂 | 「远地点，哈马丹。接触。红外。方位零四七。完毕。」 |
| 永昼特许领 | 数字、特许状条款、没有形容词 | 「A-3 尚余四十一吨。贵方有六小时。」 |
| 外环声索地 | 长停顿、不带头衔、不报单位 | 「……你们打完了吗。我们的货还在路上。」 |
| 火星难民 | 疲惫、短句、不信任任何制服 | 「……还有水吗。」 |

### 9.3　两段样本

标准通话：

```
「远地点，远地点，这里是哈马丹。报文。完毕。」
「哈马丹，远地点。请发。完毕。」
「接触。红外。方位零四七。距离八千。不明。完毕。」
「收到。保持静默。完毕。」
```

同样的格式，同样的纪律，内容是疯的：

```
「远地点，OCJC 海务。授权。
  在不首先开火的前提下，保护 Chronos 储罐。
  重复，不得首先开火。完毕。」
```

### 9.4　规则：永远不给全貌，只给证据

- 不写「UEG 是坏人」；写一份格式正确的命令，和一份没有回应的申请。
- 不写「Reclaimers 是黑的」；写法条带上被磨掉的旧名、被改过的编号、对不上的厂商型号。
- 不写「玩家是英雄」；写一条不在名册上的船，和一群不信官方说法的船员。

## 10　命名系统

### 10.1　拼音不是名字

一个地方在另一种语言里的名字，不是把中文音译过去，而是**说那种话的人自己给它起的名字**。

> 所以永昼在英文里不叫 Yongzhou。它叫 **Solstice**。

中文叫「永昼」，因为太阳不落；英文叫 **Solstice**，因为太阳停住（solstice 的本义就是「太阳站着不动」）；日文叫「常世」，因为那是回不去的地方。

**三个名字，三种理由。** 这就是这个世界的样子。

### 10.2　名字的数量 = 住在那里的社群数量

小站只有两个名字，大城有三个。没人为一个没人住的地方起名。

| 地方 | 中文 | English | 日本語 | 居民口语 | 公文名 |
| --- | --- | --- | --- | --- | --- |
| 月面采冰城 | 永昼 | Solstice | 常世 | 昼面 | 永昼特许领 |
| 月面冰场 | 永夜坑 | the Long Night | 常夜 | 坑里 | A-3 井 |
| L1 港群 | 子午 | Meridian | — | 子午环 | L1 |
| L2 港群 | 卡门 | Karman | — | 卡门环 | L2 |
| L3 港群 | 黎明 | Alborada | — | 黎明环 | L3 |
| L4 港群 | 铁砧 | Anvil | — | 铁砧环 | L4 |
| L5 港群 | 新拉各斯 | New Lagos | — | 新拉 | L5 |
| 地球 | 原乡 / 地上 | the Old Country / Earthside | 現世 / 地球 | — | UEG 本土 |
| 小行星带 | 外环声索地 | the Outer Claims | 辺境 | 带外 | 外环 |

> 港群的英文名是用户给定的正式名，不是中文的翻译；中文名是港群自己选的中文写法。

### 10.3　英文要正式，中文可以意境

- **UEG** 的机构名必须像机构：联邦议会、中央安全委员会、轨道事务委员会、联合轨道军。英文对应同样的机构词，不玩双关。
- **OCU / 港群** 的名字可以是社区自己起的：Meridian、Alborada、Anvil、New Lagos、Chronos、Eko。它们是地名，不是产品名。
- **第33舰队** 的舰级是条令词，舰名是后果词。它的命名不追求美感，追求「读起来像判决结果」。
- **OCUVF** 没有统一命名局。船名来自捐赠港群、旧名册、船员投票，偶尔来自一个已经拆掉的站。

### 10.4　每一个名字都有自己的理由

| 名字 | 语言 | 为什么这么叫 |
| --- | --- | --- |
| 永昼 | 中文 | 太阳绕着地平线转，从不落下 |
| Solstice | 英文 | solstice 本义是「太阳停住」——在这个纬度，太阳确实不升不落 |
| 常世 | 日文 | 常世の国，海那边永远不腐朽的国度 |
| Meridian | 英文 | 子午线：L1 是地球与深空之间的门面，所有文件在这里过线 |
| 卡门（Karman） | 中文 | 卡门线：轨道与大气之间的边界；L2 是通信与观测的边界站 |
| 黎明（Alborada） | 中文 / 西班牙语 | 黎明：农业站每天最早见到太阳；L3 是港群的粮仓 |
| 铁砧（Anvil） | 中文 / 英文 | 铁砧：L4 的船坞与重工业；也是「被打的地方」 |
| 新拉各斯（New Lagos） | 中文 / 英文 | 名字来自地球上的旧城；具体来历待 20 定（不编造） |
| Chronos | 英文 | 柯罗诺斯：时间；L1-05 的储罐决定港群还能撑多久 |
| Greenwich | 英文 | 格林尼治：时间与标准的起点；海关与文件在这里定基准 |
| Sextant | 英文 | 六分仪：进出港的调度与引航；没有它，船进不来 |
| 原乡 | 中文 | 祖先来的地方。回不去，才叫原乡 |
| the Old Country | 英文 | 移民对故国的叫法。爷爷就是从那儿来的 |
| 現世 | 日文 | 与「常世」相对。他们把月球叫常世（永恒之国），把地球叫现世（流转之世）——**反过来了** |

> 三语不是互译，是三种人各自看见的东西。

### 10.5　不止三种语言

这里只列三种，因为这三个社群在这几个地方人口最多。**每种语言都有自己的一套名字。**

| 语言 | 管永昼叫什么 | 意思 |
| --- | --- | --- |
| 西班牙语 | Mediodía | 正午 |
| 俄语 | Полдень | 正午 |
| 韩语 | 한낮 | 正午 |
| 阿拉伯语 | الظهيرة | 正午 |

有趣的是它们都想到了「正午」——因为那儿看起来就是正午。而日语想到的是「常世」，因为对他们来说，那不是一个时间，是一个回不去的地方。

### 10.6　地球不是「下面」

把地球叫成「下面」是贬义——它把地球说成一个更低的地方。但轨道人不是俯视地球，是**够不着**它。

中文叫原乡，英文叫 the Old Country，日文叫 現世——**三个词都指向「那个你离开的地方」，没有一个指向「下面」。**

> 地球还有第四个名字：「应许」。只有少数还相信能回去的人这么叫，而且他们大多没回去过。
>
> 你回不去的地方，才有名字。

### 10.7　称呼即立场

同一个地方，叫什么名字，暴露他是谁：

| 谁 | 管 L1-05 叫什么 | 为什么 |
| --- | --- | --- |
| UEG 联合轨道军 / 海关 | L1-05 | 编号就是官方名；文件里不需要故事 |
| OCU / Meridian 港务 | Chronos | 他们住在那儿，储罐就是城市的心脏 |
| 第33舰队 / Reclaimers | 目标站点 L1-05 / 受威胁资产 | 它不承认这地方有名字，只承认授权 |
| ID13 / 志愿舰队 | Chronos | 他们被派来保护的是人，不是编号 |
| 刚到任的军校生 | Chronos（念得很小心） | 他在学哪套词是对的 |

**在对话里换一个名字，就是换一个立场。**

### 10.8　住在那里的人

| 说法 | 谁在用 | 语气 |
| --- | --- | --- |
| **轨道居民** | 新闻、文件、正式场合 | 中性，像「市民」「居民」 |
| **轨道人** | 日常口语、自称 | 随意，有时带一点自豪 |
| **港群公民** | OCJC / 港务文件、选举 | 政治身份；有港群就有投票权 |
| **地球人** | 轨道人对 UEG 本土人的称呼 | 略带疏远 |
| **无籍船员** | 志愿舰队、黑市、难民 | 不在任何港群名册上的人；ID13 里很多 |

> 这个世界只有**登记过的人和没登记的人**。后者更自由，也更容易死。

## 11　语气规则

写任何文本（舰名、简报、无线电、UI 文案）时遵守：

1. **军队说话像军队**。报单位、报方位、报距离、用程序词、不解释、不抒情。网络上没有闲话。
2. **敌人说话比我们礼貌**。这是全作最重要的语气反差。
3. **数字要具体**。不写「大量燃料」，写「四十一吨」。
4. **不解释技术**。没人会向同事解释自己每天用的东西怎么工作。
5. **悲伤不外露**。死人之后，下一句台词是关于燃料的。
6. **不用「银河」「星舰」「宇宙战舰」这类词**。说「轨道」「港群」「站」「坑里」。
7. **不写「帝国」「皇帝」「天选者」**。UEG 是合法政府，第33舰队是体制内暴力；玩家是新官，不是救世主。
8. **不写经济纠纷，也不写法庭戏**。冲突是**紧急权力 vs 自治**，不是一场官司。
