## 0　一句话

> 这个游戏没有道德值，只有**案卷**。
> 同一份案卷，不同阵营读出来的结论不一样。

---

## 1　三个量，不是三条槽

| 量 | 范围 | 谁看 | 作用 |
| --- | --- | --- | --- |
| **阵营声望** | 每个权力体 -3 ~ +3 | 玩家可见（简报/无线电/价格） | 对话、补给、通行、盟友是否来接 |
| **上级信任** | 0 ~ 100 | 隐藏 | 授权、增援、审裁时的态度 |
| **案卷** | 事实列表 | 法庭与玩家 | 证据。不是分数，不可洗白 |

- **不做“善恶条”。** 同一件事，公约可能记你“抗命”，天市可能记你“救了人”。
- **不做“道德值”。** 玩家不是被评分，是被归档。
- 船员信任后续再加；第一关只记案卷和声望。

## 2　第一关三种结局

三种都算**通关**，都进Act 2，只是分支不同：

| 结局 | 做法 | 公约 | 天市 | 清算署 | 永昼 | flag / 后续 |
| --- | --- | --- | --- | --- | --- | --- |
| **认证交接** | 按程序签字，储罐交给清算署 | +1 | -1 | +1 | 0 | `outcome=certify`；Act 2港务冷淡，清算署按程序待你 |
| **援引第九条** | 以“迫切且不可逆之损害”阻止交接 | -1 | +2 | -2 | +1 | `outcome=article9`；Act 2开场就是审裁通知 |
| **拖程序** | 要求文书复核，拖过执行窗口 | 0 | +1 短 / -1 长 | -1 | 0 | `outcome=stall`；储罐断供，Act 2缺油 |

- 没有“正确”结局；只有你愿意付哪一种账。
- 声望变化是**提案值**，等平衡时再调。
- 三种结局都触发同一张“回执/报告”页，只是报告段落不同。

## 3　报告：什么时候可以造假

### 3.1 只有出现不良后果，才有“淡化/伪造”

| 报告时的处境 | 可选 |
| --- | --- |
| 一切合规 | **如实**（或调整措辞） |
| 未经授权开火 | 如实 / 淡化 / 伪造 |
| 误击民用船 | 如实 / 淡化 / 伪造 |
| 储罐丢失、超时、ROE 违规 | 如实 / 淡化 / 伪造 |

没有不良后果时，不给“伪造”选项——**造假不是随时可用的技能，是事故之后的逃生门。**

### 3.2 证据

报告会被四类记录对照：

- 传感器日志（谁在什么时候开机、看到了什么）
- 命令队列（谁下的令、什么时候生效）
- 应答机/通信记录（谷神-2 的故障、传唤级的通告）
- 船员证词（后续系统；第一关只做前两类）

### 3.3 造假怎么被发现

- `perjury_count`：每次选择“淡化/伪造”+1。
- `suspicion`：由伪证次数、证据矛盾、目击者共同决定。
- **第一次**：如果证据本身模糊，可能过；但会留下 `AUDIT FLAG 01`。
- **第二次**：触发例行审计，上级开始核对日志。
- **第三次**：最坏结局——战争罪审判，剥夺监督官身份，视作叛军；**新的监督舰队**被派来追捕你。
- 这就是标题的第二层：**你自己变成了一条幽影航迹**。

> 不是说一次谎就死；是谎会累积，而制度最擅长的就是等。

### 3.4 demo 里的实现

- 开火 → 自动停止 → 后果页（民用伤亡 / ROE 违规）→ 报告页。
- 报告页只有两个选项：**如实** / **伪造**。
- 选伪造：显示 `REPORT FILED — AUDIT FLAG 01`，demo 结束；不做后续审判。
- 选如实：显示 `REPORT FILED — CASE 4471`，demo 结束；Act 2引用。

## 4　开火

- **允许开火。** 玩家可以批准 weapons free，也可以自己下令。
- 一旦开火，**demo 自动停止**：时间冻结、命令队列冻结、切到后果页。
- 后果页显示：
  - 命中/未命中（demo 里脚本化：命中谷神-2）
  - 民用伤亡
  - ROE 违规
  - 案卷新增条目
- 后续不做；玩家只能选择报告方式，然后 demo 结束。
- 这不是 game over；是**进入另一条分支**。真正的审裁在战役后面。

## 5　分支接口

战役状态只需要存这些：

```json
{
  "outcome": "certify | article9 | stall | fire",
  "standing": {
    "signatories": 0,
    "market": 0,
    "receivership": 0,
    "concession": 0,
    "claims": 0
  },
  "command_trust": 72,
  "perjury_count": 0,
  "suspicion": 0,
  "record": [
    { "t": "T+62:14:08", "event": "weapons_free_authorized", "target": "谷神-2" }
  ]
}
```

- Act 2的简报、无线电口音、补给价格、盟友是否出现，都读这些值。
- 阵营 id 按 03 §14.1：`signatories` / `concession` / `market` / `claims`；`receivership` 是机构阵营，不是叙事来源。
- `CASE 4471` 与敌方案卷同号是有意的：你监督的那件事，最后把你写进了同一本案卷。
- 最坏结局（perjury_count ≥ 3 或 suspicion ≥ 80）触发“新监督舰队”战役线；玩家从监督官变成被追捕者。
- 声望不显示成进度条；只在简报、对话、价格里体现。玩家要自己记。

---

## 6　demo 范围

- 只记录 `outcome`、`standing`、`perjury_count`、`suspicion`、`record`。
- 不做声望 UI、不做审判流程、不做新监督舰队。
- 三种结局各显示一张报告卡（文字），让玩家看到“我选了哪一种账”。
- 开火分支只到 `AUDIT FLAG 01` 为止。
