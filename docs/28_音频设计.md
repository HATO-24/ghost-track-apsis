## 2　格式与混音

- 44.1 kHz / 16-bit / mono WAV；常规音效峰值 ≤ -1.5 dBFS；`hard_cut` 为更软的 -7 dBFS；`cg_ambience` 为 -11 dBFS。
- BGM 总线默认 -9 dB，SFX 总线默认 -6 dB；可 `set_bgm_volume()` / `set_sfx_volume()` 调整。
- SFX 播放器池 16 路，避免高频叠爆。
- `DSH_MUTE=1` 强制静音；headless 下 API 安全返回，不播放。
- BGM：`menu_music.wav`（`Orbital Fleet`，用户提供，仅主菜单）；`game_device_ambience.wav`（程序化：软盘步进/磁带/拨号/继电器，仅游戏内）。

## 3　实际挂接点

| 触发 | 音效 | 位置 |
| --- | --- | --- |
| HUD 任意点击 | `ui_hover` / `ui_select` | `hud.gd click()` |
| 通知/副官/手册打开/关闭 | `ui_open` / `ui_close`，通知额外 `sys_comms_rx` | `hud.gd _open_modal/_close_modal` |
| 传感器 ON/OFF | `sys_sensor_on/off`；YW-R9/MK-12 额外 `sys_radar_ping`；ELINT 额外 `sys_elint` | `hud.gd _toggle_sensor()` |
| 派穿梭机取证 / 撤人 | `sys_evidence_start` / `sys_evac_start` | `hud.gd _start_evidence/_start_evac` |
| 命令授权 | `sys_cmd_queued` | `hud.gd _authorize()` |
| 新增通信 | `sys_comms_rx` | `main.gd _audio_cues()` |
| 新命令 / 取证完成 / 撤离完成 | `sys_cmd_queued` / `sys_evidence_done` / `sys_evac_done` | `main.gd _audio_cues()` |
| 决策窗口开启 | `alarm_decision` | `main.gd _audio_cues()` |
| 开火后果 | `alarm_fire` | `main.gd _audio_cues()` |
| 内部报告开启 | `sys_cmd_exec` | `main.gd _audio_cues()` |
