> 状态：权威。按用户确认的阶段顺序执行；产品范围为完整游戏。

## 阶段0 契约与技术存档

### 任务

- 冻结 `game_v17` 阶段2转场为技术验证存档，不再修临时 HUD。
- 写 UI token/字体度量规范（`05`）。
- 写实体/时间/坐标/命令/通信/传感器/存档 schema（`03`/`04`/`06`/`07`/`09`）。
- 剧情状态机 DbC（`08`/`09`）。
- 旧文档归档映射：`00`。

### 验收

- 文档评审通过；
- schema 有示例/校验；
- 旧文档状态标注完成；
- 技术验证包可运行、可回退。

- 教学不挡地图中心；

## 测试矩阵

- 单元：数学/物理/传感器/命令/存档。
- 集成：世界+事件总线+UI view model。
- 回放：确定性。
- 存档：随机时刻/在途命令/通信。
- UI：分辨率/字体/IME/长文本。
- 性能：启动/tick/内存/战斗。
- 内容：所有文本 key/分支可达/报告正确。

## 风险

1. 完整游戏体量：先序章 vertical slice，再扩展。
2. 战斗系统剧本缺失：单独立项，不能脚本化冒充。
3. JPL 星历：默认紧凑星历，完整 SPICE 可选。
4. IME/多语言：Godot 需自绘候选窗，提前原型。
5. 旧文档冲突：以 `00`–`11` 为准。
6. UI 迁移：Control+Theme 与自绘地图共存，需先做最小壳。
