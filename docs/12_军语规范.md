## 0　总则

1. **中文为主，英文为副。** 标签用 `中文 / ENGLISH`；英文只用于舰名、型号、标准缩写，不做装饰（❌ `TRACKS` 单独当标题）。
2. **一词一义。** 接触 ≠ 目标 ≠ 航迹；虚警 ≠ 假目标；战损 ≠ 损管；命令 ≠ 指令；识别 ≠ 分类（详见 §3）。
3. **第一次出现给全称 + 缩写**，之后可只用缩写；同一屏不重复解释。
4. **数字具体、单位明确。** 不写「大量燃料」，写「四十一吨」；不写「很快」，写「45 秒」。方位三位数、距离、速度、时间都带单位。
5. **不确定就标「待核」。** 不引条令号；不把英文当权威。

> 一句话：**这是给中国人读的军队终端，不是英文 HUD 的汉化补丁。**

## 2　核心军语对照表

> 语域：**通用** = 空/海/天都可用；**空** = 空情/防空习惯；**海** = 海军习惯；**天** = 航天/轨道工程习惯。
> 「待核」= 公开译法不统一或本作未定，先按推荐写法用。

### 2.1　信息与目标

| 中文（推荐） | English | 语域 | 用法 / 边界（本作） | 禁用 / 易错写法 |
| --- | --- | --- | --- | --- |
| 接触 | contact | 空·海 | 已探测到、进入列表的实体/回波；可含仅方位、陈旧、GHOST TRACK | ❌ 用「目标」代替；❌ 英文配 `TRACK` |
| 目标 | target | 通用 | 已分配/被跟踪/准备处置的对象，暗示交战或识别意图 | ❌ 把不明接触直接叫目标；❌ 缩写 `TGT` 当 UI 标签 |
| 航迹 | track | 空·海 | 融合系统维护的连续轨迹：历史、预测、批号、协方差 | ❌ 轨迹 / 轨道；❌ 把接触列表叫 `TRACKS` 却配中文「接触」 |

| 不明接触 | unknown contact | 空·海 | 有回波/航迹，但**尚未确认是实体目标**（可能是残骸、反射、虚警） | ❌ 未确认前硬叫「不明目标」 |

| 识别 | identification | 通用 | L3–L4 泛称；精确区分时：L3=分类，L4=确认具体舰名 | ❌ L3 写「识别完成」而 L4 又写「识别」 |

| 跟踪 | tracking | 通用 | 连续维持对目标的观测与航迹 | ❌ 把光学凝视叫「锁定」（锁定留给火控） |
| 稳定跟踪 | stable track | 空·海 | 雷达在稳定跟踪距离内连续跟踪 | ❌ 稳定锁定 |
| 失跟 | track loss（待核） | 空·海 | 丢失跟踪；失去跟踪不删除，逐级降级 | ❌ 丢失目标 |
| 重捕 | reacquisition（待核） | 空·海 | 失跟后重新捕获 | — |
| 搜索 | search | 空·海 | 主动雷达/光学搜索模式 | ❌ 扫描（扫描是显示动作） |
| 威胁等级 | threat level | 通用 | 威胁分级；本作不显示数字条，只在内部/简报使用 | ❌ 威胁值（不是分数） |

### 2.2　传感器与对抗

| 中文（推荐） | English | 语域 | 用法 / 边界（本作） | 禁用 / 易错写法 |
| --- | --- | --- | --- | --- |
| 虚警 | false alarm | 通用 | 系统误报的告警/回波；无真实目标 | ❌ 假目标（假目标是敌情）；❌ 误报率（口语可，正式不用） |

| 漏警 | missed alarm | 通用 | 真有目标而系统未告警/未检测到 | ❌ 漏检（信号处理层可，系统层用漏警） |

| 诱饵 | decoy | 通用 | 实体/信号诱饵装置：热源气球、信号模拟器 | ❌ 把诱饵直接叫假目标（手段 vs 结果） |

| 遮蔽 | masking | 空·海·天 | 天体/地形阻挡视线或辐射（本作主用） | ❌ 遮挡（工程可用，军语文案优先遮蔽） |

| 指纹 | fingerprint / signature | 海·天 | 信号特征码；ELINT 用 | ❌ 特征（泛称） |

| 辐射控制 | emission control（EMCON 命令） | 通用 | 13 §2 命令：雷达/通信/干扰开机或静默；状态叫「电磁管制/静默」 | ❌ 把 EMCON 当命令中文名；❌ 与「静默」混 |
| 凝视 | stare | 空·天 | 光学持续对准目标积累分辨率 | ❌ 锁定（锁定属火控） |
| 驻留 | dwell | 天 | 激光持续照在同一点的时间 | — |

## 3　专项

### 3.1　虚警 / 虚警率 / 漏警 / 假目标 / 诱饵

| 词 | English | 定义 | 本作用法 | 禁用 |
| --- | --- | --- | --- | --- |
| 虚警 | false alarm | 系统把噪声/杂波/残骸误判为目标的告警 | 「CH-IR2 虚警」「虚警候选」；事件计数 `false_alarm_count` | 假目标 |
| 虚警率 | FAR（false alarm rate） | 单位时间或单位扫描的虚警统计 | 写清单位：次/小时 或 次/扫描；数据字段 `false_alarm_rate` | 把 Pfa 叫 FAR |
| 虚警概率 | Pfa（待核） | 单次探测/单次扫描出现虚警的概率（0–1） | 11 的 `false_alarm` 0.02–0.22 实际是 Pfa；建议字段改 `false_alarm_prob` 或注明 | 把 0.22 写成「虚警率 22%」而不说单位 |
| 漏警 | missed alarm | 真实目标存在而系统没告警/没检测到 | 与虚警成对统计 | 漏检（系统层） |
| 漏警率 | MAR（待核） | 漏警统计；单位同虚警率 | 报告「漏警率」时必须给样本量/单位 | 与 Pfa 混 |
| 假目标 | false target | 敌方制造/模拟出来的目标（含诱饵、欺骗信号产生的假航迹） | 电子战/诱饵语境 | 虚警 |
| 诱饵 | decoy | 具体的诱饵装置/信号 | 05 W-05 / E-02 | 假目标（手段≠结果） |

**三条硬规则：**

1. **虚警不是假目标。** 虚警 = 自己的系统犯错；假目标 = 敌人让我们犯错。
2. **虚警率必须有单位。** FAR 是 rate；单次扫描概率是 Pfa。11 的 `false_alarm` 是 Pfa，不是 FAR。
3. **漏警与虚警成对报告。** 只报虚警不报漏警，等于只说一半。

### 3.2　不明目标 / 不明接触 / 不明信号 / 未识别目标

**判定顺序：**

```
有没有回波/航迹？
├─ 没有，只有辐射/信号 ─────────────→ 不明信号（ELINT/ESM；不出接触）
└─ 有
   ├─ 未确认是实体（残骸/反射/虚警候选） ─→ 不明接触 / 虚警候选
   └─ 已确认是实体目标
      ├─ 身份/敌我未知 ────────────────→ 不明目标
      └─ 识别流程未完成 ───────────────→ 未识别目标（状态）；判明后 → 分类 / 确认
```

| 场景 | 推荐写法 | 不要写 | 理由 |
| --- | --- | --- | --- |
| 接触列表里的未知航迹 | **不明接触**（未确认实体）/ **不明目标**（确认实体） | 未识别、未知、Unknown | 实体名不能是识别状态词 |
| ELINT 收到信号但没有航迹 | **不明信号** | 不明目标 | 没有位置，不能叫目标 |
| Act 1「不明 ≠ 敌意」 | **不明** / **无威胁目标** | 未知、未识别 | 教学点：不应答不等于敌舰 |
| 光学/雷达识别没完成 | **未识别**（状态）/ **未识别目标**（正式） | 把「未识别」当实体名 | 状态词 vs 实体名 |
| 谷神-2（9001，应答机故障） | **中立 / 无威胁目标** | 敌舰、未识别 | 民用工作船，最终为 Neutral |
| 2001 AV-4412 传唤者 | **可疑（Suspect）**，不是敌方 | 敌方、敌舰 | 清算者军舰，但未满足 ROE |
| 9002 CH-IR2 回波 | **无威胁目标 / 虚警候选** | 目标、敌舰 | 残骸/反射，不是船 |

### 3.3　接触 / 航迹 / 目标 / 批号 / 威胁

| 词 | 是什么 | 不是什么 | UI 用法 |

## 6　无线电通话模板

### 6.1　标准格式（19 §1）

```
[发信者至收信者]-[LD/LR/RDO/IR/VIS]-[内容]
```

- 中文正文用全角标点；数据层可拆成 `from/to/mode/text`。
- 通信流只放真实通话：**不放教学提示、副官建议、手册段落**。
- 敌人礼貌、完整句、被动语态、不用缩写；称呼玩家「ID13 指挥官」或「指挥官」。

```
[Sextant 至 ID13]-[RDO]-[Chronos 加注站爆炸，进港调度依第七号令移交。请 ID13 立即让出航道。完毕。]
[ID13 至 Sextant]-[RDO]-[收到。ID13 正在核实现场，暂不能让出航道。完毕。]
[哈马丹至远地点]-[LD]-[[2001] 主动机动，[9001] 漂移；另有 [9002] 待确认。完毕。]
[AV-4412 传唤者至远地点]-[RDO]-[本舰依据第七号轨道紧急托管令，送达接管通知。本通知不构成威胁。完毕。]
[远地点至全体]-[LR]-[至全体。光学分类完成：[2001] 传唤级，清算者；[9001] 民用工作船，无威胁。注意交战规则。完毕。]
```

接触。被动红外。方位 047°。距离不明。等级 L1。批号 9002。完毕。

### 6.4　ROE / 武器释放模板

```
默认不交火。重复，默认不交火。完毕。
请求武器释放授权。目标：批号 2001。完毕。
武器释放授权已批准。重复，已批准。完毕。
武器释放授权拒绝。重复，拒绝。保持默认不交火。完毕。
```

- 正式文本：**武器释放授权**；口语/无线电可用 **自由开火**。
- `仅自卫 / WEAPONS HOLD` 与结局 `HOLD / 卡住` 分开写；不要裸写 `HOLD`。
- 开火 = 灾难分支；批准前需要二次确认。

### 6.5　内部事后报告模板（08 §4）

```
OCJC / OCUVF 内部事后报告 / INTERNAL AFTER-ACTION
报告单位：OCUVF-ID13 指挥官

裁决：HOLD / EVACUATE / EXPOSE / FIRE
经过：……
证据：……
声望：……
建议：……
```

- 报告不是通信；不进通信流。
- 只有出现不良后果，才有「淡化 / 伪造」选项；造假累积 `perjury_count`，触发审计。

## 7　写作检查表

1. **中文主、英文副**：英文是不是只作舰名/型号/缩写？有没有装饰性英文？
