- 传感器显示层权威可选：`V17_SENSOR_AUTHORITY=authoritative`，默认 shadow

## 仍明确未做的边界

1. **完整 detection/fusion 权威**：传感器默认仍 V15 legacy；V2 为 shadow。authoritative 仅显示层偏好，不接管 detection/fusion/威胁。
2. **真实推力/接触动力学**：导航/对接为规划与状态机；不执行真实推力、质量消耗、接触力、结构损伤。
3. **真实星历**：地月物理为圆轨道 + CR3BP 近似/RK4，非 JPL 星历；固定站体为 L1 局部近似/站保持占位。
4. **武器/火控**：未实现。
5. **IFF/ELINT/COMINT/EW**：shadow 模型与 HUD 只读；不参与权威融合。
6. 信息作战页视觉偏空，属于功能页，不是最终美术页。
