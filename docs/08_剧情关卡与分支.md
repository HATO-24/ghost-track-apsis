# 08 剧情、关卡与分支

> 状态：权威。来源：用户新剧本 + `07`/`15`。用户后续会继续补战斗呈现/中后期内容。

## 1 序章流程

1. 玩家在 L4-02 就任。
2. 玩家名输入（中日英；IME；过滤特殊符号）。
3. 世界观/时代背景报幕 CG。
4. 就职公文（含玩家名）+ 指挥终端登录动画。
5. 仅序章出现的行动简报 CG：Chronos 爆炸、核查组失联、Order 7、ID13 任务、ROE。
6. 关闭简报 → 副官通话 → 教学开始。
7. 教学：指挥终端、导航页、设目的地 L1 Meridian、离港申请、变轨窗口、点火、加速、抵达 L1。
8. 入港模式：选择 Chronos、并轨、加注/检查。
9. 谷神-2 故障船：被动传感器 → 数据链 L2 → 光学凝视/ELINT/IFF/灯光 → L3/L4。
10. 救援抉择：派遣拖船；拖曳/加油/船坞系统。
11. Chronos 港务通信 + 私人通信 + 证据/遥测/黑匣子行动菜单。
12. 窗口期结束，AV-4412 抵达；若提前开雷达则提前触发。
13. 对峙/谈判：强硬/标准/质疑/退让。
14. 事后报告；根据完成项/上报选择进入分支。
15. 后续章节：GHOST TRACK 线/程序正义线/错付正义线/守口如瓶线/多结局。

## 2 功能需求

### 2.1 导航/航行

- 全舰队/单舰选择目的地；
- 自动轨道规划 + 手动轨道控制；
- 离港/变轨窗口/点火/加速；
- 入港模式：并轨/对接/加注/船坞；
- 实际轨道动力学；UI 只显示符号。

### 2.2 港口/特殊舰只

- 加油（油船/港口）；
- 拖曳（拖船-目标约束）；
- 船坞（修理/改装）；
- 穿梭机（调查/救援/取证）；
- 单舰指挥、编队；
- 港口事故/失能船只的悬浮操作窗口。

### 2.3 识别

- 数据链自动 L1→L2；
- 光学凝视/ELINT 指纹/IFF/灯光 L3/L4；
- 可见光灯语四位代码；
- 接触列表/目标牌/身份分级；
- 不明≠敌意。

### 2.4 通信/证据

- 标准通信格式；
- 港务/私人/全队通信；
- 动态发送者/接收者/模式；
- 行动菜单动态生成；
- 证据：港务遥测、黑匣子、ELINT 特征码；
- 私人通信/副官建议/信任。

### 2.5 对峙/谈判

- AV-4412 从 UEG 港按真实轨道出发；
- 窗口期；提前雷达触发；
- 谈判页面：强硬/标准/质疑/退让；
- ROE 自动切换 TIGHT + 火控照射（强硬）；
- 退让彩蛋结局；
- 报告与分支。

## 3 状态/数值

### 信任（副官）

- 接受/拒绝建议、是否上报、调查行为、道德选择；
- 阈值决定是否进入 GHOST TRACK/AEUG 线；
- 多次拒绝才彻底关闭，不是一次拒绝。

### 道德

- 救援/撤离/取证/谈判/报告；
- 影响特殊 NPC 态度/分支；
- 参考 Highfleet 的隐性倾向，不做成明面数值条（可选）。

### 声望/威胁

- 对清算者威胁等级；
- 对 OCU/UEG/殖民地声望；
- 影响后续增援/谈判/结局。

### 证据

- `port_telemetry`、`inspection_blackbox`、`elint_signature`、`evacuation`；
- 取证/上报/隐藏决定分支。

## 4 分支

| 线 | 条件 | 结果 |
| --- | --- | --- |
| 程序正义线 | 取证完整 + 谈判质疑 + 报告上报 | UEG 压下调查；后续解散/围剿/隐藏奇迹 |
| GHOST TRACK 线 | 不上报 + 政治倾向 + 高信任 + 调查 | 揭真相/决战/殖民地救世主 |
| 错付正义线 | 不上报 + 倾向 + 低信任/线索不全 | 副官坦白/移交或拒绝/多种结局 |
| 守口如瓶线 | 政治倾向弱 + 高信任 | 副官坦白/OCUVF 解散/分道扬镳 |

分支必须由功能状态驱动，不靠单一对话选项。
