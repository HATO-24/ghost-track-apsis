# 启动 CG 两版

> P7。两版都是原创画面、文案与合成音效；没有复刻 Marathon 的镜头、Logo、音频或具体资产。

## 1　电影化版（备用，`DSH_INTRO_STYLE=marathon`）

`DSH_INTRO_STYLE=marathon`，17.0 s，可点击/任意键/SKIP 跳过。默认不启用。

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–2.2 s | SIGNAL 07 | 黑场白闪、垂直信号柱、橙色扫描块；`SIGNAL 07 / CHRONOS`；被截获广播与“第九天” |
| 2.2–6.2 s | 轨道 | L1/Chronos 暗面行星、轨道环、站体标记、`07` 大号编号；`清算者正在接管储罐区。你只有六分钟。` |
| 6.2–9.4 s | 故障 | 几何头盔剪影、面罩光带、RGB 分离块；`ID13 / 你不是第一个`；`不要相信清算者` |
| 9.4–12.8 s | 标题 | `GHOST TRACK` / `APSIS` 大字距标题，红色残影先落，青色副题后落 |
| 12.8–17.0 s | 字幕卡 | `RECOVER WHAT THEY LEFT.` / `DO NOT TRUST THE RECLAIMERS.` / `YOU ARE THE VARIABLE.`；硬切 |
| 17.0 s | 菜单 | 切到主菜单 |

风格要素：电影遮幅、低照度冷色、橙色/青色高对比、固定 seed 噪点与故障块、极短字幕卡、冷峻任务简报式叙事。全部为 2D 程序化绘制，不依赖外部贴图或视频素材。

## 2　终端版（默认）

`DSH_INTRO_STYLE=terminal`（默认），8.8 s；冷启动自检 → 地月线框 → 标题 → 菜单。

## 4　复现命令

```powershell
$godot = "D:\GHOST TRACK_APSIS\tools\godot\Godot_v4.7.2-stable_win64.exe"
$env:DSH_INTRO = "1"
$env:DSH_INTRO_STYLE = "terminal"   # 默认；marathon 为备用电影化版
$env:DSH_SHOT = "D:\GHOST_TRACK_APSIS\mockups\p7-cg.png"
& $godot --path "D:\GHOST_TRACK_APSIS\game_v15"
```

截图钩子：`DSH_INTRO_T=<秒>` 冻结任意帧；`DSH_INTRO=menu` 直接进菜单；`DSH_SKIP_INTRO=1` 直接进游戏。
