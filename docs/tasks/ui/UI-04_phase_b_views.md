## 3. 权威字段与可见性

编制服务写合法性/资源约束，部署服务写稳定实例和实际部署状态，逐舰运行态写真实资源/能力；界面只显示。协同协议写request/receipt/execution生命周期和已报告原因；玩家只读授权友军摘要、最近报告/年龄与已共享位置，不读AI全量任务栈或敌方真值。observed_t/received_t、ETA单位模拟秒，缺ETA不填预计值。显示名安全解析，实例ID仅非显示路由。

## 4. 实施交接

1. UI-04a字段表分名册可选性、编制约束、选中舰配置/能力、部署前检查/结果；非法原因贴近确认动作，等待/失败不伪装成功。
2. UI-04b定义独立友军摘要、可请求动作、已发送/送达/接受或拒绝/执行/完成或失败；按实际协议排序，不能把OrderService QUEUED统一译为未发送。
3. 折叠舰队、按任务显示相关图层；未选舰不出击、资源不串舰由B1业务实现并验；UI不可绕过检查直接生成实体/扣资源。
4. 页面接入与业务实现分提交、同最终候选联调；友军失联/资源不足/受损给实际报告，未收到就注明未确认，不写假回执。
