# UI-02：字体测量、可读尺寸与组件视觉统一

状态：消费链/测量样本可并行准备；运行时WAIT UI-01与字体/密度方案核对。风格与语义依据[60](../../60_Astra_UI与文案设计规范_交Sol.md)，依赖[61](../../61_UI文案台账与实施队列.md)。

## 1. 目标与现状

主要操作/状态在1920×1080、1600×900及放大UI后都读得清、点得准，保留复古终端气质。当前大量7/9px token、固定基线偏移，配置字体文件与实际SystemFont路径分离；改配置不等于实际使用。历史图的小字不作可读性豁免。

## 2. 基线、依赖与范围

取证main3045311657609dfe10a133802b93dde2fc8abb79；开工填写A1/UI-01最终40位SHA。允许Fonts/TextMetrics/LayoutTokens/PanelPainter及实际消费它们的有限HUD组件和必要字体资源/打包；先标唯一生效色板与度量入口。一个实施者串行接入，禁止同时在pal与JSON建立互不相干色板；不重新接回旧state.gd、不改物理/授权/情报/布局业务。

## 3. 单位与权威

实际加载Font资源给出字符宽/ascent/descent/行高；布局token保存可解释的尺寸/间距/状态色，最终可见像素随分辨率/UI比例记录。1920×1080、100%主操作/状态14–16px、次要12–14px为首轮建议，关键读数更大；不是一刀切全token。字体回退、打包路径、系统/平台差异需明确，未打包不能宣称全平台已验收。显示状态来自获准view，字体层不补造文本/数值。

## 4. 实施与提交

1. 记录当前实际Font、系统回退、palette消费链和测量样本（中文、数字/单位、小数、Δv/ROE/IFF、长舰名、混排）。
2. 先统一实际度量与缓存失效（字体/字号/比例变化后重算），处理中文/等宽基线和单位间距；不靠字号+固定偏移假装对齐。
3. 再应用语义字号、行高、padding、稳定动作/命中区域与focus规则。长名允许可展开省略，命令对象/单位/失败原因不无提示裁断。
4. 最后收敛配色/线框/选中/告警：绿白常态、磷光绿重点、琥珀注意、红危险；兼有文字/形状。扫描/辉光/减少动态设置对实际绘制生效。

## 5. 验收

1920×1080与1600×900，100%及建议125%缩放（比例先核对）均测试；主要文字不能靠缩回6–9px塞满。正常/禁用/焦点/选中、长名、无数据/过期、密集表格、中文数字混排、字体资源缺失回退、关闭装饰都有样张。鼠标命中与视觉框一致，键盘焦点可见且不被重绘抢走；状态不能只靠颜色。业务输出及旧profile行为不变。

## 6. 命令与证据

复用UI-01专项与原C回归（修改共享显示/输入后执行）；必要度量fixture记录实际字体和测量量，验证混排基线/裁切/比例变化，不能只断言token==新数字。以正式非headless入口取得每个分辨率/比例的页面图，附实际字体名/资源、有效尺寸、绘制rect/命中rect、人工阅读/点击/键盘结果。Linux/macOS未经实际验证继续NOT RUN，衔接既有#50，不扩称完成。

## 7. 旧失败与局限

不刷新7项历史失败或放宽几何精度；资源清理stderr与业务错误分开。字体可用性和布局节奏需要实机，不以headless或历史截图替代；不为风格删真实错误、预览标识或观测不确定性。

## 8. 交付

消费链/度量报告、有限组件diff、资源打包说明、跨尺寸前后图和回归；Sol核对文字完整，Astra核对复古气质/密度，负责人评估阅读体验。明确哪些组件仍未迁移，UI-03在已收敛组件上推进。
