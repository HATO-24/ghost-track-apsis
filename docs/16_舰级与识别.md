## 0　一句话

> **船有名字，人有编号。**
> 识别一条船 = 读它的**编制语言**（舰级 / 舰种 / 舰名 / 舷号）+ **四位数批号** + **六级身份** + **六级威胁**；
> 探测等级 L1–L4（看得多清）与身份（政治上是谁）是两条轴，不混。

## 2　身份的五层（04 §12）

| 层 | 是什么 | 谁定 | D2 例 |
| --- | --- | --- | --- |
| **厂商型号** | 原厂型号或改装型号 | 船厂 / 舰队改装记录 | 刺桐-2M、赤铁-6 改 |
| **舰级 / class** | 内部条令的舰级名 | 第33舰队条令 / OCUVF 编制 | 远地点级；清算级、执刑级等 |
| **舰种 / type** | 舰体规模与战术角色 | 舰队条令 | 船坞舰；战列舰 BB、重巡洋舰 CA、轻巡洋舰 CL、驱逐舰 DD、护卫舰 FF、通报舰 AV |
| **舰名** | 专名 | 命名机构 / 船员 | 远地点、哈马丹、湮没者 |
| **舷号** | 登记号 | 舰队登记处 | 001、114、4471、4412 |

- 任务职能（哨戒、封锁、追索、征用等）是任务分配，不属于舰船身份层。
- 第33舰队主标识 = **类型代码 + 4 位登记号 + 舰名 + 舰种**；内部舰级（如「传唤级」）可以出现在条令/简报里，但**不作主标识**。
- OCUVF 侧没有正式舰级：**型号 +「改」+ 舰名 + 三位数舷号**。

| 执刑级 | 重巡洋舰 | CA | 执刑 / 旗舰 | 出现即意味着终局 |

- 单舰名三种语域：**施事者**（裁夺者、湮没者、抹除者…）、**不可动摇**（不移、无赦…）、**权威**（终局、铁律…）。

- 单舰全称例：**执刑级重巡洋舰，湮没者，CA-4471，旧名白霜**。

## 5　第一关接触识别（07 §2/§3、19 §2）

批号是**融合系统的编号**，不是舰名/舷号：`1000–1999` 友军/已知、`2000–2999` 敌对（清算者）、`9000–9999` 不明/民用/已确认无威胁。

| 批号 | 名称 | 舰种 / 阵营 | 身份初值 → 事件后 | 第一关提示 |
| --- | --- | --- | --- | --- |
| 1000 | 远地点（APSIS 001） | 远地点级船坞舰 / ID13 旗舰 | 友方 | 母舰，不可损失 |
| 1001 | 哈马丹（114） | 托盘-5 改哨舰 / ID13 | 友方 | 舰队传感器节点（YW-R9 / MS-OT2 / CH-IR2 / ELINT） |
| 1002 | 渡口 | 赤铁-6 改炮舰 / ID13 | 友方 | 请求武器释放授权（默认驳回） |
| 1003 | 望楼 | 安海-1 中继舰 / ID13 | 友方 | 激光中继，命令延迟 8 s；被击毁 → 45 s |
| 1004 | 深井 | 月港-4 油船 / ID13 | 友方 | 全队航程 |
| **2001** | **AV-4412 传唤者** | 传唤级通报舰 / **清算者（第33舰队）** | 未知 → 光学分类后 **可疑**（威胁=高） | 送达 Order 7；礼貌、程序化；不先开火 |
| 9001 | 谷神-2 | 远环合作社通用工作船 / 民用 | 待定/未知 → IFF/光学确认后 **中立**（威胁=无威胁） | 应答机故障，漂移；「不明 ≠ 敌意」 |
| 9002 | 无威胁目标 | 残骸 / 反射（不是船） | 待定 → **已交叉确认 · 无威胁**（威胁=无威胁） | 交叉确认后从目标列表移出/标灰，不再当敌人 |

**三层分开显示**：

1. **批号**（识别号）；2. **身份**（政治上是谁：友方/中立/可疑/敌方…）；3. **探测等级 L1–L4**（看得多清：仅方位 → 定位 → 舰级分类 → 具体识别）。

- IFF 无应答只能到 **未知/可疑**，不能自动判敌；**敌方（Hostile）需要证据 + ROE**。
- 第一关默认不交火：开火 = 灾难分支（FIRE），不是常规玩法。

| 身份 | English | 定义 | UI 色/形 |
| --- | --- | --- | --- |
| 待定 | Pending | 刚发现，还不知道是什么 | 灰；虚线方框/问号 |
| 未知 | Unknown | 雷达看见，但 IFF 无回应、ELINT 无特征码，无法判明 | 琥珀；菱形 |
| 假定友好 | Assumed Friend | 加密 IFF 应答、飞行计划比对或 PPLI 广播，但尚未完全确认 | 浅蓝；虚线圆 |
| 友方 | Friend | 己方/盟军资产，身份确认 | 薄荷绿；实心圆 |
| 中立 | Neutral | 民间船只或其他非参战国资产 | 灰绿；方形 |
| 可疑 | Suspect | 表现出不友好举动，高度怀疑是敌军，但未满足交战规则 | 橙；三角形 |
| 敌方 | Hostile | 确认敌对目标，满足交战规则 | 红；菱形/实心 |

## 7　威胁等级（P1k，与身份分开）

身份回答「政治上是谁」，威胁回答「现在该不该把它当威胁」；两者独立显示（接触行右端身份徽章 + 底部威胁图例）。

| 威胁 | English | 含义 | 第一关例 |
| --- | --- | --- | --- |
| 无威胁 | NONE | 已确认不构成威胁 | 友军；9001 确认中立后；9002 已交叉确认 |
| 低 | LOW | 存在不确定性但无主动敌意 | 民用/待确认但无武装迹象 |
| 中 | MED | 行为异常、需保持监视 | 未判定目标的默认档 |
| 高 | HIGH | 高度怀疑敌对、但未满足 ROE | **2001 AV-4412 传唤者**（光学分类后） |
| 确认敌对 | HOSTILE | 证据 + ROE 满足，可交战 | 第一关默认不出现（FIRE 是灾难分支） |
| 待判定 | PENDING | 信息不足，威胁未评估 | 新接触/9002 确认前/9001 确认前 |

- UI：接触行右侧身份徽章；底部图例以威胁为主（详见 `docs/09` §17）；图上符号也按身份/威胁区分，不只靠颜色。

## 8　GHOST TRACK 的识别

- **对 UEG 文书系统**：OCUVF-ID13 是最新编制，不在 UEG 非法舰队名册上 → 传感器/文书里是一条**没有登记的航迹（GHOST TRACK）**。
- **对玩家**：第33舰队也有自己的 GHOST TRACK——内部黑单位/试作改装群（T3 式）：假旗、抹航迹、试作舰。
  - 第一关的假旗痕迹是 **EXPOSE** 的证据链：Chronos 港务遥测 + UEG 核查组黑匣子 + 一条「任何厂商型号都对不上」的 ELINT 特征码；三件拿两件才能走 EXPOSE。
  - L2-04 Argus 的光学阵列「能拍到不像任何已知船的航迹」；L4-08 Crucible（拆船/黑市）可能流出原型零件；L2-09 Silent（月背静默站）可能是其测试点。
- 它不是可选阵营，也不显示成一个可点击单位：**只在证据、无线电、日志、报告里出现**。

## 9　Act 与 Phase（作者侧）

- 任务单位 = **Act**：Act 1 = **Chronos（L1 Meridian-05）**；战役 = Act 1/2/3/4。Act 2 = **永昼（月面特许领）**。
- 关内阶段 = **Phase 1/2/3**（读 / 令 / 赌）；不使用 beat / 三拍 / Scene。
- **两者只用于作者侧/代码状态机，游戏内不显示**；游戏内只显示目标（如「越权回收」）与局面。
