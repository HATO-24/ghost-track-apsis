- 游戏内 UI 全符号；物理层保留轨道/站体/端口数据；近景模型在美术阶段。

## 7 ROE/授权

- 序章后解锁。
- 四档：WPN DEFEND / HOLD / TIGHT / FREE。
- 三级授权：TRACK / SOLUTION / FIRE；范围：单目标/武器组/单舰/全舰队；持续 N 秒或直到目标摧毁。
- HOLD：三级手动授权；TIGHT：TRACK 自动，SOLUTION/FIRE 一次确认；FREE：对敌对自动 TRACK/SOLUTION，FIRE 手动确认。
- 身份变化/友军进射界/弹药不足→自动降级 TIGHT/HOLD，UI 提示。
- 未知/中立仍需授权。

## 8 轨道/星历
