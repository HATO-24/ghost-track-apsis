> 状态：提案稿。本文回答：**舰船长什么样、为什么长这样、里面怎么运作、玩家怎么从剪影里读出威胁**。

## 0　一句话

> 这些船不是飞船，是**没有窗户的建筑物**。
> 它们从出生到拆解都在轨道上，靠一堆散热片活着，
> 剪影就是它们的履历表。

## 1　三条舰船法则

### 1.1　第一法则：Δv 只看燃料比，不看吨位

```
Δv = Isp · g₀ · ln( 1 / (1 − f) )      f = 燃料质量 / 总质量
```

同样 30% 燃料比、同一种推进，一千吨的船和一万吨的船，Δv **一模一样**。

> **吨位买的是推力、装甲、传感器和载荷；燃料比买的是航程。**

推论：**油船是全队航程最远的船，也是全队最慢的船**。它不是后勤，它是战略武器。

### 1.2　第二法则：剪影即教义

本作用线框渲染，剪影是唯一稳定的信息通道。所以外形不能"设计"，只能**推导**：

| 舰体特征 | 玩家读出的信息 |
| --- | --- |
| 散热片总面积 | 热负荷 → 武器功率、反应堆规模 |
| 散热片是否对称 | 是否受损、是否在应急散热 |
| 燃料舱占比 | 航程 / 是不是油船 |
| 装甲带厚度 | 抗打程度、是不是有人舰 |
| 桅杆高度 | 传感器孔径 → 探测距离 |
| 外挂罐数量 | 远征状态 / 临时改装 |

**设计规则：任何一个外形特征，如果不能被玩家读成一条战术信息，就删掉。**

### 1.3　第三法则：船厂即身份

一艘船的外形不是设计师决定的，是**船厂的生意模式**决定的：泉州有大坞和政府订单，所以它造得整齐；车肆靠修船起家，所以它的船永远像没造完；永昼的船本来是压力容器，只是有人后来加了炮。

**玩家在 L2 接触等级下，先认出的是船厂，不是阵营。**

## 2　物理基线

### 2.1　Δv 表（核热 900 s，ve = 8826 m/s）

| 燃料比 f | 质量比 | Δv |
| --- | --- | --- |
| 20% | 1.25 | 1.97 km/s |
| 25% | 1.33 | 2.54 km/s |
| 30% | 1.43 | 3.15 km/s |
| 35% | 1.54 | 3.80 km/s |
| 50% | 2.00 | 6.12 km/s |
| 70% | 3.33 | 10.63 km/s |

### 2.2　续航公式

```
全推续航 t = f · ve / a
```

与吨位无关，只与燃料比和加速度有关：

| 舰种 | f | a | 全推续航 |
| --- | --- | --- | --- |
| 哨舰 | 0.25 | 0.15 g | 25 min |
| 炮舰 | 0.30 | 0.10 g | 45 min |
| 弹舱舰 | 0.35 | 0.08 g | 66 min |
| 中继舰 | 0.20 | 0.12 g | 25 min |
| 油船 | 0.70 | 0.01 g | 17.5 h |
| 母舰 | 0.30 | 0.02 g | 3.8 h |
| 拖船 | 0.30 | 0.20 g | 22 min |
| 舰载穿梭机 | 0.50 | 1.0 g | 7.5 min |

> 舰载穿梭机只能烧七分半钟。这不是缺陷，这是它的全部设计：**它只需要跑一趟。**

### 2.3　传感器梯度：探测便宜，识别昂贵

真实的红外物理决定了：**在太空里藏不住。** 三百度的船体对着三度的背景，十万公里外就能被看见。

所以本作的"看不见"不发生在**探测**层，发生在**识别**层：

| 层级 | 物理手段 | 代价 | 对应接触等级 |
| --- | --- | --- | --- |
| **探测**（有没有） | 被动红外，大孔径 | 几乎免费 | L1 |
| **定位**（在哪） | 三角测量 / 主动雷达 | 需要第二个平台，或暴露自己 | L2 |
| **识别**（是谁） | 光学、光谱、信号特征 | 需要时间与接近 | L3 |
| **确认**（叫什么） | 数据库比对、无线电问答 | 需要情报，或对方配合 | L4 |

> 反过来说：**干掉对方的哨舰，比干掉对方的炮舰有用。**

## 3　推进系统

### 3.1　三种发动机，三种哲学

| 类型 | Isp | 推力 | 推进剂 | 用途 | 为什么是它 |
| --- | --- | --- | --- | --- | --- |
| **化学** | 320 s | 高 | 可贮存（肼类 / 四氧化二氮） | 战术机动、姿态、末段修正 | **能立刻点火**，不用等冷却和预热 |
| **核热** | 900 s | 中 | 液氢 | 战役转移、主要航程 | 比冲够用，推力够大 |
| **电推** | 3000 s | 极低 | 氩 / 水等离子 | 长期轨道调整 | 慢，但能把航程翻三倍 |

化学推进用可贮存推进剂，比冲只有 320 s，因为**战术机动的船不能等加注低温燃料**。这是一个真实的取舍，不是数值平衡。

### 3.2　推进剂从哪来

```
月冰 → 水 → 电解 → 液氢 + 液氧
1 kg 水 → 0.111 kg H₂ + 0.889 kg O₂
```

- 核热用液氢
- 化学用液氧 / 液氢（或可贮存肼类，由地球运来，贵十倍）
- 电推用氩，从月壤提取

**所以冰不只是燃料，冰是整条供应链的起点。** 这就是为什么一份关于采冰区的裁定能引发战争。

### 3.3　沸腾：停着也在漏油

液氢沸点 20 K。再好的绝热层也挡不住漏热：

```
日蒸发率 ≈ 0.2%–0.5%（良好绝热）
```

一艘带 300 吨液氢的船，停三十天损失 **18–45 吨**。

> **你停得越久，油越少。**

对策有三种，都要付代价：

| 对策 | 代价 |
| --- | --- |
| 主动制冷 | 持续耗电，反应堆不能停 |
| 太阳屏蔽 | 增加质量与转动惯量 |
| 尽快烧掉 | 你得决定去哪，而决定本身要情报 |

**加注站之所以是战略资产，不是因为它有油，是因为它有电和散热，能做零蒸发贮罐。**

### 3.4　发动机布局

核热发动机需要**阴影屏蔽**：反应堆和乘员之间必须有距离，且屏蔽体要在一条直线上。这条约束直接决定了船为什么是长的、桅杆为什么在最上面、反应堆为什么在最下面。

| 部件 | 位置 | 为什么 |
| --- | --- | --- |
| 发动机集群 | 舰艉，4–9 台 | 可万向 ±10°，兼作俯仰/偏航控制，省 RCS |
| 推力结构 | 贯穿全舰的脊梁 | 推力要从发动机传到最前端的载荷 |
| 反应堆 | 舰艉段 | 远离乘员，便于散热 |
| 阴影屏蔽 | 反应堆与住舱之间 | 挡住中子和伽马 |
| 乘员舱 | 舰体中前部 | 屏蔽阴影里 |
| 桅杆 | 舰艏最前端 | 离反应堆最远，视线最好 |

### 3.5　RCS：最贵的小动作

- 冷气或过氧化氢，Isp 150–200 s
- 推力小，但响应快
- **姿态调整消耗的推进剂不计入主发动机的 Δv，但一样会耗尽**

一艘船在轨道上"转身"几十次，消耗的推进剂可能相当于一次像样的变轨。这是玩家最容易忽略的一笔账。

## 4　能源与热管理

### 4.1　电从哪来

| 来源 | 功率密度 | 限制 |
| --- | --- | --- |
| 核热发动机带动布雷顿循环 | 数 MW | 只有主发动机工作时才有 |
| 专用反应堆 | 1–10 MW | 重，需要独立屏蔽与散热 |
| 太阳能 | 1 AU 处 1361 W/m²，效率 20–30% | 面积大，且和散热片抢地方 |
| 电池 / 飞轮 | 峰值 | 只能撑几分钟 |

### 4.2　一艘炮舰的电力预算

| 系统 | 常态 | 峰值 |
| --- | --- | --- |
| 生保 | 50 kW | 50 kW |
| 传感器 | 80 kW | 400 kW（雷达开机） |
| 通信 | 20 kW | 200 kW（激光） |
| 轨道炮 | — | 2 MW（电容充电） |
| 近防炮 | — | 300 kW |
| 热管理泵 | 100 kW | 400 kW |
| **合计** | **约 250 kW** | **约 3.3 MW** |

> 装机 3 MW，常态只用 250 kW。**多出来的电不是浪费，是"随时能开火"的权利。**

### 4.3　散热：热是唯一的硬约束

```
P = ε · σ · A · T⁴        σ = 5.67×10⁻⁸
```

| 废热 | 350 K 需要的面积 | 600 K 需要的面积 |
| --- | --- | --- |
| 1 MW | 1,176 m² | 136 m² |
| 5 MW | 5,880 m² | 680 m² |
| 20 MW | 23,500 m² | 2,720 m² |

**温度翻倍，面积降到十六分之一。** 所以所有船都想把散热片烧得更热——但越热，红外特征越亮。

| 策略 | 散热片 | 红外 | 雷达 |
| --- | --- | --- | --- |
| 低温大排 | 巨大 | 暗 | **亮**（面积大） |
| 高温小排 | 小 | **亮** | 暗（面积小） |

> **这是本作给玩家的一个真实两难：躲红外还是躲雷达。** 不能两个都躲。

### 4.4　热汇：静默的代价

关掉散热片，把热存进热汇（水、熔盐）：

```
5 MW × 300 s = 1.5 GJ
水：4.2 kJ/(kg·K) × 100 K = 420 kJ/kg
需要约 3.6 吨水
```

> **静默五分钟，代价是三吨水。**

这就是本作的"静默航行"：物理上成立，时间上有限，代价是水——而水既是燃料原料，也是生命线。

### 4.5　散热片是命门

散热片是最大的雷达反射面、最大的红外特征、最容易被破片打烂的部分，也是全舰唯一不能装甲的东西。

**打散热片 = 不打穿船体也能让它失去战斗力。**

## 5　防护

### 5.1　为什么不能全装甲

```
1 m² 的 10 cm 钢 = 0.785 t
1000 m² 的外壳 = 785 t
```

785 吨超过一艘炮舰的全部干重。所以装甲只能**选择性**：

| 部位 | 装甲 | 理由 |
| --- | --- | --- |
| 乘员舱 | 2–5 cm 钢当量 | 人不能换 |
| 反应堆 | 5–10 cm + 屏蔽 | 打穿了就是核事故 |
| 火控 / 弹药 | 3–5 cm | 一次命中就失去战斗力 |
| 燃料舱 | 1–2 cm | 主要靠隔舱，不靠装甲 |
| 散热片 | **0** | 装甲了就不散热 |
| 桅杆 / 传感器 | **0** | 装甲了就不透波 |

### 5.2　惠普尔屏蔽：所有船都有的那层皮

```
薄外层（1–3 mm）→ 间隙（10–30 cm）→ 内层（承载壳）
```

高速碎片打在薄外层上被撞碎、分散，内层只需承受剩下的部分。

轨道上全是垃圾，所以**每一艘船都有这层皮**。它被打穿之后，用钢板补上——这就是剪影上那些"补丁"的来源。

> 补丁不是美术风格，是维修记录。

### 5.3　四个弱点

1. **散热片** —— 热管理失效，船变成烤箱
2. **桅杆** —— 传感器失效，船变成瞎子
3. **喷管** —— 推力失效，船变成靶子
4. **对接环** —— 结构失效，船断成两截

**所有战术都围绕这四处展开。** 装甲再厚，打这四个地方就够了。

### 5.4　点防御

- 近防炮：拦截末段导弹
- 诱饵：欺骗导引头
- 机动：消耗导弹的 Δv

点防御的边界是**拦截窗口**：导弹末段飞行时间只有几秒，来不及就是来不及。

### 5.5　辐射

| 威胁 | 对策 |
| --- | --- |
| 反应堆 | 阴影屏蔽 |
| 太阳质子事件 | 风暴掩体（用水或推进剂做屏蔽） |
| 长期在轨 | 服役期限、药物、轮换 |

**轨道居民在生理上不属于地球。** 长期低重力让他们回不去——这不是法律问题，是骨头的问题。

### 5.6　大气与火

舱内是 21% 氧 / 79% 氮，不是纯氧。纯氧在太空里等于自杀：一根电线短路就能烧掉整条船。

损管队是船上最危险的工作，因为他们要在失压和起火之间选一个。

## 6　整体设计

### 6.1　模块化：船是积木

| 接口 | 规格 | 用途 |
| --- | --- | --- |
| 主对接环 | 2.4 m | 舰与舰、舰与站 |
| 辅助对接环 | 1.2 m | 补给、人员、缆线 |
| 标准货柜接口 | 2.4 m × 2.4 m | 任务模块、外挂罐、弹药 |

**所以船可以改。** 一艘货船加两个货柜接口就能当弹舱舰；一艘拖船加一个模块就能当扫雷舰。这是公约舰队"拼装"风格的物理基础。

### 6.2　建造：没有一样东西是为了好看

- 轨道船坞分段建造，焊接是主要工艺
- 没有气动外形，没有起落架，没有整流罩
- 船坞的尺寸决定船的尺寸上限
- **每一根线条都是被预算逼出来的**

### 6.3　居住：没有重力

- 没有旋转舱（太重，且转速一高就晕）
- 全员自由落体，靠扶手、系绳、睡袋
- 锻炼两小时/天，仍然会骨质流失
- 服役期有限；回地球是奢侈的

> 这就是为什么轨道人管地球叫「原乡」——一个他们回不去的地方。

### 6.4　生保：水是三合一的

```
水 = 燃料原料 + 饮用 + 辐射屏蔽
```

闭式循环回收 90% 以上，剩下的靠补给。**一艘船的水储备同时是它的航程、它的生命、和它的掩体。**

### 6.5　舰体布局：塔楼不是船

船在加速时"下"是舰艉，在滑行时没有"下"。所以舰体不是横躺的船，是**竖着的塔**：

```
        ┌─ 桅杆 / 传感器
        │
      ┌─┴─┐
      │舰桥│        ← 最高、最远、最冷
      ├───┤
      │住舱│
      ├───┤
      │装甲带│      ← 包住住舱与推进剂
      ├───┤
      │燃料舱│      ← 体积最大，占了剪影的一半
      ├───┤
      │反应堆│
      ├───┤
      │发动机│      ← 推力轴，也是"地板"
      └───┘
   ╱散热片╲  ╱散热片╲   ← 横出的"翅膀"，最脆弱
```

### 6.6　没有窗户

不是因为装甲，是因为**没什么可看**：交战距离在几十到几百公里，肉眼看不见。舰桥是一个黑房间，玩家看到的画面**就是**传感器融合的结果。

> 这一条把 01 的 HUD 设计与世界观焊死了：**玩家看到的就是船员看到的。**

### 6.7　满身扶手

滑行时全员自由落体，舱外作业靠扶手和系绳。线框渲染里，这些扶手是**免费的纹理**——几百条短线，成本几乎为零，质感极强。

## 7　舰种表

公约舰队不设计船，它**买船、改装船、然后把船用坏**。所以每一个舰种背后都有一家船厂、一个型号、一段来历。

| 角色 | 型号 | 厂商 | 干重 | f | Δv | a | 编制 | 失去它的后果 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 哨舰 | 托盘-5 改 | 车肆重工 | 300 t | 0.25 | 2.54 | 0.15 g | 12 | 你瞎了 |
| 炮舰 | 赤铁-6 改 | 永昼机械 | 1200 t | 0.30 | 3.15 | 0.10 g | 68 | 你打不死任何人 |
| 弹舱舰 | 龙门-3M | 车肆重工 | 900 t | 0.35 | 3.80 | 0.08 g | 24 | 你打不着任何人 |
| 油船 | 月港-4 | 泉州重工 | 2000 t | 0.70 | 10.63 | 0.01 g | 18 | 全队回不了家 |
| 中继舰 | 安海-1 | 泉州重工 | 500 t | 0.20 | 1.97 | 0.12 g | 30 | 命令延迟 8→45 s |
| 拖船 | 绞盘-2 | 车肆重工 | 400 t | 0.30 | 3.15 | 0.20 g | 9 | 你救不回任何人 |
| 船坞舰 | 刺桐-2M | 泉州重工 | 9000 t | 0.30 | 3.15 | 0.02 g | 240 | 战役结束 |

### 7.1　托盘-5 改 · 哨舰

车肆的轻型运输船。加一根桅杆、两具红外阵列，就是哨舰。它便宜到可以造很多条，也便宜到可以死很多条。

> 哨舰的存活时间，通常等于它发现敌人到你决定撤退之间的那段时间。

### 7.2　赤铁-6 改 · 炮舰

永昼的矿运船。壳厚、罐大、传感器差，因为它本来要在粉尘里挖十年冰。加一门轨道炮，它就是炮舰。

它不是为战斗造的，所以它有两个互相矛盾的特点：**很耐打，但很难瞄准。**

### 7.3　龙门-3M · 弹舱舰

车肆的重货船，货舱改成发射架。四十八个单元，自己只有近防炮。全队真正的杀伤力，也是全队最该被藏起来的船。

> 导弹打光了它就是一条空船。但它比炮舰重不了多少——因为导弹很轻，发射架很重。

### 7.4　月港-4 · 油船

泉州的大船。两千吨干重，装四千六百吨推进剂。全队航程的来源，也是全队最诱人的目标。它一箱油可以让三艘炮舰各做一次大机动。

> 战术上的常见问题不是"打不打得过"，是"打完还回不回得去"。答案通常是月港。

### 7.5　安海-1 · 中继舰

**一百二十米可展开通信/监听阵列**，中央是一台 2 m 孔径激光通信主镜，周围是 ELINT 接收面。它把命令延迟从 45 秒压到 8 秒，代价是自己变成一个巨大的辐射源和一个巨大的靶子。

中继舰不消耗 Δv 传递消息；它只在站位保持和重新部署时消耗 Δv。45 s 和 8 s 都不是光速延迟——L1 单程光速约 1 s，中继省掉的是排队、转手、确认和重传。

**这是本作独有的舰种**，因为它对应本作独有的机制：命令延迟。中继舰被击毁时，玩家感受到的不是"少了一条船"，是"我的命令突然变慢了"。失去它，链路回退到 45 s，HUD 显示 `LINK DEGRADED`。

### 7.6　绞盘-2 · 拖船

车肆的拖船。能拖走一条失去动力的炮舰，能登舰，能捞记录仪。没有它，打赢了也带不走战利品，输了就全军覆没。

### 7.7　咏叹-1 · 舰载穿梭机

奥尔西尼的舰载穿梭机，不是舰队编制里的独立舰种。二十吨，三人，无武装，一 g 加速，由远地点号或船坞舰携带一至两架。通信被干扰、光学和红外链路都断时，它是唯一还能把命令送到的手段；也可以登舰、救援、送人。**它送的不是消息，是你的意志。**

它像联盟号一样小，但任务更脏：没有返回窗口的时候，它可能只飞一次。

### 7.8　刺桐-2M · 船坞舰

泉州的刺桐-2，被公约改成了移动港口：两个维修坞、机加工车间、法庭舱、医院、够全队烧三周的燃料。公约给这个改装型单独一个舰级代号——**远地点级**，首舰「远地点」号，舷号 001。

0.02 g 的加速度意味着它几乎不能机动——它只能被保护，不能被拯救。

### 7.9　不在编队里的船

| 型号 | 厂商 | 为什么提它 |
| --- | --- | --- |
| **后渚-3** | 泉州重工 | 真正的军舰。签约国分遣队才有，玩家只能看着它从旁边开过去 |
| **谷神-2** | 远环合作社 | 外权地的万用工作船。便宜、耐操、到处都有，是最好用的诱饵和最好的掩护 |
| **咏叹-1** | 奥尔西尼 | 舰载穿梭机，旗舰携带 1–2 架。不占舰队编制，但断链时它是唯一的物理传令手段 |

> 编队里没有一条船是为这场战争造的。这就是公约舰队的样子。

## 8　为什么炮舰不是战列舰

这是本作和"太空海战"游戏最大的分野，值得单独说。

轨道炮是瞬时命中，但要打提前量。目标在飞行时间内可以侧向机动：

```
侧向位移 = ½ · a · t²
```

目标以 0.1 g 侧向机动，要让位移小于 50 米（一条船的宽度），飞行时间不能超过 **10 秒**。弹速 6 km/s，对应射程 **60 公里**。

> **轨道炮只能打不会躲的东西。**

| 目标类型 | 能不能打 | 为什么 |
| --- | --- | --- |
| 机动中的战舰 | ❌ | 十秒足够它挪开 |
| 燃料耗尽的船 | ✅ | 它躲不了 |
| 加注中的船 | ✅ | 它不敢动 |
| 空间站、质量驱动器 | ✅ | 它不会动 |
| 已经失去动力的残骸 | ✅ | 处决 |

**炮舰是处决武器，不是决战武器。** 决战靠导弹，靠的是把对方的 Δv 耗尽，然后让炮舰上去收尾。

这个结论直接从牛顿力学推出来，不需要任何"设定"。**它的战术是从物理里长出来的。**

## 9　六种视觉语法

线框渲染里，剪影是唯一的身份证明。**玩家应该能先认出"谁造的"，再认出"谁在开"。**

### 9.1　识别阶梯

| 等级 | 玩家看到 | 读出 |
| --- | --- | --- |
| L2 | 轮廓 | **船厂与型号**：对称重甲＝泉州；模块焊缝＝车肆；鼓形大罐＝永昼；极简快船＝奥尔西尼；裸露桁架＝远环 |
| L3 | 涂装、加改装件、法条带 | **使用方**：公约的哪个分舰队，或者清算署 |
| L4 | 舷号、舰名、案卷号 | **具体是哪一条船** |

**这条阶梯是本文最重要的设计产出**：它把"识别"从一次判定变成三层信息，每一层都可以被骗、被延迟、被摧毁。

### 9.2　五家船厂的剪影

| 厂 | 剪影规则 | 一句话 |
| --- | --- | --- |
| **泉州重工** | 等直径舱段；左右成对的散热片；完整装甲带；焊缝双线且规整 | 太整齐了 |
| **车肆重工** | 3–6 段不等直径；集装箱架；左右散热片独立抽取、尺寸不等；1–3 块补丁 | 永远像没造完 |
| **永昼机械** | 鼓形主舱 + 2–4 个球罐；散热片面积小；外露采矿臂；表面粗糙线 | 压力容器 |
| **奥尔西尼** | 细长；散热片只有一对且小；无外露桁架；化学推进喷管短而多 | 减法 |
| **远环合作社** | 桁架全露；单台大喷管；无外涂装（线框直接是结构）；焊缝不磨 | 它能回来 |

### 9.3　清算署的标准改装件

清算署不造船，它**把没收来的船改成同一个样子**。所以它的识别特征不是船体，是**改装件**：

```
标准散热组件   一对等尺寸散热片，位置固定在舯部（原来的拆掉）
标准桅杆       一套统一规格的传感器桅杆
法条带         一条高对比度色带，绕舰体一周
案卷号         刷三处（艏、舯、艉）
原名           被色带盖住一半，旧漆在色带下隐约可见
```

**底层船体仍然是原厂的。** 所以你会看到一条永昼的鼓形矿船，装着一对泉州的散热片，刷着清算署的条纹。

> 这比"统一的灰色舰队"可怕得多：**它说明这些船本来都是别人的。**

### 9.4　为什么这个差异能成立

| | 泉州 | 车肆 | 永昼 | 奥尔西尼 | 远环 | 清算署 |
| --- | --- | --- | --- | --- | --- | --- |
| 工业 | 大坞、国资 | 修船起家 | 月面重工 | 家族精品 | 合作社 | 没收 |
| 经济 | 政府订单 | 产量 | 资源 | 时薪 | 以物易物 | 托管账户 |
| 时间 | 交付慢 | 永远在改 | 用十年 | 用一次 | 用一辈子 | 刚拿到 |

> 美术差异必须能翻译成一句经济学的话，否则就是装饰。

## 10　损伤即剪影

线框渲染的最大优势：**损伤可以被画出来，不需要贴图。**

| 损伤 | 剪影变化 | 玩家读到的 |
| --- | --- | --- |
| 散热片被打掉一片 | 一侧翅膀消失 | 它在过热，撑不了多久 |
| 燃料舱击穿 | 舰体缩短，尾部有扩散点 | 它回不去了 |
| 桅杆折断 | 顶部变秃 | 它瞎了，但还能打 |
| 装甲剥落 | 外层稀疏线框消失，露出内层密线框 | 它已经没装甲了 |
| 姿态失控 | 整体倾斜，绕轴翻滚 | 它已经不算一艘船了 |

**规则：任何损伤都必须在剪影上留下痕迹，且痕迹必须能被玩家在 1 秒内读出。**

## 11　命名规范

真实海军的舰名同时携带三件事：**传统、建造者、用途**。星际公民的做法更进一步：**厂商本身就是一种语言**——Aegis 的船叫 Sabre、Vanguard，Drake 的船叫 Cutlass、Corsair，Origin 的船叫 300i、890 Jump。听到名字，你就知道是谁造的、卖给谁、打算怎么用。

我们照这个逻辑，把一艘船拆成**四个标识**：

| 标识 | 是什么 | 由谁定 | 例 |
| --- | --- | --- | --- |
| **厂商型号** | 产品名 | 船厂 | 刺桐-2、龙门-3M、赤铁-6 改 |
| **舰队舰级** | 编制代号 | 公约舰队 | 远地点级、龙门级、赤铁级 |
| **舰名** | 专名 | 舰名委员会 | 远地点、哈马丹、背风岸 |
| **舷号** | 登记号 | 舰队登记处 | 001、114、207 |

**为什么要有四个**：因为它们不属于同一个人。船厂管型号，舰队管编制，委员会管名字，登记处管号码。**一艘船的身份是四个机构妥协的结果**——这本身就是这个世界的样子。

**还有一条铁律：一艘船只有一个标准名，是英文。** 其他语言都是本地化。

| English（标准） | 中文（本地化） | 日本語（本地化） |
| --- | --- | --- |
| APSIS | 远地点号 | アポジー |
| HARMATTAN | 哈马丹号 | ハルマッタン |
| LEE SHORE | 背风岸号 | リーショア |
| ANVIL | 铁砧号 | アンヴィル |
| VESUVIUS | 维苏威号 | ヴェスヴィオ |
| DEEPWELL | 深井号 | 深井（しんせい） |
| ANNIHILATOR | 湮没者 | 湮滅者（えんめつしゃ） |
| NO QUARTER | 无赦 | 無赦（むしゃ） |

> 日语本地化有一条规矩：**用汉语词，不用口语短语。** 所以是「無赦（むしゃ）」，不是「容赦なし」——前者是一个名字，后者是一句话。而且用**音读**：舰名是汉语词，不是和语，念法也得是汉语词的念法。

**清算署舰名的日文对照**（同为音读汉语词）：

| English | 中文 | 日本語 | 読み |
| --- | --- | --- | --- |
| ANNIHILATOR | 湮没者 | 湮滅者 | えんめつしゃ |
| ADJUDICATOR | 定谳者 | 裁定者 | さいていしゃ |
| NO QUARTER | 无赦 | 無赦 | むしゃ |
| UNYIELDING | 不移 | 不撓 | ふとう |
| ENDGAME | 终局 | 終局 | しゅうきょく |
| IRON RULE | 铁律 | 鉄律 | てつりつ |
| FINALITY | 既判 | 既判 | きはん |

**船壳上刷的是英文**——公约舰队的工作语言是英语（一支四国联军总得选一种）。**UI 里显示的是你的语言。**

> 所以玩家在剪影上看到的是 `HARMATTAN`，在接触列表里看到的是「哈马丹」。同一条船，两个写法，一个来源。

型号同理：刺桐-2 的国际型号是 **ZAITON-2**（刺桐是泉州古称，Zaiton 是它在中世纪的名字），龙门-3M 是 **GANTRY-3M**，赤铁-6 是 **HEMATITE-6**。

### 11.1　厂商型号

型号名来自各厂的命名语法，详见 [`06_工业与企业.md`](06_工业与企业.md) §8：

| 厂 | 语法 | 例 |
| --- | --- | --- |
| 泉州重工 | 港口与航路 | 刺桐、月港、安海、后渚 |
| 车肆重工 | 工具与物流 | 龙门、绞盘、锚链、托盘 |
| 永昼机械 | 矿物 | 赤铁、玄武、冰晶、云母 |
| 奥尔西尼 | 音乐术语 | 咏叹、夜曲、托卡塔 |
| 远环合作社 | 小行星 | 谷神、灶神、智神 |

型号后面跟一个改型码：

| 后缀 | 意思 |
| --- | --- |
| `-1` | 原型 |
| `-2` | 量产 |
| `-3` | 大改 |
| `M` | 军规 |
| `改` | 战地改装，没有图纸，没有验收 |

> 「龙门-3M」：车肆的龙门级重货船，第三代，军规型。
> 「赤铁-6 改」：永昼的赤铁级矿运船，第六代，但**不是军规**——是有人在船坞里自己加的炮。

### 11.2　舰队舰级与舰名

大多数时候，**舰级就是型号**：龙门级、赤铁级。只有一种情况舰队会另给代号：**它改装得太多，已经不是原来那条船了。**

| 情况 | 舰级 | 例 |
| --- | --- | --- |
| 原样采购 | 型号即舰级 | 龙门级弹舱舰 |
| 大幅改装 | 舰队另给代号 | 刺桐-2M → **远地点级** |

舰名由**公约舰队舰名委员会**按《命名条例》授予，按舰种分系列：

| 舰种 | 舰名系列 | 例子 |
| --- | --- | --- |
| 船坞舰、补给舰 | 轨道要素 | 远地点、近地点、交点、停泊点 |
| 哨舰 | 天气 | 哈马丹、背风岸、无风带、白霜 |
| 炮舰 | 地形与关隘 | 铁砧、渡口、断崖、浅滩 |
| 弹舱舰 | 火山 | 维苏威、喀拉喀托、圣海伦 |
| 油船 | 水源 | 深井、泉眼、暗河 |
| 中继舰 | 高塔与烽火 | 望楼、烽燧、灯塔 |
| 拖船 | 工具 | 缆桩、铁锚、拖钩 |
| 舰载穿梭机 | 文书 | 信笺、火漆、封泥 |

> 弹舱舰以火山命名，是照抄现实海军的做法——美国海军的弹药船就以火山命名。**真实感往往来自一个具体的旧惯例，而不是一个宏大的新设定。**

### 11.3　舷号

舷号是三位数，**按舰种分段**：

| 段 | 舰种 |
| --- | --- |
| 001–099 | 船坞舰、补给舰 |
| 100–199 | 哨舰 |
| 200–299 | 炮舰 |
| 300–399 | 弹舱舰 |
| 400–499 | 油船 |
| 500–599 | 中继舰 |
| 600–699 | 拖船 |
| 700–799 | 舰载穿梭机（旗舰载，不占舰队编制） |

> **远地点号**：远地点级船坞舰首舰，泉州重工 刺桐-2M，舷号 **001**。
> **哈马丹号**：托盘-5 改哨舰，舷号 **114**。

### 11.4　清算署：名字说的是它要对你做什么

清算署的舰名不是文学，是**通告**。它遵循一条规则：

> **不取希望，只取后果。**
> 帝国的船不叫「自由」「黎明」「希望」——那是叛军的叫法。它叫「毁灭者」「复仇者」「暴君」。
> 名字要告诉一颗行星：接下来会发生什么。

中文的对应形式是**施事者**：「XX者」。它说的不是船是什么，是船要对你做什么。

**舰级 = 教条**（对应「帝国级」「胜利级」「执行者级」）：

| 舰级 | 角色 | 说明 |
| --- | --- | --- |
| **清算级** | 主力舰 | 以机构本身命名，最常见。相当于「帝国级」 |
| **执刑级** | 重炮 / 旗舰 | 少。出现即意味着终局 |
| **禁制级** | 封锁 | 断航、驻留。名字取「禁止」，不取「战斗」 |
| **追索级** | 追击、登舰 | |
| **征用级** | 缴获、回收 | |
| **传唤级** | 联络、送达 | 最轻，也最客气的一级 |

**单舰名 = 三个语域**：

| 语域 | 例 | 感觉 |
| --- | --- | --- |
| **施事者** | 裁夺者、究诘者、追索者、湮没者、抹除者、定谳者、荡除者、肃清者 | 它要对你做什么 |
| **不可动摇** | 不移、无赦、恒常、既定 | 你改不了它 |
| **权威** | 终局、铁律、定谳、既判 | 它就是规矩 |

一艘船的全称是：**执刑级，湮没者，舷号 4471**。

**船有名字，人有编号。** 船员没有名字，只有「执行员 4471-07」。这是帝国式命名最省事也最冷的地方。

**旧名字还在**：法条带下面盖着它被没收前的名字。**湮没者原来是白霜。**

**其余全是改装船**，保留原厂的型号名，加一个「改」字：龙门改、赤铁改、谷神改、月港改。

### 11.5　单舰：案卷号与旧名字

清算署的单舰没有舰名，只有**案卷号**——它被没收时对应的那个案子。

但船壳上有两个名字：新刷的案卷号，和法条带下面被盖住的旧舰名。

> 这意味着：**你有可能在某一天，认出对面那条船。**
> 它可能来自你服役过的站，可能是你认识的人沉掉的那条，可能就是你十七年前待过的那条。

**字段约定：**

| 字段 | 谁写 | 谁读 |
| --- | --- | --- |
| `builder` / `model` | 06 + 本文 | 剪影、涂装、识别阶梯、图鉴 |
| `class_name` / `hull_number` / `name_en` / `name_local` | 本文 | UI、无线电 |
| `name_en` / `name_local` / `hull_number` / `former_name` / `retrofit` | 本文 | UI、清算署识别、剧情 |
| `dry_mass_t` / `fuel_fraction` / `isp_s` / `thrust_kn` | 02 + 平衡 | 仿真 |
| `silhouette` | 本文 | 程序化几何 |
| `sensors` / `weapons` | 05 + 平衡 | 仿真 |
| `notes` | 本文 | 文案、关卡设计 |

> `silhouette.style` 的取值必须来自 §9.2 的五种之一（`qh_spec` / `chi_module` / `ym_drum` / `oa_sleek` / `frc_bare`）。清算署的船用原厂 style，另加 `retrofit`。
> 传感器只允许 01 §5.1 的三种类型：`ir` / `radar` / `optical`。激光测距属于 `optical` 的子型，**不是第四种传感器**。
