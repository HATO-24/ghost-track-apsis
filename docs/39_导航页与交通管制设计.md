## 0　一句话

> **R4 导航页把“命令面板里的点火草案”升级为独立规划页：左选站/目标，中看地月图与交通区，右比较航线候选与许可，底下看时间轴与消息；玩家下意图/约束，core 算候选与代价，交通管制给许可/拒绝，执行仍走命令队列与延迟。**

不是自由飞行，也不是新游戏；是 `docs/13` 的“意图 → 计划 → 授权 → 延迟执行”做成 V1 风格一页。主 HUD 只保留摘要/告警，完整规划在此页。

## 2　页面布局（V1 四区骨架）

### 2.1　总体

导航页是**独立页**（覆盖主 HUD），但沿用 V1 四区矩形/字号/线框，避免新视觉语言：

| 区域 | Rect（1920×1080） | 导航页内容 |
| --- | --- | --- |
| 顶栏 STATUS | `(40, 40, 1840, 72)` | `导航 / NAVIGATION · ROUTE & TRAFFIC`；中页签 `航线 ROUTES / 交通 TRAFFIC / 机动 MANEUVER`；右 `T+`、执行窗口、Δv、LINK、`返回 / BACK (ESC)` |
| 左栏 | `(60, 124, 320, 752)` | 对象/站点列表（TARGETS / STATIONS / PORTS / ROUTES）+ 选中摘要 |
| 中区 | `(396, 124, 1128, 752)` | **地月图 / CELESTIAL CHART**：地月/站点/本舰/目标/候选航线/交通区/比例尺 |
| 右栏 | `(1540, 124, 320, 752)` | **航线计划 / ROUTE PLAN**：候选 A/B/C、约束、Δv、许可、授权/中断 |
| 下左 | `(60, 884, 1120, 156)` | 规划/交通/命令日志（可展开全文，仿 §35 通信流） |
| 下右 | `(1200, 884, 660, 156)` | **时间轴**：任务时间/执行窗口/点火节点/许可有效期 + 操作提示 |

- 字号沿用 V1：标题 7/8/9/10/11/12/14；正文 7/8；按钮 8/9；数字 mono 7/8/9/10；**不引入 V2 大字/大留白**。
- 颜色 `pal.gd`：BG/PANEL/PANEL2/LINE/PH/PH_DIM/AMBER/BLUE/RED/FAINT/TXT；不新增高饱和色。
- 1px 分隔线；面板标题下 8；内边距 16（左右内容 76…364 / 1556…1844）；页面打开时主 HUD 隐藏，返回后恢复。
- 附录：`mockups/nav-page-wireframe.png` 展示布局；文字按 V1 大小（wireframe 中略大以便阅读）。

### 2.2　顶栏

- 左：`导航 / NAVIGATION`（9/PH）+ `ROUTE & TRAFFIC CONTROL · L1 MERIDIAN`（7/DIM）。
- 中页签（三个 136×20，间距 12）：`航线 / ROUTES`（默认）、`交通 / TRAFFIC`、`机动 / MANEUVER`；选中左侧 2px 竖线/下划线，不整块反白。
- 右：`T+00:12:40`（mono 10）、`EXEC 00:06:00`（AMBER）、`Δv 1,120 / 1,260 m/s`（PH）、`LINK LD 8 s`（DIM）、`返回 / BACK (ESC)`（AMBER 边）；页面暂停时显示 `PAUSED / 规划中`。

### 2.3　左栏：对象与站点

- 页签 `TARGETS` / `站点·港口` / `ROUTES`；行高 56；选中行左 2px PH + 淡底。
- `TARGETS`：批号/名称/类型/身份/距离/等级（给规划选点，不替代主 HUD 接触列表）。
- `站点·港口`：按港群分组（L1 Meridian / L2 Karman / …），行 `编号 名称 类型 归属`；`orbit_source` 显示来源（V2/R6/固定）。
- `ROUTES`：A/B/C 候选/已保存计划，点击切换右侧计划。
- 底部 `SELECTED / 选中`：名称/批号/类型/身份/轨道来源/距离/方位/相对速度；站点/港口显示 `size/停泊能力`（R3/R6）。

### 2.4　中区：地月图

- 视图：正交/压平 2D（迁移 plot `planar` 资产）；页内固定 `FRAME: ECI / L1`（左上标注）与 `SPAN`；可滚轮缩放/拖拽平移；默认地月正交图，跨度约 700,000 km（与 `PLANAR_SPAN_KM` 一致，100,000–900,000 km）。
- 元素（1px/低饱和线框，无贴图）：
  - 地球/月球（圆/椭圆+经纬线）、地月连线/轴（虚线）；
  - L1–L5 站点（方框/菱形+标签）、GEO 环、月球轨道站/港口；
  - 本舰（PH 圆点+环）、目标（身份色标记）、站点/港口（小方框+名称）；
  - 当前航线实线 PH；候选 A/B/C 虚线（fastest/cheapest/quietest 线型/色不同；选中更亮）；
  - 点火节点（菱形+`BURN Δv`）、到达节点（方框）+预计时刻；
  - 交通管制区：进近走廊（平行线带）、等待区（虚线圆/扇区）、50 km 检查边界（细红线/琥珀）、禁飞区（斜线填充）；只显示玩家已知管制区；
  - 地球/月球阴影锥、太阳方向（弱线，R6 接真实光照/遮挡）；比例尺/罗盘/图例。
- 不画未建模的假雷达扇区/假球；R5 后球形雷达/ELINT 只作可关层，默认不显示。
- 页面信息条：`FRAME / ORTHO / SPAN / CURSOR T+`；底部比例尺/坐标读数。
- 交互：LMB 选点；RMB 平移；滚轮缩放；双击站点设目的地；点击航线选候选；ESC 取消选择。

### 2.5　右栏：ROUTE PLAN

1. `FROM / TO`：起点→终点两行 + `SWAP`；未选显示“选择起点/终点”。
2. `CONSTRAINTS / 约束`（紧凑行）：最早出发/最晚到达/Δv 上限/暴露等级/EMCON/避让区/优先级；点击或 `[−][+]` 切换，不用滑块。
3. `CANDIDATES / 候选`：A 最快、B 最省 Δv、C 最隐蔽；每卡显示 Δv/时间/暴露/交通风险/可行性（`可用/不可用 + 原因`）；选中卡 PH/AMBER 边框。
4. `PLAN SUMMARY / 摘要`：Δv 需要/剩余、出发/到达、窗口、点火节点、置信度/误差、许可。
5. `CLEARANCE / 交通许可`：状态徽标（未请求/请求中/已批准/被拒绝/过期）+ 管制单位 + 原因 + `请求许可 / REQUEST`；拒绝时显示替代动作。
6. 按钮：`授权执行 / AUTHORIZE`（需许可+Δv+参数有效；否则置灰+原因）、`中断 / ABORT`（仅点火前/执行中）、`返回 / RETURN`。
7. 备注：`规划页暂停仿真`、`执行延迟 X s`、`点火后不可撤销`。

### 2.6　下左：规划/交通日志

- 页签 `规划日志 / PLAN`、`交通 / TRAFFIC`、`命令队列 / QUEUE`；默认随模式。
- 行 24px；全文可展开（按钮/双击/滚动/ESC，仿 §35）。
- 来源：交通管制（Sextant/Hammer/Chronos）、命令队列、链路延迟、规划警告、R5 后传感器暴露/ELINT。
- 拒绝原因保留原文与原因码，不用模糊“失败”。

### 2.7　下右：时间轴

- 横轴任务时间（T+0…窗口/任务结束）；游标=当前仿真时间；点击预览（不改时钟）。
- 标记：阶段、执行窗口（6:00 红/琥珀底带）、变轨窗口、点火/到达节点、许可有效期、A/B/C 细刻度（选中加亮）。
- 交互：点击跳预览；拖动播放头看计划快照；页面顶栏暂停/播放；执行窗口锁 1×。
- 小字：`规划中暂停 · 执行按命令延迟`、`时间轴只读预览（不改仿真时钟）`。

## 3　页签与功能

### 3.1　ROUTES（半自动规划，默认）

- 流程：选 FROM → TO → 约束 → 生成候选（core）→ 选候选 → 请求许可 → 授权 → 命令队列（延迟）→ 执行 → 航行/到达。
- 兼容 PRELUDE：页内显示 4 步（目的地→窗口→点火确认→航行，读 `navigation_stage()` 数据）；R4 初期保留旧覆盖层，导航页读同一 `state.prelude_*`，不双写；后期覆盖层作为快捷入口，旧 `DSH_UI=prelude` 截图钩子保留。
- 无可行候选：显示原因（Δv 不足/窗口冲突/无许可/轨道不可达），提供放宽约束/改窗口/取消。
- 起点/终点：本舰/友舰/站点/港口/已知接触；未识别目标只作航向点/区域，不作精确交会点（不伪造位置）。

### 3.2　TRAFFIC（交通管制）

- 左栏：管制区/站点/许可列表；中图显示管制区/走廊/等待区/本舰；右栏许可状态/拒绝原因/请求；下左交通消息全文。
- `交通管制单位`：Sextant 进港调度、Hammer 港务、Chronos 港务/清算者管制区；显示链路/延迟/状态（ONLINE/DEGRADED/SILENT/HOSTILE_CONTROL/UNKNOWN）。
- `许可状态`：`NONE→REQUESTED→GRANTED/DENIED/PENDING/TIMEOUT/EXPIRED/REVOKED`；GRANTED 含编号/类型/有效期/条件/管制单位；过期/撤销需重申。
- `限制`：禁飞区、50 km 检查边界、优先级、武装护航限制、EMCON 要求。
- `请求`：类型/窗口/备注 → 发送（链路延迟）→ 批准/拒绝；拒绝显示原因码 + 建议。
- 拒绝原因码（固定文案/测试）：
  `no_clearance 未获许可`、`window_conflict 时间窗冲突`、`priority 优先级不足`、`restricted_zone 管制/禁飞区`、`unsafe_corridor 安全走廊关闭`、`insufficient_dv Δv 不足`、`unreachable 轨道不可达`、`comms_timeout 通信超时`、`identity_unknown 身份不明`、`roe ROE 限制`、`hostile_traffic 敌对交通`、`degraded 管制降级/数据不足`。
- 交通是信息战（docs/37 §3.1）：延迟/拒绝可能是敌方/清算者策略；R5 后可通信截获/欺骗，但 UI 只显示已知信息。

### 3.3　MANEUVER（半自动/自动/战斗机动）

- 机动模式 chips：`STATION 保持站位`、`SHADOW 跟踪伴飞`、`APPROACH 接近`、`WITHDRAW 脱离/规避`、`ATTITUDE 姿态指向`、`BURN 脉冲点火`；R6 加连续推力/交会/对接。
- 参数：目标/站位点、终距/接近率、Δv/时间、规避方向/最小距离、姿态指向、ROE。
- 预览：相对轨迹、到达时间、Δv、暴露/传感器风险、碰撞/走廊警告（R5/R6）。
- 执行：授权→命令队列（延迟）；可中断；自动模式减少操作步数，不减少延迟/风险；战斗机动只规划/授权，结果显示回主 HUD/事件。
- 计划产生 `command`（STATION/SHADOW/APPROACH/WITHDRAW/ATTITUDE/BURN）仍走 `state.issue_command`，不得直接改轨道。

## 4　交互流程

### 4.1　标准航线

```
打开导航页（暂停）→ 选 FROM → 选 TO → 约束 → [生成候选]
→ 候选 A/B/C（core）→ 选候选 → 请求许可 → 授权执行
→ 命令队列（延迟/点火倒计时）→ 执行/跟随 → 到达 → 关闭页面
```

- 点火前可取消/改参数；**点火后不可撤销**（只能发新命令/修正）。
- 候选/轨迹/Δv 由 core 计算；UI 只显示 `preview_points/nodes/dv/risk/clearance`，不自行积分/估算。
- 页面打开默认暂停仿真；返回恢复打开前状态（不自动提高时倍率）。

### 4.2　许可/执行/中断

```
request → requested(链路延迟) → granted/denied/pending/timeout
  granted → authorize（有效期内）→ 命令 → 执行
  denied → 原因/建议 → 改计划/窗口/请求升级
```

- 请求/响应延迟由 R5 通信/交通模型给；页面显示倒计时/待定，不假装即时。
- 授权成功后生成命令（issue_t/delay_s/exec_t/status），主 HUD 队列同步；点火前 ABORT 可用。
- 页面关闭/返回不撤销已授权命令；主 HUD 仍显示倒计时/告警。
- 自动模式授权一次按计划节点执行；仍可中断。

### 4.3　键鼠（建议，实现前查 V1 键位表）

| 操作 | 键/鼠标 |
| --- | --- |
| 打开/关闭导航页 | `N` / `ESC` / BACK |
| 页签 | 点击 / 页面内独占数字键 |
| 选起点/终点 | LMB / 双击站点 |
| 生成候选 | `G` / 按钮 |
| 请求许可 | `R` / 按钮 |
| 授权执行 | `E` + 二次确认/长按 |
| 中断 | `X` / 按钮 |
| 返回 | `ESC` / BACK |

页面打开时输入独占，避免与主 HUD 1–4 命令冲突；返回不丢选中/滚动。

## 6　真实物理接入后的替换点（抽象成本 → 轨道积分）

原则：UI 只消费计划/预览数据，不做物理；R4 抽象与 R6 真实共用 UI 契约，替换点在 core/数据层。

| 页面元素 | R4 抽象 | R6 真实 | UI 改？ |
| --- | --- | --- | --- |
| 候选 | 成本模型/预算表；固定候选 | RK4/CR3BP/星历/Lambert/连续推力；同 schema `preview_points` | 否 |
| 预览轨迹 | 直线/示意弧/采样 | 真实轨道积分/误差椭圆/遮挡/光照 | 否（画点） |
| Δv/时间窗 | 预算/内容窗口 | 真实点火积分/相位/窗口求解 | 否（显示 core 值） |
| 站体/港口 | 固定/示意 | cislunar/R3/R6 真实轨道/站保持 | 否（读 nav_objects） |
| 交通许可 | 脚本/文本 | 站体/航道/进近走廊/R5 通信/ELINT | 否（显示状态/原因） |

| 暴露/风险 | 估算/表 | R5 传感器/ELINT/通信总线 | 否（读 risk） |
| 执行 | 命令队列/延迟/脉冲 | 同一状态机+真实发动机/姿态 | 否 |

验收：同一 UI/probe 在 R4 mock 与 R6 真实数据下都能跑；schema 不变；UI 不新增第二套轨迹计算。

## 9　验收 / probe / 迁移

### 9.1　验收

1. 1920×1080：四区与主 HUD 骨架一致，无文本越界/重叠；V1 字号/色板。
2. 打开暂停/关闭恢复（选中/滚动/时倍率不自动变）；顶栏 PAUSED。
3. 页签切换不丢选中；候选 A/B/C 高亮；约束改变重算（core）。
4. 许可 request/denied/granted/expired 显示正确；拒绝原因码+建议；无许可时 AUTHORIZE 置灰+原因。
5. 授权后命令进主 HUD 队列；点火前可中断、点火后不可撤回；主 HUD 同步。
6. 无 core/数据：隐藏候选/许可/轨迹不伪造；页面可返回。
7. 主 HUD 只摘要/告警；END/REPORT/DECISION 覆盖层优先。
