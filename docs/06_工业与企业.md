## 0　一句话

> 没有一家公司能独立造出一艘船。
> 一艘炮舰是十一家公司的产品、三个管辖区的许可、和一群在册抵押人员的工时。
> **这就是为什么这场战争打不起来，也停不下来。**

## 1　三层格局

| 层 | 在哪 | 有什么 | 谁控制 |
| --- | --- | --- | --- |
| **资本与发射** | 地球 | 钱、港口、重力井、法律 | 签约国的银行与财团 |
| **制造** | 天市环带 | 船坞、精密加工、数据 | 天市诸港 + 各家船厂 |
| **原料** | 月面 + 外权地 | 冰、金属、挥发物 | 永昼租界 + 远环合作社 |

**关键事实：没有一层能独立存活。** 地球有钱没原料，环带有工厂没冰，月面有冰没粮食。

> 这是公约存在的理由，也是它必然失败的理由。

### 2.1　泉州重工　QH

| | |
| --- | --- |
| 所在地 | 地球同步轨道 · 泉州坞 |
| 出身 | 2040 年代国家重型运载联合体，签约国国有资产 |
| 客户 | 各国政府、公约舰队 |
| 造什么 | 船坞舰、油船、中继舰、护卫舰——**大船** |

**设计哲学**：它造的不是船，是**规格**。所有舱段等直径，装甲带完整，双散热片左右对称，焊缝打磨过。

**为什么是这种风格**：坞是重力井边上最大的一个，客户是政府，验收标准写在合同附件里。**它不需要省，它需要过审。**

**命名语法**：港口与航路。刺桐、月港、安海、后渚。

> 「我们不卖船，我们交付舰队。」

### 2.2　车肆重工　CHI

| | |
| --- | --- |
| 所在地 | 天市环二 · 车肆坞 |
| 出身 | 修船起家，现在是产量最大的厂 |
| 客户 | 所有人 |
| 造什么 | 货船、拖船、轻型运输——**什么都能改** |

**设计哲学**：模块。3–6 段不同直径的舱段焊起来，集装箱架外挂，散热片左右不对称（左右是两次不同的采购），补丁从来不补平。

**为什么是这种风格**：它主要不是造船，是修船和改装。坞里同时停着三十条船，每条都在等一个不同的零件。

**命名语法**：工具与物流。龙门、绞盘、锚链、托盘。

> 「任何一艘船，都可以再干一份活。」

### 2.3　永昼机械　Solstice Machinery　SM

| | |
| --- | --- |
| 所在地 | 月面 · 永昼 |
| 出身 | 采冰设备制造商，租界实际统治者之一 |
| 客户 | 永昼冰业、外权地矿主、二手市场 |
| 造什么 | 矿运船、采冰船、重装运输——**不是军舰** |

**设计哲学**：压力容器。鼓形船体、大球罐、低散热面积、防尘涂层、外露采矿臂。

**为什么是这种风格**：月面没有空气，只有磨料一样的尘土。它的船必须能挨住十年粉尘，而不是挨住一发炮弹。

**命名语法**：矿物。赤铁、玄武、冰晶、云母。

> 「我们造的是工具。武器是别人后来加的。」

### 2.4　奥尔西尼工坊　OA

| | |
| --- | --- |
| 所在地 | 地球低轨 · 奥尔西尼坞 |
| 出身 | 米兰裔家族企业，三代人做快船 |
| 客户 | 各国政府、通信社、有钱人 |
| 造什么 | 舰载穿梭机、交通艇、指挥艇——**快船** |

**设计哲学**：减法。散热片只有两片，因为跑得快、烧得短；没有外露桁架；化学推进，随时能点火；浅色涂装。**它卖的是时间。**

**命名语法**：音乐术语。咏叹、夜曲、托卡塔。

> 「速度是一种奢侈品。」

### 2.5　远环合作社　FRC

| | |
| --- | --- |
| 所在地 | 外权地 · 谷神星 |
| 出身 | 破产矿工的自救组织，现在是合作社 |
| 客户 | 不卖，只换 |
| 造什么 | 通用工作船、矿船、拖船——**最便宜、最耐修** |

**设计哲学**：裸露。没有涂装，没有外板，桁架直接露在外面，一台发动机，焊缝从来不磨。所有零件通用，用扳手就能拆。

**为什么是这种风格**：外权地没有船坞，只有补给船和扳手。一条船坏了，得在真空里用现成零件修好。

**命名语法**：小行星。谷神、灶神、智神。

> 「它不会漂亮，但它会回来。」

### 3.1　七组对立

| 对立 | 争什么 | 玩家看到的结果 |
| --- | --- | --- |
| 北岭 vs 南十字 | 军用标准 vs 民用成本 | 重得可靠，还是轻得便宜 |
| 北岭 vs 东方 | 寿命 vs 推力 | 能一直跑，还是一下子窜出去 |
| 明视 vs 中村 | 锐度 vs 耐用 | 看得更远，还是摔不坏 |
| 远望 vs 红隼 | 软件 vs 硬件 | 算得快，还是藏得住 |
| 夜面 vs 白夜 | 高温小排 vs 低温大排 | **躲红外还是躲雷达，只能选一个** |
| 厚土 vs 哈尔沃森 | 便宜 vs 一体成型 | 坏了能补，还是整块换 |
| 铁砧 vs 雷石 | 质量 vs 数量 | 一发命中，还是一万发弹幕 |

> 这些对立不是数值差异，是**世界观差异**：每一家都认为另一家在做错事。

## 4　部件目录

### 4.1　怎么读

每个部件有四个维度，**没有一项能全拿**：

| 维度 | 含义 |
| --- | --- |
| **规格** | 1 / 2 / 3。船体有槽位，装不下就是装不下 |
| **数值** | 这一项最硬的那个数 |
| **强项** | 它为什么值得买 |
| **弱项** | 你为什么后悔买了它 |

价格分四档：**极低 / 低 / 中 / 高**。

### 4.6　三套典型配置

**穷人的哨舰**（车肆托盘-5 改）

```
南十字 SC-4 反应堆     轻、便宜、过热
车肆 CH-IR2 红外       60,000 km，虚警多
车肆 CH-R0 无线电      4 s 延迟
无装甲
总价：极低
```

> 便宜到可以死很多条。问题是它经常把残骸当成敌舰，然后你派炮舰过去，发现是一场空。

**均衡的炮舰**（永昼赤铁-6 改）

```
泉州 QH-12 反应堆      到处能修
北岭 NR-N1 发动机      稳
夜面 NT-3 散热         600 m²，但红外极亮
厚土 HT-8 装甲         8 cm 钢，重
铁砧 TZ-K30 主炮       标准
总价：中
```

> 耐打、能修、打得准。代价是你一开机，半个战场都看见你了。

**贵的猎手**（泉州后渚-3，友军分遣队的船）

```

明视 MS-IR9 红外       120,000 km
远望 YW-R9 雷达        30,000 km
白夜 WT-5 散热         红外暗
薄云 BY-2 装甲         轻
铁砧 TZ-K30 + 长风 CF-H4
总价：高
```

> 看得远、藏得住、打得准。贵到不敢用——**这才是它真正的缺点。**
> 你编不到这种船。你只能在简报里看到它的配置，然后开着三条改装矿船去干同样的活。

### 4.7　标准化 vs 优化

部件可以混装，但混装有一个账面上看不见的代价：

| 选择 | 好处 | 代价 |
| --- | --- | --- |
| **全队统一供应商** | 备件通用，战地维修快 30% | 放弃单项最优 |
| **每艘船单独优化** | 性能最好 | 备件清单变成噩梦，维修慢 50% |

> 这是一道**舰队级**的选择，不是单舰级的。玩家在船坞里做的不只是配船，是在决定这支舰队以后怎么活。

### 5.1　断供是最便宜的武器

| --- | --- |

| 明视光学 | 全队退回 L1 |
| 夜面热工 | 无法持续开火 |
| 厚土冶金 | 挨打就穿 |

> 玩家会在任务简报里看到：**"第三批散热片卡在环一海关。"**

## 6　劳资：在册抵押人员

### 6.1　三种人

| 身份 | 是什么 | 占在轨人口 |
| --- | --- | --- |
| **轨道居民** | 在轨出生、居住，持有所在站或辖区的居住权 | 约六成 |
| **合同工** | 地球派来的，合同期满回国 | 约三成 |
| **在册抵押人员** | 劳动合同作为抵押物，登记在清算署托管账户 | 约一成 |

### 6.2　他们到底是什么

不是奴隶。他们可以工作、领薪、结婚、上诉。

但劳动合同是抵押物的一部分：**换工作要清算署批准，离开辖区要清算署批准，罢工要清算署批准。**

清算署从不阻止——它只是"暂缓处理"。一份申请压在案卷里三年，人还在原地干活。

> 这是这个世界最有效的一种暴力：**它不锁门，它只是不给你回执。**

### 6.3　工会

| 工会 | 在哪 | 实力 |
| --- | --- | --- |
| 坞工联 | 天市环二 | 最强。一次停工，前线少三艘船 |
| 镜工联 | 天市环四 | 最精。磨镜的人不能换 |
| 坑下工联 | 月面永昼 | 最硬。他们在地下工作，也在最下面谈判 |

**罢工是这场战争里最被低估的武器。** 一条船坞停三天，前线的巡逻密度就掉一个档。

## 8　企业的政治

### 8.1　不站队也是一种站队

- 泉州重工公开支持公约，因为它的订单来自公约
- 车肆重工两边都卖，因为它的坞在环二，谁都能来
- 永昼机械必须站租界，因为它的厂在月面
- 奥尔西尼谁都不站，因为它只卖快船，快船谁都需要
- 远环合作社站自己，因为它谁都信不过

### 8.2　企业能做的三件事

| 手段 | 效果 | 例子 |
| --- | --- | --- |
| **断供** | 让一支舰队停飞 | 夜面热工停止交付散热片 |
| **停工** | 让前线的补充变慢 | 坞工联罢工三天 |
| **不表态** | 让一份命令变成废纸 | 明视光学"正在评估合规风险" |

### 8.3　企业之间的四种手段

| 手段 | 例子 |
| --- | --- |
| **挖人** | 白夜热工就是从夜面热工出走的人开的，带走了真空钎焊的工艺 |
| **仿制** | 雷石仿铁砧的近防炮，便宜三成，卡壳率高五倍 |
| **诉讼** | 明视告远望侵犯光学专利，官司打了六年，双方都还在用对方的技术 |
| **破坏** | 环二船坞每年三次"事故"，没有一次查得清 |

> 这些公司不需要打仗。它们已经在打了，只是用的是合同、专利和事故报告。
