## 0　用途与口径

### 0.1　用途

本文规定第一关 **L1 Meridian-05 Chronos** 的全部玩家可见文本：

- 开场与三条 Phase 的无线电/事件文本；
- 通信流条目（发信者、收信者、链路、正文）；
- 通知窗口、交战规则卡、执行窗口、命令队列等 UI 文案；
- 四种结局（HOLD / EVACUATE / EXPOSE / FIRE）的选择提示与内部事后报告正文；
- 报告造假（淡化/伪造）文本。

### 0.2　文风

- **正式、说明性**：用完整句、程序词、单位与批号；不写抒情短句，不写旁白式评价。
- 军队通话：报单位、方位、距离、接触等级、请求/回复；不解释动机。
- 敌对方（清算者、格林尼治海关）用语礼貌、程序化、引用授权文件；不使用缩写与口语。
- 我方（ID13）用语简短、程序化；指挥官不是职业军官，措辞可以略显生硬，但不写俏皮话。

### 0.3　通信口径

- 通信流格式固定为 `[发信者至收信者]-[通信方式]-[正文]`（19 §1）；
  数据层拆成 `from / to / mode / text` 四个字段，UI 再拼接。
- 链路优先级（Lead 2026-10-18 修正）：**激光直连（LD） > 激光中继（LR） > 红外（IR） > 无线电（RDO） > 可见光（VIS）**。
  红外为第三、无线电为第四（兜底）；无线电只用于公开法律广播、港务/民用与应急。
- 第一关不写电子战、干扰与链路故障；五级链路只声明战术主序，不硬造故障。

### 0.4　批号与身份

- 批号：1000 远地点号、1001 哈马丹号、1002 渡口号、1003 望楼号、1004 深井号、2001 AV-4412 传唤者、
  9001 谷神-2、9002 CH-IR2 回波（交叉确认后为**无威胁目标**）。
- 身份：待定 / 未知 / 假定友好 / 友方 / 中立 / 可疑 / 敌方；第一关初始与迁移见 19 §2.5。
- 文本中引用目标统一写 `[批号]`；正式文书可用舰名，不得把批号当舰名。

### 0.5　前置航行

玩家在 ID13 母港 **L4-02 Hammer** 上任，完成交接后收到 OCUVF 命令，前往 L1 Meridian 作为“谈判主力”介入 Chronos 事件。

前置阶段的教学目标是基础轨道航行：设定目的地、选择变轨窗口、确认 Δv 消耗、执行点火、等待到达。该阶段不计入 6:00 执行窗口；执行窗口从 ID13 抵达 Meridian、AV-4412 进入 50 km 检查边界后开始。

## 1　场景结构

### 1.1　时间

**2193 年，第七号轨道紧急托管令（Order 7）发布后的第九天。**

- 第七号令发布当天（Day 0），L1 Meridian-05 **Chronos** 加注站爆炸，UEG 核查组失联。
- 第九天（本关），Chronos 储罐仍在泄漏；爆炸原因与核查组下落仍无定论；
  第33舰队以“火星分离主义破坏”为由维持对储罐与进港航道的接管；
  OCU 内部因猜疑陷入混乱。
- OCUVF-ID13 于当天抵达 Meridian，名义任务是“谈判主力”，实际授权有限。
- 本关的**执行窗口 6:00** 从 AV-4412 传唤者进入 **50 km 检查边界**、清算者启动 Chronos 最终封存程序时开始；
  仿真时间计时，时标锁 1×（可暂停、不可加速）。

### 1.4　我方授权与交战规则

- OCJC 给 ID13 的授权：**在不首先开火的前提下，采取一切必要措施保护港群资产与居民。**
- 默认交战规则：**不得首先开火**；武器释放须由 ID13 指挥官明确授权。
- 清算者受程序与政治限制，不会首先对 ID13 开火；其目标是完成接管、造成既成事实。
- 开火属于**灾难分支**：政治风险、站体/人员损失、ID13 被定性；不是常规玩法。

### 1.5　两条暗线

- **GHOST TRACK**：Chronos 爆炸与“火星分离主义破坏”的说法存疑；
  传感器记录中存在无法归档的接触与未登记特征码。EXPOSE 依赖相关证据。
- **前任指挥官之死**：第一任 ID13 指挥官在 **L5-01 Eko** 遇刺；官方说法为“报复性刺杀”，
  ID13 船员不接受该说法，也不完全信任新任指挥官。
