## 1　规则

1. **不自动改游戏文本。** 任何玩家可见文本先进入批次表；用户批准后才写入游戏文件。
2. **一批一表。** 每批包含：ID、文件/位置、当前文本、拟改文本、理由、状态。
3. **状态**：`待审` → `已批准` / `待润色` / `已驳回` → `已应用`。
4. 叙事文本默认不使用教学括号；教学提示只放在独立的副官建议或手册中。
5. **游戏内不显示 Act / Phase / 关卡 / 阶段 / 教程提示。** Act/Phase 只用于作者侧结构。
6. 每批应用后，Lead 跑 headless + 截图，再交用户复核。
