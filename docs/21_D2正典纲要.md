## 2　历史（改写 03 §1）

- **2051 大停摆**：太阳离子风暴摧毁全球通信数月，地月失联；旧国际体系失效，联合国名存实亡；港群雏形、月面基地进入三不管状态。
- **2071 UEG 成立**：地球联合政府以《轨道宪章》接管关键基础设施；港群与月面获得自治承诺，但联合议会席位按地球人口与出资分配。
- **2093 火星叛乱**：MIDA 夺取火星轨道；UEG 发动极光行动，联合轨道军主力被牵制；地月系兵力真空，第33舰队扩权。
- **2093 第七号令 / Chronos 事件**：Greenwich 发布 Order 7；Chronos 爆炸、UEG 核查组失联；现在是发布后的第九天。

不要再用“债权/违约/合同/裁定/案卷”作为核心冲突词；用 **托管、授权、紧急状态、宪章、自治**。

## 3　权力结构

### 3.1 地球联合政府（UEG）

- 联邦制政府，不是单一民族国家；首都/机构在地球。
- **联邦总统 + 联邦议会**：分裂。
- **中央安全委员会（鹰派）**：第33舰队的靠山；主张紧急状态中央集权。
- **轨道事务委员会（鸽派/自治派）**：要求复核第七号令；玩家潜在盟友。
- **联合轨道军**：正规军，主力在火星；地月系只剩架子。
- **UEG 海关/轨道管制**：Greenwich、Quay 等节点。

### 3.2 第33轨道特别独立舰队 / 清算者（Reclaimers）

- 正式中文：**地球联合政府（UEG）第33轨道特别独立舰队**。
- 正式英文：**Earth Union Government (UEG) 33rd Orbital Special Independent Fleet**。
- 名义隶属 UEG 轨道司令部，实权独立；鹰派私兵；类似 Titans/Manhunter。
- 任务：执行第七号令、接管“失能/受威胁”的关键基础设施、回收“无主/违法”资产。
- **GHOST TRACK**：舰队内部的标准改装试验群/黑单位；T3 式；试作舰、假旗、抹航迹。
- 科尔：前线接管官；礼貌、程序化；可能真信“临时托管能避免更大灾难”。

### 3.3 轨道殖民地联合（OCU / OCJC）

- **OCJC**：轨道殖民地联合议会，五个港群 + 月面自治 + 外环观察员；松散、票决、没有常备军。
- **OCU**：政治名称；联合本身；不是国家，是自治港群的政治联合。
- **OCUVF**：志愿舰队；混编、半地下、靠港群供养。
- **OCUVF-ID13**：第13独立分遣群；玩家单位；母港 L4-02 Hammer；旗舰 APSIS。
- 玩家：ID13 新任指挥官；前任在 L5-01 Eko 被刺杀（官方宣称“殖民地刺杀”）；船员不信官方说法。

### 3.4 五个港群

- L1 **Meridian**：贸易/海关；Greenwich、Sextant、Chronos、Astrolabe。
- L2 **Karman**：中继/观测；Janus、Argus、Horizon、Silent。
- L3 **Alborada**：农业/水；Aurora、Ceres、Dew、Demeter。
- L4 **Anvil**：船坞/重工；Hammer、Vulcan、Crucible、Ingot。
- L5 **New Lagos**：人口/轻工；Eko、Zuma、Savannah、Victoria。
- 详见 `20_港群与站点.md`。

### 3.5 其他

- **月面永久居住领地-永昼**：月面公司城；中立/灰色；水和燃料。
- **远地环带飞地**：小行星带；后期后方。
- **火星殖民地叛乱**：UEG 正规军被拖住；也是难民来源（L5-07 Savannah）。

## 4　Act 1 正典

- 地点：**L1 Meridian-05 Chronos**；Greenwich 发布第七号令；Sextant 控制进港。
- 事件：Chronos 加注站爆炸，UEG 核查组失联；清算者称“火星分离主义破坏”，援引第七号令接管储罐/航道。
- 真相：GHOST TRACK 自导自演，测试新改装/制造接管借口。
- 玩家：ID13 新任指挥官，刚到 Meridian；舰队是唯一还能动的武装。
- 政治：玩家没有法理依据，是妨碍项；清算者要既成事实；UEG 不想升级；**默认不交火**。
- 玩家可做：卡位、登舰检查、转移人员/储罐、记录 GHOST TRACK、谈判、拖时间、找 UEG 鸽派。
- 开火：灾难分支，不是常规玩法。
- 前任之死：官方“殖民地刺杀”；实际与 GHOST TRACK/清算者有关，留作 Act 1 暗线。
