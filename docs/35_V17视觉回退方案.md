# V17 视觉回退方案

## 结论
`game_v16` 的 UI 设计语言偏离 V1。V17 采用：
- **视觉/交互基线**：`game_v15` 的 HUD/plot/intro/字体/密度/坐标，原样复制到 `game_v17`。
- **数据后端**：`game_v16` 的 core/sim/content 复制到 `game_v17/framework/`，通过桥接层接入。
- **旧版保留**：`game_v15` 稳定可运行；`game_v16` 仅作数据框架实验。

## 边界
- 不再继续扩展 V16 的 UI 视觉。
- V17 所有新功能必须在 V1 HUD 的面板/字号/密度/交互里表达。
- 逐项迁移：教学门控、TWS/球形雷达、光学/IR、图层、回放、损管、站体/储罐、窗口适配。

## 阶段
1. V17-0：复制 V15、动画/音频/截图基线；framework 接入 probe。
2. V17-1：V1 HUD 数据适配（接触/选中/右栏/命令/日志）。
3. V17-2：TWS/光学/教学门控落到 V1 plot/HUD。
4. V17-3：回放/损管/图层/站体储罐模型。
5. V17-4：窗口适配、独立包、演示视频。
