## 0　一句话

> 你刚接过一支没人信任的志愿舰队。Chronos 发生爆炸事故，清算者正打算接管。
> 你的任务不是打赢——是让接管不成为既成事实；而你手里的法理依据，是零。

---

## 1　主要教学目标

1. **基础轨道航行操作**：玩家上任位置在母港，完成上任交接工作后立刻受到命令前往Chronos。
   如何下达变轨指令，如何设定目的地，如何在变轨窗口内操作。
2. **学习阅读接触列表与身份识别**：L1 方位线 → L2 定位 → L3 分类 → L4 确认；四位数批号（1000/2001/9001/9002）；
   六级身份（待定/未知/假定友好/友方/中立/可疑/敌方）；**不明 ≠ 敌意**，**无威胁目标 ≠ 敌舰**。
3. **命令下达与传感器使用**：传感器是**按舰载**的；哈马丹号是舰队的 AWACS/EWR 节点。
   玩家要**命令哈马丹开机**，并体会命令的中继延迟、待生效与撤销。
4. **守政治红线**：ID13 在 Chronos 没有法理依据，是清算者眼里的**政治妨碍项**。
   默认不交火；玩家在 **HOLD / EVACUATE / EXPOSE** 之间做选择；**开火 = 以OCU名义宣战**。

**不教**：完整武器系统、电子战、损管、编队命令。
只保留一次**脚本化开火后果**，让玩家看到“擅自开火的后果”。

## 2　场景与卡斯

**地点**：**L1 Meridian-05 Chronos**（子午港群，L1-05 柯罗诺斯；燃料加注站与冰/燃料储罐群）。
**时间**：**第七号轨道紧急托管令**（Order 7）发布后的**第九天**。Chronos 加注站爆炸与 UEG 核查组失联发生在第九天之前的 Day 0；当前储罐仍在泄漏，清算者维持接管。
ID13 抵达 Meridian 后，AV-4412 进入 50 km 检查边界、清算者启动最终封存程序时，本关的 **6 分钟执行窗口**开始（仿真时间；时标锁 1×，可暂停、不可加速）。

**背景三段**：

- **Greenwich（L1-01）** UEG发布第七号令：港群行政中心/海关总部，UEG 海关与 OCU 港务委员会共管；
  所有进出港文件的第一道闸。
- **Sextant（L1-03）** 控制进港：港群实际交通咽喉，引航员工会亲 OCU；想封锁 Chronos，必须先过 Sextant这道坎。
- **清算者（UEG 第33轨道特别独立舰队）** 以“火星分离主义破坏”为由，援引第七号令接管 Chronos 储罐与航道；
  **真相是 GHOST TRACK 自导自演**：假旗试作舰制造爆炸、抹掉航迹，为接管制造借口（Act 1 暗线）。

## 3　Act 1 · 越权回收（约 12–15 分钟）

> **Act 1 / Phase 1–3 只用于作者侧设计**；游戏内不显示 Act/Phase/关卡/阶段提示。
> 玩家只看到一个大目标（阻止接管成为既成事实）和一个执行窗口，怎么达成由玩家决定。

### Phase 1 · 判读（约 4 分钟）

- 爆炸后 90 秒，ID13 在 Meridian 外缘：Chronos 储罐群失压、加注站仍有火点；UEG 核查组信号消失。
- 哈马丹的 CH-IR2 报出**两条回波**：一条在机动（2001 AV-4412 正在进港），一条在漂移（9001 谷神-2）；
  另有一条 **9002 回波候选**，交叉确认后为**无威胁目标**（残骸/反射，不是船）。
- 玩家选中哈马丹，打开它的**按舰传感器架**：YW-R9 / MS-OT2 / CH-IR2 / ELINT / CH-R0；
  **命令哈马丹开机**；雷达一开就给 L2，同时被 2001 的 ELINT 点名——**开机即暴露**。
- 光学凝视推 L3、MK-12 IFF 推 L4；9001 无应答 → “不明 ≠ 敌意”，最终为中立；
  2001 光学分类为传唤级·清算者 → “可疑”，但**没有 ROE 依据，不能判敌方**。
- 玩家第一次看到：批号、身份、探测等级是**三层不同的东西**；9002 不是目标。

### Phase 2 · 下令（约 4 分钟）

- 命令哈马丹跟踪 9001（经望楼 LR，**8 秒后生效**）；命令队列显示“待生效”，图上出现**命令幽灵**；
  玩家可以在生效前撤销，第一次体会“命令会过时”。
- 命令深井号把储罐拖离火区/航道：Δv 预算下降，玩家第一次看到“机动是花钱”。
- **Greenwich 的第七号令通告**通过 RDO 法律广播送达；Sextant 进港调度被清算者接管。
- 执行窗口 **6:00** 开始，时标锁 1×（可暂停、不可加速）；窗口结束前必须做出决定。
- 可选动作：副官建议派穿梭机/登舰小队去 Chronos 取港务监控与核查组黑匣子——这是 **EXPOSE 的前置**，
  不花 Δv，但花时间，并且可能被清算者拦下。

### Phase 3 · 赌（约 5 分钟）

- 科尔要求 ID13 撤出、交出储罐与航道，称“临时托管避免更大灾难”；
  Chronos 港务请求先撤人、别把储罐交给清算者；渡口号请求武器释放授权（需要玩家明确下令拒绝，否则内置计时器结束后默认随机向9001开火）。
- **EXPOSE 线索**：Chronos 港务遥测 + 核查组黑匣子 + 一条“任何厂商型号都对不上”的 ELINT 特征码
  ——GHOST TRACK 的假旗痕迹。三件拿到两件，才能走 EXPOSE。
- 执行窗口内四选一：

| 选项 | 做什么 | 结果 |
| --- | --- | --- |
| **HOLD / 卡住** | 卡位、拖时间、拒绝签字；用 ID13 的存在顶住 Sextant/Chronos 的接管流程，把既成事实拖成 UEG 复核 | 清算者未能完成接管；UEG 被迫复核第七号令；ID13 被记名 |
| **EVACUATE / 撤人** | 撤走 Chronos 平民与储罐/补给，让清算者接管空站 | 人活下来、站体被接管；Media/Meridian 记你人情，清算者指责你“转移资产” |
| **EXPOSE / 曝光** | 把 GHOST TRACK 假旗证据交给 OCJC/UEG 鸽派，公开或半公开 | UEG 鸽派启动调查；清算者行动被拖慢；ID13 成为清算者头号眼中钉 |
| **FIRE / 开火（灾难）** | 授权/率先开火（无论目标是 2001 还是误击 9001） | 政治灾难：战争风险、站体/平民伤亡、ID13 被定性；进入后果页与调查线；不是 game over |

- 全程可以一枪不放。
- 暗线：爆炸前 Chronos 有一条在轨道管控记录里被抹掉的航迹。

## 4　呈现方式

- **没有弹窗教程。** 教学只通过三样东西：**副官建议**（一次性、单独 UI，不进通信流）、
  **通信流**（19 §1 格式）、**第一次接触的方位线与面板高亮**。
- **默认视角 = local 3D**；拉远到 dist > 640,000 自动进 flat 战略图，< 580,000 回 3D；
  flat 只作为自动压平/拉远后的战略图，不作为开局视角。
- **传感器架按舰载**：选中舰 → 看它的传感器列表（型号/厂商/距离/延迟/暴露），
  可**命令开机/关机**；雷达一开就暴露（哈马丹 YW-R9 是教学点）。
- **DATUM 常驻顶栏**：本关 `DATUM: L1 / STATION FRAME`；图上不是地球弧，而是**站点基准十字 + 地月双体**。
- **通信流常驻**：按 `[发信者至收信者]-[LD/LR/RDO/IR/VIS]-[内容]` 显示（19 §1）。
- **接管通知窗口**：Greenwich/清算者的第七号令通告做成可点开的 notice；打开时暂停。
- **ROE 卡常驻**：`默认不交火 / 武器释放需指挥官授权`；渡口的武器释放请求闪红，玩家必须明确驳回或授权。
- **执行窗口**：顶栏 `EXECUTION WINDOW 00:06:00`；进入窗口时提示 `TIME SCALE LOCKED`，锁 1×。
- **命令队列常驻**；时间轴可回拖 60 秒，看“当时我为什么那么判断”。
- **结束是内部报告**，不是击毁/占领提示。

开场通话示例：

```
[Sextant 至 ID13]-[RDO]-[Chronos 加注站爆炸，进港调度依第七号令移交。请 ID13 立即让出航道。完毕。]
[ID13 至 Sextant]-[RDO]-[收到。ID13 正在核实现场，暂不能让出航道。完毕。]
[哈马丹至远地点]-[LD]-[[2001] 主动机动，[9001] 漂移；另有一条回波待确认。完毕。]
```

## 5　成败与报告

**通关**：**HOLD / EVACUATE / EXPOSE** 三种默认结局**都算通关**，各自写入声望与 Act 2 分支；
前提是没有未经授权的开火、没有误击民用目标。

**开火分支**：允许开火，但它是**灾难分支**。一旦开火，demo **自动冻结**（时间/命令队列），
进入后果页（交火风险、站体与平民伤亡、ID13 被定性），再进入内部报告；不是 game over，
后续调查见 [`08_声望与审计.md`](08_声望与审计.md)。

**报告**：OCJC/OCUVF 的**内部事后报告**（19 §5 T1-14 的新格式），不是给 UEG/Greewich 的官方回复。
只有出现不良后果，才出现“淡化 / 伪造”选项；多次造假累积 `perjury_count`、触发审计，
最坏结局见 08。报告是 Act 2 的证据。

## 6　剧情接口

- **Act 1 · Chronos（本关）**：玩家学会基础操作，做第一次政治选择；拿到（或没拿到）GHOST TRACK 证据。
- **Act 2 · 待做**：默认为交火开战线，玩家被UEG定性分离主义分子武装力量，玩家需要在各殖民地之间流亡，并说服各方势力以及其他OCUVF舰队加入战斗。
- **Act 3 · 幽影**：本关的假旗证据（EXPOSE）是它的引子。
- 玩家的内部报告是后续调查/审计的证据；“你今天救下的人，可能明年在听证会上成为你的证人，或你的罪证。”
- 假报告累积到第三次，触发最坏分支（OCJC 除名 / 清算者通缉 / ID13 被定性），详见 08。
- 前任指挥官之死是暗线：Act 2 追查，船员信任随调查推进变化。
