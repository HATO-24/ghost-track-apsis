## 舰艇从哪里来

OCUVF 以购买、借用与改装民用船建立舰队，不是按统一军舰蓝图量产。船厂和原用途会留在外形与弱点中：泉州重工偏大型、规则化的船坞舰/油船/中继舰；车肆重工以模块货船、拖船与改装见长；永昼机械的矿运船有厚壳与储罐。舰船身份按**厂商型号、舰级／内部代号、舰种、舰名、舷号**记录；任务职能另记。型号“可装”不代表这一艘已装，具名舰不能因为模板相同而复制身份。旧 04 §12 与 16 §2 对 OCUVF 是否有正式“舰级”的用词不完全一致：对外主标识沿“型号＋舰名＋舷号”，内部可保留远地点级代号；不扩张成新命名规则。

## 首场联合战役编制

**已确认产品口径**为 11 艘独立舰：8 艘旗舰/支援舰（含 APSIS）＋3 个作战舰位置。作战位的炮舰:导弹舰可为 **3:0、2:1、1:2、0:3**。APSIS 在战区后方承担真实风险，不占作战位；不恢复旧提案的 3 舰总上限、100 点预算或 3600 秒全局硬限。点数暂不冻结，M0 无全局硬倒计时。四种组合的难度可以不同。来源为 Astra 审查核过的 GitHub main `docs/tasks/joint_campaign/JC-B03P_用户确认与后续执行_20261029.md`（blob `8cacef9ec07280afe39faed3ed79d22132f25483`）及该审查 §3。

旧固定名册只列一艘具名龙门舰，不足以证明三导弹组合的内容已经齐备；也不能证明新主线缺失。Astra 裁定同级舰可由**合法舰级模板建立独立场景实例**，每舰稳定唯一 ID、库存、燃料与损伤；暂用明确场景呼号，不复制既有具名舰，也不凭空补主线正典舰名。实例合法、11 舰部署、旗舰风险及四组合仍是工程和内容验证项，**NOT RUN**。〔`docs/settings/SET-C01_整合说明.md`；S-04 `conflict_decisions.md` C1/C2〕

玩家对这 11 艘自有编制舰实施直接指挥；另有具独立任务和指挥权的 AI 友军舰队参与联合战役，玩家发送协调请求并等待其回执与实际行动。友军身份不自动授予直控权或即时共享全部观测。本场的对手方向和阶段性目标已定为解除第33舰队某战区部队有组织作战能力；具体参战敌舰数和难度尚未冻结。〔`docs/56_Astra_开发需求_交6Sol.md` R2 §2.1、§6“逐舰指挥和战斗”“AI 友军协同”“目标与去军事化判定”〕
