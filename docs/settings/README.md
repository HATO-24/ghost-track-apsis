# 世界设定全书

正文入口：《[GHOST TRACK · 世界设定全书](GHOST_TRACK_世界设定全书.md)》。

这是项目当前**最新、最正式、最完全**的世界设定文档，共九章：历史与现状、地月系地理与站点、势力与政治、经济与工业、人物、舰船、技术与装备、命名与术语、军语与通信。

此前分散的十五份设定文档（03/04/05/06/10/12/16/19/20/21/44/46/47/48/49）与历轮整合材料（地月圈设定集、全量汇编、主题底稿、来源登记与冲突台账）已归档至 [`docs/archive/legacy_setting_20261101/`](../archive/legacy_setting_20261101/)，仅作历史查证，不再作为设定依据。
