## 1. 当前战役编制与舰级用途

**已确认产品决定**：首场战役 **11 = 8 艘旗舰/支援舰 + 3 个作战舰位置**。远地点号在前 8 艘中，进入战区后方并承担真实风险，不占作战位置。作战舰由炮舰与导弹舰自由组合，3:0、2:1、1:2、0:3 均合法；不保证四种阵容难度相同。点数暂不冻结，不设全局硬倒计时。旧 3 舰总容量、100 点与 3600 秒是历史提案，不用于约束本版。8 艘内容身份、舰池可用数量与实际部署仍需内容卡和工程合同逐项核对。

**历史设定可沿用的层次**：赤铁-6 改是矿运船改装炮舰，依靠轨道炮与火控承担较集中火力；龙门-3M 是货船改装弹舱舰，承担远程导弹打击，长距离目标获取依赖共享情报（`docs/04_舰船设定.md` §7.2–7.3）。远地点号的“后方旗舰”是本轮部署决定，不应靠文案把它改成前线炮舰。舰级是可能的装备/角色，具名舰实例才拥有实际库存、燃料、损伤与命令记录。

**旧树线索与当前产品裁定**：固定旧树名册是 13 艘 proposal 候选，仅一艘具名龙门导弹舰 VESUVIUS；炮舰有 FERRY 与 ANVIL（`game_v17/docs/fleet_system.md` §1、`framework/content/fleet_roster.json`）。舰级目录 `ships_friendly.json` 的 GANTRY `known_ships` 为空，与名册是不同数据入口，不能互相代填。Astra 已裁定由合法舰级模板建立独立场景实例，每舰有稳定唯一 ID 及独立库存、燃料、损伤；未定新正典舰名时使用场景呼号，不复制 VESUVIUS 的具名身份，也不扩写主线正典。工程 Sol 在新基线核对四组合、实例生成和编制合法性；旧树数量不证明最新主线缺失。

## 2. 武器平台、弹药、发射与效果分层

| 层 | 本文用法 | 不能推出 |
|---|---|---|
| 舰艇 / 命名舰实例 | 拥有自身可用发射器、装载、库存与损伤 | 同级其他舰自动共享弹药或发射器 |
| 武器平台 / 发射器 | 轨道炮、导弹发射架及其兼容范围 | 任意弹药都可从任意平台发射 |
| 弹药型号 / 任务载荷 | 单体动能弹、集束动能弹、导弹或诱饵任务载荷 | 更换名称就有新行为、无限战中切换 |
| 发射与在途对象 | 记录具体发射舰、消耗、持续物与事件 | 一次发射既按母体又按子体重复结算 |
| 观测与玩家信息 | 按授权传感与共享情报展示结果和时效 | UI 自动知道诱饵真相、敌方库存或确证身份 |

**本轮设计**：单体动能穿甲弹作对单目标的基线；集束动能穿甲弹用有限覆盖换取单个命中单元较低作用。两种轨道炮弹沿既有 railgun 不可拦截契约，取舍来自机动、预测误差、散布、防护与资源。低质量或陈旧估计本身不新增一刀切禁射；AI 可能自主不选，射出后也可能因预测失准落空，既有 FIRE/ROE/平台/库存拒绝另按真实合同处理。航迹仿真诱饵有实际投放状态，可能造成某些观察者的可疑航迹，但有持续时间、消耗与交叉验证破绽。旧 `weapons_l1.json` 的 railgun/missile/decoy 是实现线索，不是这些新弹种的现成行为；固定树的导引头诱饵不能算战术航迹伪装已做完。

**平台映射待核**：龙门的 48 单元发射架是设定描述，舰级目录写 `missile_48_cell`，通用武器表写 `missile`。尚无证据证明两者是一份弹药库存或可直接转换的 ID。D2 干重、燃料比、Δv 与目录 `displacement_t`、旧点数也各有含义，不通过文案合并为单一成本值。

## 3. 两艘同级弹舱舰不同装载：设计示意

假设有两艘通过合法舰级模板建立的龙门-3M 场景实例 **M1**、**M2**（仅为场景呼号，分别有稳定唯一 ID，不是新增正典舰名或复制具名舰）。首个新增主武器装载切片中，两舰各选一种兼容的主装载，舰间可不同。若未来核实平台兼容和内容规格，M1 可担任打击，M2 可担任欺骗/支援；**现有三卡并未给出两种完整攻击导弹规格，也未批准龙门导弹架投放 AM-03**，因此此例不能直接转成可执行装载表。每舰的携行量、发射许可、库存、燃料与损伤独立记账；M1 发射不能扣 M2，读档不能凭空恢复库存。既有 PD、独立对抗设备及其他合法装备不因“单一主装载”而删除；出击冻结后不免费改型或补弹。

此示意说明**舰间异构**的设计分工；诱饵是否使用导弹发射架、另一种投放器或独立挂载尚需平台兼容审查。同一主发射系统的有限混装后延，届时另核槽位、库存、UI、AI 与存档映射。场景实例的内容、具体弹数、载荷、费用及平衡值仍待内容与工程核对。

## 4. 玩家可读文字与战报

简报应写实际可用的舰艇角色、任务和装载差异，不以旧 Chronos 日期/地点填空。编制页分开显示“舰级可装”“本舰已装”“本舰剩余”，拒绝不兼容组合时给可理解原因。战斗中单体/集束显示射手有权获得的观测估计、年龄/不确定性与实际发射结果；物理真值仅供权威结算，不作火控捷径。诱饵只呈现玩家一方可知的投放、观测与报告，友军共享受消息到达约束，敌方判断不作为常驻真值。HUD 常驻当前弹种、可用量、授权/准备状态及本次操作相关风险；详细机理放展开层。战报分别记录弹药消耗、真实命中/失效、诱饵造成的可观测影响与未知项，不把诱饵投放等同于敌方必然受骗。
