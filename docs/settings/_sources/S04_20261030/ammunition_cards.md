# S-04｜三份弹种设计卡

状态：Astra 2026-10-29 已定战术方向，2026-10-30 审查收口 R1–R5；名称为工作名，数值和工程实现未批准。**本轮未实现/NOT RUN** 不等于断言当前项目没有相关基础。以下只定义虚构游戏取舍，不提供现实制造或工程参数。历史线索见固定旧树 `docs/05_技术手册.md` W-01/W-05、`docs/12_军语规范.md` 及 `game_v17/docs/combat_ballistics.md`；旧树不能证明最新主线不存在后续改动。

## AM-01｜单体动能穿甲弹（比较基线）

| 项 | 设计 |
|---|---|
| 用途 / 平台 | 轨道炮兼容的单体弹，适合在射手掌握较可靠估计时对单个较强防护目标集中作用；低质量估计仍按既有开火合同处理，是否所有炮舰均可用按舰级挂载核对。 |
| 好用 / 不好用 | 目标明确、窗口稳定且需要单点作用时好用；目标持续机动、定位较旧、需要同时覆盖多个可能位置时风险高。 |
| 信息需求 | 射手有权获得的目标观测/估计位置与预测、数据年龄和不确定性，以及既有火控授权；友军共享须等消息实际到达。物理真值仅用于权威模拟/结算，不向玩家或 AI 提供全知火控捷径；身份评估与 ROE 不代替 FIRE 许可。 |
| 消耗与代价 | 每次发射扣具体舰实例库存、占用火控准备与射击窗口；窄覆盖导致失手代价。 |
| 失败与反制 | 低质量/陈旧估计本身不新增禁射门禁：已发射后可能因预测失准或目标机动而落空，AI 可自主不选该射击；现有 FIRE/ROE、平台或库存拒绝才按对应真实原因记录。单体轨道炮弹沿既有 railgun 不可拦截契约；对方可机动、改变窗口或依现有防护降低效果。 |
| 玩家反馈 / AI 意图 | 发射前给单体作用与可知预测不确定性，发射后区分命中、未命中、未知；AI 在其有权收到的情报与资源下权衡单点打击，不把偏好等同于硬拒绝。 |
| 存档 / 结算 | 保存具体舰库存、发射与在途对象；战报按真实命中和消耗记账，不把预测当结果。 |
| 待定 | 与旧 railgun 项的关系、兼容舰级、可读预测字段、平衡数值、损伤效果与存档迁移。 |

## AM-02｜集束动能穿甲弹（工作名）

| 项 | 设计 |
|---|---|
| 用途 / 平台 | 轨道炮弹种候选，在有限预测区域形成覆盖，给轻/中防护目标或位置不确定的单目标施压；须先验证平台兼容。 |
| 好用 / 不好用 | 对位置误差较大、需要覆盖一片预测区域时可能更合理；对单个重防护目标或目标高度分散时，单个命中单元作用较弱且易浪费。 |
| 信息需求 | 使用射手有权获得的观测/估计区域、预测误差、年龄及不确定性和现有开火授权。可知的友军/民用风险按已有规则提示；**不要求获知隐藏旁观实体或全图安全才开火**，也不因 UI 说“可能命中”泄露隐藏实体。物理真值只用于权威结算。 |
| 消耗与代价 | 与单体弹共享有限平台时间和具体舰库存；覆盖换取每个命中的较低穿透/损伤；每次发射不自动给更多总伤害。 |
| 失败与反制 | 散布过大、预测失准、目标逃出区域或防护可使效果下降；**集束轨道炮弹沿 railgun 不可拦截契约**，不另加拦截门禁或拦截抗性收益。若采用多个在途对象，限制数量并防母体/子体重复结算；聚合表示也须保证可解释结果。其他类型反制另核。 |
| 玩家反馈 / AI 意图 | 发射前显示“覆盖机会”和“单点作用较低”及本方可知风险；AI 可在位置不确定时偏好覆盖，也可因资源或风险偏好不选。低质量/陈旧估计不新增一刀切禁射；AI 偏好、射后物理落空与既有 FIRE/ROE/平台/库存拒绝分别记录，不因名称默认更优。 |
| 存档 / 结算 | 记录具体舰弹药、发射组、在途/效果唯一 ID、一次性消耗与命中/未命中；读档不重复生成或重复伤害。 |
| 待定 | 散布和对象数量、友军/民用安全边界、平台与弹种选择 UI、性能预算、单体/集束对照场景。 |

## AM-03｜航迹仿真诱饵弹（工作名）

| 项 | 设计 |
|---|---|
| 用途 / 平台 | 投放实际存在且有限寿命的对抗实体/信号，使特定观察者可能形成可疑目标或错误航迹判断。发射/投放平台要单独核对，不默认与导弹架通用。 |
| 好用 / 不好用 | 对方依赖单一观测渠道或短窗口判断时可争取时间；多来源交叉核查、持续跟踪、机动/热特征不一致时易被识破。 |
| 信息需求 | 分投放实体、各观察者观测、各自航迹/识别判断三层。己方知道自身投放行为，不代表友军即时共享，也不代表敌方必被骗。 |
| 消耗与代价 | 具体舰库存与投放动作消耗；有持续时间、投放位置和暴露风险；不能无限产生永久确证目标。 |
| 失败与反制 | 可能未被观察、被判不可信、超时失效或被反制；对方可用多传感器、观测年龄、行动一致性复核。导引头诱偏若存在，只是另一个消费者。 |
| 玩家反馈 / AI 意图 | 己方看到已投放和自己获得的观测，不显示敌方隐藏判断；报告可写“可能造成误判”“已观察到敌方反应”并附来源。AI 按其可用情报判断是否部署或识破，不读全知实体真值。 |
| 存档 / 结算 | 保存投放实体、寿命、各方已获观测与实际消息；读档不重复投放/扣弹或向未获授权方泄漏诱饵身份。 |
| 待定 | 兼容平台、可影响的观测渠道与特征、失效/识破条件、性能、AI 消费、UI 术语及存档合同。 |

三卡的**共同正例**：一局选单体更合理，另一局因位置不确定选集束更合理；诱饵的同一投放在不同观察者形成不同证据。**共同反例**：集束在全部维度优于单体；诱饵直接写入敌方确证身份；两艘同级舰共享库存；文案把预测或设计样稿当已发生战果。
