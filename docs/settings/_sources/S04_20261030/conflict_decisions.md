## 本轮已收口的三项与待核证据

1. **同级舰实例**：采用合法舰级模板建立独立场景实例，稳定唯一 ID、独立库存/燃料/损伤；新正典舰名未定时使用场景呼号。旧树仅一艘具名龙门舰，是内容与运行核对点，不再要求先补两艘正典具名舰。
2. **新增主武器装载**：首切片每舰单一主装载、舰间可不同；既有 PD、独立对抗设备及其他合法装备照旧。同一主发射系统有限混装后延，不能从示例批准导弹架通用诱饵投放或两种攻击导弹规格。
3. **旗舰计数**：11 艘中 8 艘旗舰/支援舰含远地点号，3 艘为作战位置。远地点号后方部署且有真实风险。首版 S-04 曾误列“编制外节点”备选，现依 GitHub main 的用户确认文档及 Astra 审查撤回；历史误差保留在此，不再作为当前选择。

剩余核对是内容实例、实际接口和运行证据，不是上述产品选择的重提。工程依赖沿 **#45 在先、#63 随后、B1b 逐舰账本及相关接口再核**；本包不派 DeepSeek，也不称最新主线缺失这些功能。
