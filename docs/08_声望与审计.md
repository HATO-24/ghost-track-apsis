## 0　一句话

> 这个游戏没有道德值，只有**记录**。
> 同一份内部报告，五个对象会读出五种结论。

---

## 1　三个量，不是三条槽

| 量 | 范围 | 谁看 | 作用 |
| --- | --- | --- | --- |
| **阵营声望** | 五个对象，各 -3 ~ +3 | 玩家可见（简报 / 无线电 / 补给价格 / 通行） | 对话、补给、通行、盟友是否来接、Act 2 是否给情报 |
| **指挥信任** | 0 ~ 100 | 隐藏（OCJC / OCUVF） | 授权范围、增援、调查时的态度、能否调动友邻分遣群 |
| **记录 / 档案** | 事实列表 | OCJC 监察、UEG 调查方、玩家 | 证据。不是分数，不可洗白；Act 2 的引用源 |

- **不做“善恶条”。** 同一件事，OCJC 可能记你“擅自行动”，Meridian 记你“救了人”。
- **不做“道德值”。** 玩家不是被评分，是被归档。
- 船员信任 Act 2 再加；第一关只记记录与声望。

## 2　五个声望对象

| 对象 | English / 定义 | 谁在看 | 对玩家的意义 |
| --- | --- | --- | --- |
| **OCU / OCJC** | Orbit Colony Union / Orbit Colony Joint Congress：五个港群的政治联合与联合议会；玩家的政治母体，但没有常备军 | 志愿舰队、港群议会、OCJC 监察 | 补给、通行、Act 2 授权与调查；最重要的长期变量 |
| **Meridian** | L1 子午港群：Greenwich、Sextant、Chronos、Astrolabe；本关现场的政治实体 | 港务委员会、引航员工会、Chronos 居民 | 补给价格、进港引航、现场情报；HOLD/EVACUATE 的直接受益者 |
| **UEG 鸽派** | UEG 轨道事务委员会 / 自治派：要求复核第七号令，玩家的潜在盟友 | 委员会、UEG 调查方、部分媒体 | 合法性、调查渠道、UEG 内部保护；EXPOSE 的接收方 |
| **远地环带飞地** | 小行星带声索地；后期后方与撤离通道 | 外环观察员、后续战场 | 难民通道、资源、Act 2 后方；第一关只影响观察员态度 |
| **清算者** | UEG 第33轨道特别独立舰队（Reclaimers）；体制内暴力，不是敌国 | 前线接管官、第33舰队司令部 | 拦截、通缉、调查压力；开火后彻底敌对 |

- 五个对象各自独立计分，不合并；声望变化通过简报、无线电口吻、价格、是否放行体现，**不显示数字条**。
- 第一关初始全部为 0（提案）；具体数值等平衡时再调。

## 3　第一关的四个结局

**HOLD / EVACUATE / EXPOSE** 三种默认结局都算**通关**，都进 Act 2，只是分支不同；
**FIRE** 是灾难分支，仍可继续，但把整个战役推向调查与战争风险。

| 结局 | 做法 | OCU/OCJC | Meridian | UEG 鸽派 | 外环 | 清算者 | flag / Act 2 后续 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **HOLD / 卡住** | 卡位、拖时间、拒绝签字，把接管拖成 UEG 复核 | +2 | +1 | +1 | 0 | -2 | `outcome=hold`；Act 2 清算者按程序盯你，Meridian 给补给折扣 |
| **EVACUATE / 撤人** | 撤走 Chronos 平民与储罐/补给，让清算者接管空站 | +1 | +2 | +1 | +1 | -1 | `outcome=evacuate`；Act 2 有人道信用，Chronos 补给线吃紧 |
| **EXPOSE / 曝光** | 把 GHOST TRACK 假旗证据交给 OCJC/UEG 鸽派 | +1 | 0 | +2 | 0 | -3 | `outcome=expose`；Act 2 调查线与清算者通缉线同时打开 |
| **FIRE / 开火（灾难）** | 授权/率先开火（对 2001 或误击 9001） | -1 | -2 | -2 | -1 | +1 | `outcome=fire`；Act 2 直接进调查/战争风险线；清算者借机坐实 ID13 非法化 |

- 没有“正确”结局；只有你愿意付哪一种账。
- 声望变化是**提案值**；FIRE 的清算者 +1 表示“他们政治得利”，不是关系变好。
- 四种结局都触发同一张**内部事后报告**页，只是报告段落不同。

## 4　报告：内部事后报告

### 4.1 性质

- 报告是**给 OCJC / OCUVF 的内部事后报告**，不是给 UEG 或 Greenwich 的官方回复。
- 报告是舰队内部归档，**不走通信流**（19 §5 T1-14 格式）。

```
OCJC / OCUVF 内部事后报告 / INTERNAL AFTER-ACTION
报告单位：OCUVF-ID13 指挥官
事件：L1 Meridian-05 Chronos · 第七号轨道紧急托管令
裁决：HOLD / EVACUATE / EXPOSE / FIRE
经过：……
证据：……
声望：……
建议：……
```

### 4.2 什么时候可以造假

| 报告时的处境 | 可选 |
| --- | --- |
| 一切合规 | **如实**（或调整措辞） |
| 未经授权开火 | 如实 / 淡化 / 伪造 |
| 误击民用目标 | 如实 / 淡化 / 伪造 |
| 储罐/站体损失、超时、交战规则违规、人员伤亡 | 如实 / 淡化 / 伪造 |

没有不良后果时，不给“伪造”选项——**造假不是随时可用的技能，是事故之后的逃生门。**

### 4.3 证据

报告会被五类记录对照：

- 传感器日志（谁在什么时候开机、看到了什么）
- 命令队列（谁下的令、什么时候生效、是否撤销）
- 通信记录（LD/LR/RDO；谁说了什么）
- 港务与核查组黑匣子（Chronos 遥测、UEG 核查组记录；EXPOSE 的关键）
- 船员证词（Act 2 再加；第一关只做前四类）

### 4.4 造假怎么被发现

- `perjury_count`：每次选择“淡化/伪造”+1。
- `suspicion`：由伪证次数、证据矛盾、目击者/遥测共同决定。
- **第一次**：证据模糊时可能过，但留下 `AUDIT FLAG 01`。
- **第二次**：触发例行审计——OCJC 监察组与 OCUVF 军法开始核对日志。
- **第三次**：最坏结局——OCJC 除名、移交 UEG 调查方；清算者获得通缉授权，ID13 被定性为无国籍武装；
  OCJC 另组一个分遣群接替你的位置，并允许清算者“协助追捕”。
- 这就是标题的第二层：**你自己变成了一条没有登记、没有法理的航迹**。

> 不是说一次谎就死；是谎会累积，而制度最擅长的就是等。

### 4.5 demo 里的实现

- 开火 → 自动冻结（时间/命令队列）→ 后果页 → 内部报告页。
- 报告页只有两个选项：**如实** / **伪造**。
- 选伪造：显示 `REPORT FILED — AUDIT FLAG 01`，demo 结束；不做后续审判。
- 选如实：显示 `REPORT FILED — CHRONOS / ORDER 7`，demo 结束；Act 2 引用。

## 5　开火

- **允许开火，但它是灾难分支**，不是英雄分支。玩家可以驳回/批准渡口的请求，也可以自己下令。
- 一旦开火，**demo 自动冻结**：时间冻结、命令队列冻结、切到后果页。
- 后果页显示（脚本化）：
  - 是否命中、命中谁（2001 或 9001，随版本定）
  - Chronos 站体/储罐损坏
  - 平民伤亡
  - 交战规则违规 / ID13 被定性
  - 记录新增条目
- 后续不做完整战斗；玩家只能选择报告方式，然后 demo 结束。
- 这不是 game over；是**进入另一条分支**。真正的调查在 Act 2。

## 6　分支接口

Act 2 只读这些值：

```json
{
  "outcome": "hold | evacuate | expose | fire",
  "standing": {
    "ocu_ocjc": 0,
    "meridian": 0,
    "ueg_doves": 0,
    "outer_ring": 0,
    "reclaimers": 0
  },
  "command_trust": 72,
  "perjury_count": 0,
  "suspicion": 0,
  "ghost_track_evidence": false,
  "record": [
    { "t": "T+62:14:08", "event": "weapons_release_authorized", "target": "2001" }
  ]
}
```

- Act 2 的简报、无线电口音、补给价格、盟友是否出现，都读这些值。
- `ghost_track_evidence` 记录 EXPOSE 是否拿到假旗证据（见 07 §3）。
- 声望不显示成进度条；只在简报、对话、价格里体现。玩家要自己记。
- 最坏结局（`perjury_count >= 3` 或 `suspicion >= 80`）触发“被 OCJC 除名/被清算者追捕”战役线；
  玩家从志愿舰队指挥官变成无国籍武装的指挥官（或囚犯）。

## 7　demo 范围

- 只记录 `outcome`、`standing`、`command_trust`、`perjury_count`、`suspicion`、`ghost_track_evidence`、`record`。
- 不做声望 UI、不做完整审判流程、不做新分遣群追捕线。
- 四种结局各显示一张内部报告卡（文字），让玩家看到“我选了哪一种账”。
- 开火分支只到 `AUDIT FLAG 01` 为止。
