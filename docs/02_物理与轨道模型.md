# 物理与轨道模型

> 这份文档定的是**数值与算法**，不是玩法。所有常数取自真实数据；
> 凡是"游戏化"的地方都会明确标注，不允许悄悄失真。

---

## 1　坐标系

| 帧 | 用途 | 定义 |
| --- | --- | --- |
| **ECI**（地心惯性） | 仿真主帧 | 原点地心，X 指向春分点，Z 指向北极 |
| **LVLH**（局部水平） | 相对运动、UI 显示 | R 轴沿半径向外，S 轴沿速度方向，W 轴沿轨道法向 |
| **BODY**（舰体） | 姿态、推进方向 | +Z 舰艏，+X 右舷，+Y 龙骨 |

**仿真内部一律用 ECI 做积分**，只在显示与相对几何时转换。这样避免"参考系本身在加速"带来的伪力错误。

## 2　二体问题

### 2.1 基本常数

```
μ_earth = 398600.4418 km³/s²
R_earth = 6378.137 km
```

### 2.2 轨道根数

由状态矢量 `(r, v)` 求六个根数：

```
h = r × v                       比角动量
e_vec = (v × h)/μ - r/|r|       偏心率矢量
e = |e_vec|                     偏心率
a = 1 / (2/|r| - |v|²/μ)        半长轴（vis-viva 反解）
i = acos(h_z / |h|)             倾角
Ω = atan2(h_x, -h_y)            升交点赤经
ω = 升交点与近地点夹角           近地点幅角
ν = 近地点与当前位置夹角         真近点角
```

### 2.3 常用关系

```
vis-viva:    v² = μ (2/r − 1/a)
周期:        T = 2π √(a³/μ)
圆轨道速度:  v_c = √(μ/r)
逃逸速度:    v_esc = √(2μ/r)
```

**参考数值（400 km 圆轨道）**：`r = 6778 km`，`v = 7.67 km/s`，`T = 92.5 min`。

## 3　轨道传播（最常用的运算）

给定 `(r, v)` 和经过时间 `Δt`，求新的 `(r, v)`。用**开普勒方程**：

### 3.1 算法

```
1. 由 (r,v) 求 a, e
2. 求偏近点角 E：
     平近点角 M = √(μ/a³) · Δt + M₀
     解 M = E − e·sinE          ← 牛顿迭代
3. 由 E 求真近点角 ν：
     tan(ν/2) = √((1+e)/(1−e)) · tan(E/2)
4. 在轨道平面内由 ν 求 r, v
5. 用 Ω, i, ω 旋转回 ECI
```

### 3.2 牛顿迭代（伪代码）

```js
function solveKepler(M, e, tol = 1e-9) {
  // 初值：小偏心率用 M，大偏心率用 π
  let E = e < 0.8 ? M : Math.PI;
  for (let k = 0; k < 30; k++) {
    const f = E - e * Math.sin(E) - M;
    const fp = 1 - e * Math.cos(E);
    const dE = -f / fp;
    E += dE;
    if (Math.abs(dE) < tol) break;
  }
  return E;
}
```

> 双曲线轨道（e > 1）改用双曲开普勒方程 `M = e·sinh(H) − H`，实现时单开一个分支。

### 3.3 性能

一次传播约 200 次浮点运算。**20 艘船 × 60 Hz × 300 倍时间加速**时，不要每帧传播 300 次 —— 用"关键帧 + 插值"，或者按需要传播（见第 9 章）。

## 4　机动

### 4.1 Δv 与齐奥尔科夫斯基

```
Δv = Isp · g₀ · ln(m₀ / m₁)        g₀ = 9.80665 m/s²
m₁ = m₀ · exp(−Δv / (Isp·g₀))
```

**这是本作的"钱"**：给定燃料质量，能买到多少 Δv 是死的，玩家必须分配。

参考值（干重 1000 t 的舰，燃料 300 t）：

| 推进 | Isp | 满燃料 Δv |
| --- | --- | --- |
| 化学 | 320 s | ≈ 1.03 km/s |
| 核热 | 900 s | ≈ 2.90 km/s |
| 电推 | 3000 s | ≈ 9.66 km/s |

> 电推 Δv 大但推力小：推力 20 kN 推 1000 t 只有 0.002 g，变轨要烧几十分钟。
> 这个差别是本作"两种机动哲学"的物理基础。

### 4.2 Hohmann 转移（教学/参考）

```
Δv₁ = √(μ/r₁) · (√(2r₂/(r₁+r₂)) − 1)
Δv₂ = √(μ/r₂) · (1 − √(2r₁/(r₁+r₂)))
```

两个脉冲，最省 Δv，但耗时固定（半个转移椭圆周期）。**游戏里只在"同平面、大高度差"时是最优解**，作战中几乎用不上——但它是玩家理解 Δv 的入口。

### 4.3 Lambert 问题（交会 / 拦截）

给定起点 `r₁`、终点 `r₂`、飞行时间 `Δt`，求所需速度矢量。

- 这是**拦截解算**的核心：敌人 20 分钟后会到某处，我现在该往哪烧？
- 实现用**通用变量法**（universal variables）或 Battin 的解法；单次求解 ≤ 1 ms
- 游戏层面：玩家点"拦截"，系统解算并显示 Δv 代价与到达时刻

**重要**：Lambert 解可能有多支（短程/长程），UI 必须让玩家看到代价最高的那一支，避免"我以为只要 200 m/s"。

### 4.4 连续推力（电推螺旋）

低推力不能近似成脉冲。做法：

```
沿速度方向持续加速 → 轨道半径缓慢抬升（螺旋爬升）
数值上就是：每步 a = F/m，按当前速度方向施加
```

**不需要解析解**，直接积分即可。这也让电推舰的"变轨"变成一个**持续几十秒的可中断过程**——玩家可以中途反悔，代价是已经烧掉的燃料。

## 5　数值积分

### 5.1 两种方案

| 方案 | 用途 | 步长 |
| --- | --- | --- |
| **解析传播**（开普勒） | 无推力滑行段 | 任意长 |
| **数值积分**（RK4） | 有推力、多体、需要精度 | 0.05–0.5 s |

**默认走解析传播**：绝大多数时间船是不烧的，用开普勒一步到位，代价极低。

**烧的时候切数值积分**：RK4 四阶，步长自适应（加速度大时缩到 0.02 s）。

### 5.2 为什么不用辛积分

辛积分（如 velocity Verlet）能量守恒更好，但轨道偏心率高时精度不够。这里用 RK4 + 短步长更简单，且我们的时间尺度短（一局 40 分钟），累积误差可接受。

### 5.3 误差预算

| 来源 | 一局累计误差 | 处理 |
| --- | --- | --- |
| 开普勒迭代收敛 | < 1 m | 迭代到 1e-9 |
| RK4 步长 | < 10 m / 局 | 步长上限 0.1 s |
| 忽略 J2 | 数十 km / 天 | **游戏内忽略**，但文档注明 |

> J2 摄动对本作的影响是"轨道缓慢进动"，在 40 分钟一局里不足以影响玩法，明确忽略。

## 6　六自由度刚体

### 6.1 状态

```js
{
  r: [x, y, z],        // ECI 位置，m
  v: [vx, vy, vz],     // ECI 速度，m/s
  q: [w, x, y, z],     // 姿态四元数（BODY ← ECI）
  w: [wx, wy, wz],     // 体轴角速度，rad/s
  m: 干重 + 剩余燃料，kg
}
```

### 6.2 运动方程

```
ṙ = v
v̇ = a_thrust(q) + a_gravity(r)
q̇ = 0.5 · q ⊗ [0, ω]
ω̇ = I⁻¹ (τ − ω × (I·ω))          ← 欧拉方程
```

### 6.3 姿态控制

RCS 产生力矩，有**最小脉冲**（不能无限精细）：

```
角加速度上限 α_max  = τ_max / I
角速度上限   ω_max
```

典型值（150 m 护卫舰）：转 90° 约 **4–8 秒**。

**这直接决定玩法**：发现目标 → 转向 → 开火，中间有 5 秒的窗口，敌人也在动。

### 6.4 四元数积分

不要用欧拉角（万向锁）。每步：

```js
const dq = quatFromAxisAngle(normalize(omega), |omega| * dt);
q = normalize(quatMul(q, dq));
```

## 7　质量与推进

燃料消耗实时影响质量，进而影响加速度：

```js
// 每步
const mdot = thrust / (Isp * g0);        // kg/s
m -= mdot * dt;
const accel = thrust / m;                // 推力恒定，加速度随质量变化
```

**这给"最后一滴燃料"赋予戏剧性**：油越少，加速越快，但机动余地也越小。

## 8　相对运动与交战几何

### 8.1 相对状态

```
Δr = r_target − r_self          （ECI 下相减，再转到 LVLH 便于显示）
Δv = v_target − v_self
closing = −(Δr · Δv) / |Δr|     接近速度
TCA      = |Δr| / closing        最近接近时间（线性近似）
```

### 8.2 交火窗口

```
窗口时长 ≈ 武器有效射程 / 相对速度
```

相对速度 5 km/s、射程 300 km → **窗口 60 秒**。
相对速度 0.5 km/s、同样射程 → 窗口 600 秒，但双方都能从容拦截导弹。

**这是本作最核心的战术张力**：快 = 难打但打得狠；慢 = 好打但打不穿。

### 8.3 提前量

轨道炮是瞬时命中，但要打**提前量**：

```
预测位置 = propagate(target, 飞行时间)
```

飞行时间 = 距离 / 弹速（相对论忽略）。300 km / 5 km/s = 60 s —— 60 秒后的目标位置误差可能很大，这就是"打不中"的来源。

## 9　时间加速与确定性

### 9.1 固定步长仿真

仿真以 **20 Hz** 固定步长推进（`dt = 0.05 s`），与渲染帧率解耦。

```
accumulator += realDt * timeScale
while (accumulator >= 0.05) { step(0.05); accumulator -= 0.05; }
```

时间加速 300× 时，一帧要跑 `300 × 0.05 / 0.05 = 300` 步 —— 太多。
所以加速时用**大步长 + 解析传播**：

| 时间倍率 | 仿真步长 | 方法 |
| --- | --- | --- |
| 1× | 0.05 s | RK4 |
| 10× | 0.05 s | RK4 |
| 60× | 0.5 s | 开普勒（滑行）/ RK4（推力） |
| 300× | 5 s | 开普勒 |

### 9.2 确定性

- 不用 `Math.random()`，用**种子化的伪随机**（同样的种子同样的序列）
- 浮点运算顺序固定
- 命令队列按时间戳排序，同时刻按 id 排序

这样就能录一段命令、重放、比对最终状态做回归测试。

## 10　明确忽略的项

| 项 | 为什么可以忽略 |
| --- | --- |
| J2 摄动 | 40 分钟内轨道进动很小 |
| 大气阻力 | 战场在 400 km 以上 |
| 太阳光压 | 影响量级远小于推力 |
| 第三体引力 | 地月转移段例外，v1 不做 |
| 相对论效应 | 完全无关 |
| 结构形变 | 刚体假设足够 |

**所有忽略项都要写进文档**，将来有人问"为什么轨道和真实不符"时有据可查。

## 12　实现顺序

1. `kepler.js` —— 根数 ↔ 状态矢量、传播（自测：传播一个周期回到原点，误差 < 1 m）
2. `maneuver.js` —— Hohmann、Lambert、Δv 计算
3. `rigid.js` —— 六自由度积分、四元数
4. `sim.js` —— 固定步长循环、命令队列
5. `data/*.json` —— 舰船与武器参数

每个模块都配一个可在控制台跑的**自测用例**，不依赖浏览器。
