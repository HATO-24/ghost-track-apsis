## 0　使用说明

1. 写 UI 文案、关卡脚本、`data/*.json` 之前先查这一页。
2. 英文列写 `—` = **设定文档没有给**，不要自己编；标 `※` = 按文档命名规则推得，入数据表前需拍板。
3. 旧名、被否方案见 §11：它们不是「备用名」，是**已否决**的方案。
4. 发现 03–06 内部矛盾，记在 §13，**不要顺手改 03–06**。
5. `§` 后数字是文档章节号，不是行号。

- 舰名由**公约舰队舰名委员会**按《命名条例》授予，按舰种分系列（§5.2）。
- **一艘船只有一个标准名，是英文**；其他语言都是本地化。
- **船壳上刷英文**（工作语言），**UI 显示本地化**。
- 日语舰名：用汉语词 + **音读**，不用口语短语——是「無赦（むしゃ）」，不是「容赦なし」。
- 型号国际名同理：刺桐-2 = **ZAITON-2**，龙门-3M = **GANTRY-3M**，赤铁-6 = **HEMATITE-6**。

- **五家船厂**：决定舰体与剪影（L2 认厂，L3 认使用方，L4 认船——但接触等级定义见 C-3）。

## 11　命名规约（检查表）

### 11.1　七条铁律

1. **英文是舰名的标准名**，其他语言是本地化（L-06；04 §11）。
2. **一个地方三种语言三个名字，不是互译**；拼音不是名字（L-07；03 §11.1）。
3. **名字的数量 = 住在那里的社群数量**（03 §11.2）。
4. **舰级 = 教条，舰名 = 后果**；不取希望，只取后果（L-05；03 §8.3；04 §11.4）。
5. **船有名字，人有编号**（L-05；03 §8.3；04 §11.4）。
6. **企业命名来自出身，清算署命名来自后果**（L-08；06 §9）。
7. **船厂即身份**：L2 认厂、L3 认使用方、L4 认船（L-09；04 §9.1）——**但接触等级定义与 05/07 冲突，见 C-3；在冲突解决前，UI 教学以 07 为准。**
