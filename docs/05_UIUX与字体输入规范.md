# 05 UI/UX、字体度量与输入法

> 状态：权威。替代 `09`/`35` 中的临时坐标。保留 V1 美术语言。

## 1 技术路线

- 地图/线框：自绘（`Control._draw`）。
- 面板/按钮/列表/弹窗/输入框：Control + Theme + 9-Slice。
- 自绘与 Control 共用同一套字体度量、颜色、间距 token。
- 不复用阶段2临时 `transit_hud.gd` 作为成品骨架。

### 为什么迁移

9-Slice、Layout Group、Content Size Fitter、滚动、焦点、IME、可访问性、不同分辨率适配，手绘坐标无法长期维护。

## 2 字体度量（Token）

必须固定：

```text
font_cjk, font_mono, font_display
size_xs=7, sm=8, md=9, lg=11, xl=14, title=18
ascent/descent per font+size
baseline_offset
line_height = round(size * 1.35)
padding_x=6, padding_y=4
row_gap=6
tracking_caps=0.08em
```

规则：

- CJK 与等宽混排用统一基线，不靠“垂直居中”。
- 数字用 tabular figures（等宽数字）。
- 全大写英文增加字距。
- 多行文本固定行高，不依赖自动换行。
- 所有面板左右内边距 ≥ 6px，上下 ≥ 4px。

## 3 Control/Theme 规范

- 每个面板：9-Slice 边框 + 内边距 + 标题栏。
- 列表：Vertical Layout Group + Content Size Fitter；长名字省略/换行规则。
- 按钮：最小高度 22–28px；hover/pressed/disabled 状态。
- 弹窗：模态层 + 焦点捕获 + ESC/关闭。
- 浮动标签：world-to-screen 投影 + 避让；拥挤时只显示主标签，其余圆点。

## 4 指针

- 自定义指针，符合 V1 线框/准心美术。
- 状态：默认、可点击、拖拽、不可用、等待。
- 指针不应遮挡准心/目标牌。
- 悬停三色圆点显示“存档/存档并回主菜单/存档并退出桌面”。

## 5 顶栏

- 左：`指挥官 / COMMANDER` + 玩家名。
- 任务时间：自开始持续计时；入港重置，港内显示 `PORTED TIME` 并持续计时。
- 中间动态计时器窗口：
  - 标准：变轨/入轨/对接倒计时；
  - 战斗：命中/导弹倒计时，可堆叠，过期自动移除；
  - 特殊：剧情窗口/拦截窗口。
- 右：链路、时标、Δv、ROE（序章后解锁）。

## 6 接触列表 / 目标牌

- 友军可折叠；无威胁目标自动隐藏。
- 目标牌尺寸缩小，但元素不变。
- 按目标类型加底色；字体颜色统一；目标标号加大。
- 选中行高亮/反转。
- 威胁排行图标加舰种。
- 地图选中目标高亮动画；拥挤时标签避让/圆点。

## 7 地图

- 雷达圈分层：PDZNE/火控/雷达不同粗细/透明度。
- 运动矢量、武器射线分色。
- 目标锁定/ROE 提示（锁图标 + `ROE HOLD`/`Awaiting Auth`）。
- 比例尺、图例、星图/站体符号按 `03`。
- 空间站只显示符号，不显示近景模型。

## 8 右侧舰船详情

- 舰名/批号/级别/角色/状态。
- 状态条加粗，条内/右侧显示数值。
- ROE 独立醒目显示（HOLD/TIGHT 等）。
- 传感器架、损管入口、Δv、证据。
- 友军可指挥舰与敌方目标分页；敌方无指挥/损管。
- 未开火原因提示。

## 9 日志/时间轴

- 时间戳深灰，动作亮色；时间轴提示提亮。
- 通信/命令/事件独立分区；可展开全文。
- 回放指针可鼠标拖动。

## 10 动态计时器

数据来自命令/仿真事件，不由 UI 计时：

```text
timer_id, kind, label, start_t, end_t, target_id, source_event
```

过期自动移除；可堆叠；支持暂停/时标。

## 11 输入法与玩家名

- 首发中日英；本地化接口开放。
- 玩家名输入：过滤控制字符/特殊符号；长度限制；重复名检测（可选）。
- IME：捕获组合事件，自绘候选窗（美术兼容）。
- 候选窗位置避让；不遮输入框；支持上下选择/确认/取消。
- 名字写入存档/就职公文/顶栏/通信。

## 12 教学 UI

- 弹窗不挡地图中心；贴边/锚定高亮对象。
- 高亮：呼吸边框 + ≤30% dim。
- 目标标记：旋转瞄准环。
- 字幕：点击/空格下一句。
- 完成条件由教学状态机控制，不由 UI 计时器。

## 13 字段清单

所有 UI 字段必须列入 `docs/12_UI字段清单.md`（待建）并附呈现样式；本文件先定义分类：

- 顶栏、接触列表、目标牌、地图、右侧舰船、传感器、损管、导航、命令、通信、日志、时间轴、教学、弹窗、输入法、存档、ROE、战斗。

## 14 验收

- 1920×1080 与 1600×900 无溢出/错位；
- CJK/英文/数字混排基线一致；
- 长文本/长舰名不破框；
- 输入法候选窗可用；
- 任意面板可键盘/鼠标操作；
- 视觉仍为 V1 终端语言。
